# A3 失败的根因：概念错误，不是运气

日期：2026-07-26（结果产生之后写，作为对已冻结 STOP 判决的解释，不改判决）

引导实例把弧 (i,j) 的成本改为 `d_ij − (π_i + π_j)/2`。对一条经过客户
`c_1 … c_k` 的路线，沿途累加这些半个对偶恰好等于 `Σ_{i∈r} π_i`（车场对偶为 0）。

因此对**任何完整解** S（每客户恰覆盖一次）：

    引导成本(S) = 真实成本(S) − Σ_{全部客户} π_i

右端第二项与 S 无关，是常数。**引导实例与真实实例是同一个优化问题，只差一个常数。**
HGS 在其上的行为不可能不同，唯一差异来自 2.3% 被截断到 0 的弧与取整噪声。

这解释了两个观测：
- `guided_only_columns_selected` 五题全为 0；
- PR17B 的 A3 成绩 4776.851 与 D6 的 k=6 逐位相同。

**教训（对后续设计有约束力）**：对偶价格不能用于引导"求解整个 VRP"的求解器。列生成
要求的是**逐条路线定价**——求解"找一条约化成本最负的路线"这一子问题（带资源约束的
初等最短路），其目标是单条路线的约化成本，不会因整解覆盖约束而抵消。任何后续候选若
再次采用"改成本后重跑整解求解器"的形式，均属同一错误，不得重提。

本说明不改变 `STOP_A3_DUAL_GUIDED` 判决，也不授权任何修补或重跑。
