# Duty-HGS 充电常量外提后单轮复核

## 结论

本包只复核不改变候选集合和 best-improvement 语义的计算提速，不形成算法成绩或算例选择。北京 37 客户子问题仍生成 2132 个动作；动作编号、通道、车辆组、改动车辆、状态、错误和候选成本的浮点十六进制表示与提速前逐行比较，差异 0 项。罚后最佳动作仍为 `whole-duty-type-exchange:CV_D_beijing_1<->EV_D_beijing_1`，完整可行且增量结果与完整真值一致。

同机同输入的单轮墙钟由 16.620887 秒降到 8.466435 秒，本次技术测量快 1.963 倍。墙钟只用于判断实现提速是否真实，不是正式算法表现。
