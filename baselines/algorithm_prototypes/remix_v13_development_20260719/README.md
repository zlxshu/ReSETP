# ReMIX V13 six-instance development gate

This directory implements the single pre-registered candidate in
`REMIX-V13-DEV-001`.

The gate compares PyVRP 0.12.2 HGS, PyVRP 0.13.4 ILS, and ReMIX on the six
frozen V13 development instances. It is a short development gate, not the
28-instance paper experiment.
