# 已核实的结构快照（不是已下载源文件）

本文件只摘录从公开论文正文/页面中实际看到的规模、节点类别和字段描述。因为源数据没有落盘，以下内容不能替代文件级字段抽查。

## 1. 重庆多车场 MDEVRPTW-DD（Wang et al., 2025）

来源：<https://www.mdpi.com/2071-1050/17/6/2700>

- 业务背景：重庆实际网络案例。
- 公开正文描述：4 个 depot、151 个客户（101 个静态、50 个动态）、13 个充电站；另有从 NEO MDVRPTW 派生并加入充电站/动态需求的 30 个实例。
- 规模覆盖：表格中的客户规模包含约 48、96、144、192 等级，落入用户要求的 50--200 区间附近；真实案例为 151 客户。
- 模型元素：客户需求、服务时间、时间窗；EV 电池容量、充电速率；多车场和充电站。
- 文件字段：论文没有给出可下载 TXT/CSV/JSON 的字段名表，也没有公开坐标文件。因此坐标系、客户逐行记录、车辆逐车记录和充电站逐站记录均为“未验证”。

## 2. JD.com 北京 E-VRP-HC（Wang et al., COR 2026）

来源：论文页面 <https://www.sciencedirect.com/science/article/abs/pii/S0305054825004034>；可读 PDF <https://chairelogistique.hec.ca/wp-content/uploads/2025/05/Electric-Vehicle-Routing-with-Heterogeneous-Charging-Stations-1.pdf>。

- 业务背景：论文把真实 JD.com 数据描述为北京实例。
- 图表描述：1 个 depot、1500 个客户、100 个充电站；实例命名包括 `C1500_S100`、`C1400_S100`、`C1300_S100`、`C1200_S100`、`C1100_S100`。
- 模型元素：客户需求/服务时间/时间窗、EV 电池与充电；充电站技术、等待函数和价格由论文作者补充，因为 JD 原始数据不含这些字段。
- 文件字段：论文没有列出仓库原始文件的逐列 schema；坐标系、客户/充电站 CSV 列名、车辆容量和电池字段名均为“未验证”。
- 多车场：论文模型是单 depot；不能把图中的 1 个 depot 写成多车场。若作为 C31 基础，需要增加至少 1 个新 depot、分配客户/车辆并重新做可行性校核。

## 3. 可复用的非中国结构参照：2E-EVRP v2

来源：<https://zenodo.org/records/14844216>；数据文章 <https://www.sciencedirect.com/science/article/pii/S2352340925002021>。

- 页面实际列出 `2E-EVRP-Instances-v2.zip`，4.1 MB，页面 MD5 为 `30681ecabe17fb5498693da59e3de0dd`；Zenodo 权利页显示 CC BY 4.0。
- 数据文章明确写有两层、电动车、时间窗、卫星节点，以及 5、10、15、50、100 客户组；这是可作格式/改造流程参照的公开源。
- 但其地理分布是随机/聚类/随机聚类基准，不是中国真实地理；两层 satellite 语义也不能直接替代本文单层多车场定义。
- 本轮未把压缩包下载到工作区，因此上面的文件名和页面 MD5 不是本地 SHA-256。
