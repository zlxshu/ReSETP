## Frozen gate result

All six protected HGS-M witnesses replayed with zero violations and matched
their recorded v7 costs. The six workers scored the frozen panel of 96
non-iterative candidates per task. The final ledger contains 576/576 rows:
32 candidates passed common completion and independent full checking, while
544 had no feasible all-CV completion. No candidate was accepted or fed back
into any search.

Strict proxy-versus-full ordering inversions occurred in 3/6 tasks, below the
required 5/6. More importantly, the number of tasks with any strict
full-model improvement over the protected HGS-M witness was 0/6, versus the
required 4/6. Consequently, no task could contain a best improving candidate
missed by the proxy top eight, and no size tier qualified.

The feasible-candidate counts by action were: relocate 1/144, swap 9/144,
segment reversal 18/144, and tail exchange 4/144. This is diagnostic context,
not authority to modify the frozen action panel or reopen the stopped
feasibility-guided VNS family.

## Interpretation and boundary

The tested causal premise is rejected on the locked tasks: there is no
verified evidence that the current half-load/minimum-energy-price HGS proxy
is hiding nearby full-model improvements in this fixed action panel.
Therefore the proposed resource-coupled HGS path must stop before a
six-customer evaluator implementation or performance run. The result does
not prove that the HGS proxy is exact, nor that no better algorithm exists.
It only forbids using this specific proxy-misranking explanation to justify
another local-order education rescue on these tasks.

The protected three-view HGS remains unchanged as the fallback. This gate is
not paper-performance evidence, not a public BKS/SOTA result, and does not
authorize China81 full reruns, E3, or a new algorithm candidate.
