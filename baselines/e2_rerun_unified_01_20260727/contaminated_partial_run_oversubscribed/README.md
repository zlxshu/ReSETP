本目录保存 `E2-RERUN-UNIFIED-01` 首次正式启动产生的诊断现场。发现问题时进度约为
163 个尝试行；使用安全终止流程完成写盘时，共归档 165 个完整 `result.json`。

这些结果是在本批 6-worker 池与已被取代的 6-worker 收敛试跑同时运行、并伴有孤儿

超订使相同秒数对应的实际求解工作显著减少，并会不对称削弱 MV-HGS-SP 的重组质量。
因此这不是可校正的计时偏差，而是臂间解质量不可比。

判定、预算调整或正式批续跑。洁净正式批必须从空 `tasks/` 目录重新开始。
