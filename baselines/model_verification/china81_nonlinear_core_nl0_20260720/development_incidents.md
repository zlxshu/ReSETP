# NL0 开发期失败留痕

以下两类失败发生在正式五记录面生成前，均未运行搜索、未改保护文件，也未改变冻结输入
或验收口径。

1. 首次直接用系统 Python 收集测试时，仓库包路径未加入 `PYTHONPATH`，测试在导入
   `setp_solver` 前失败。按仓库既有方式设置 `PYTHONPATH=solver/src:.` 后重跑；没有
   为该环境错误修改源码。
2. 首版新内核对相邻断点数组使用了 `zip(..., strict=True)`，但把完整数组与去掉首项
   的数组相配，测试在构造曲线时正确失败。修复为相邻切片或非 strict 相邻迭代；随后
   24 项目标测试和 264,600 条冻结动作全量复核通过。该错误没有进入任何正式求解或
   证据结果。
