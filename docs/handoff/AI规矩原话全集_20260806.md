# AI 工作规矩：用户原话全集

日期：2026-08-06  
性质：原话证据册，不是代理改写的规则摘要。

## 一、收录规则

1. 引号内只放从原始对话中核到的用户原话；不修病句，不统一大小写，不替换标点，不把口语润色成书面语。
2. 同一句话同时含规则、任务和判断时，整句保留，不擅自截成更“漂亮”的规则。
3. 互相冲突、后来改变、今天看来不妥的原话照收。是否仍有效，另行裁决；本册不偷偷删掉。
4. 代理在交接文档、总结或规则文件中的概括，不算用户原话。能找到原始对话的，以原始对话为准；找不到的，放入“待核原文”，不得加引号冒充。
5. 本册所称“全集”，范围是已经检出的、会持续影响 AI 工作方式、科研判断、实验、写作、授权和交接的用户原话；不是把所有寒暄、一次性命令和整段聊天无差别复制进来。
