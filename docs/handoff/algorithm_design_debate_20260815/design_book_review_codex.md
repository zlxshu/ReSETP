# 整车设计书对撞审查（Codex）

审查对象：`docs/handoff/algorithm_full_design_20260816.md`。对照材料为体裁标尺、算法章程、P63/P65/P66 决定册、设计对辩记录、设计期探针和当前源码。审查只做文档核对、只读代码核对和联网文献核对，没有运行求解器，没有改代码、算例或三个受保护文件，也没有加载旧 `china81_finite_fleet_authority` 系列。

总体结论：**改，暂不过呈。** 图纸的主骨架可以保留：一本钱账、串行教育链、C2 下层补全、C7 先软后硬、C6 作为第二段施工件、两条条件命题以及开跑前预注册的 F1 档案。当前不能直接呈现的不是“方向错误”，而是四类混写：目标架构写成了现行实现；简化模型命题写成了完整成本模型的机制保证；C7 还没有把平局、指标缺失和分法作用边界定义完；复杂度、参数和文献页码没有全部达到可复核程度。

## 2. 数学核验

### 2.1 命题 1、1.472 和探针锚点

**判定：数学推导过；与完整代码的连接改。**

在“同一段固定电量整体从时段 a 搬到时段 b，其他项不变，且不触发碳配额截断”的前提下，图纸的差分

`(p_b-p_a)E - κ(g_a-g_b)E`

和条件 `p_b-p_a < κ(g_a-g_b)` 是对的。数值也对：`0.7921-0.3182=0.4739`，`0.3574-0.0355=0.3219`，`0.4739/0.3219=1.472196...`，所以写成 `1.472` 合理；用设计书的 `κ=0.075` 计算约为 `19.63` 倍，写“约 1/19.6”合理。探针的 1,775 条评价全部没有优于父代，最小总评价变化 `+5.9290209103`；碳分量最多省 `0.5787670425` 元，非碳分量至少涨 `6.0031048752` 元。这些数字支持“现价下独立择时通道算术上不赢”，不支持更广的“所有充电策略都不值得做”。

**证据（探针）：** `solver/reports/design_probe_timing_diag_20260815/report.md:65-82`；该报告还明确把独立择时提案退役，保留 C2 策略对照和碳价扫描。

需要改的不是命题本身，而是 A1 的映射。当前 `cost.py` 的总账包含固定、距离、燃油、电费、占用、时间、转运和碳成本；碳成本还按配额条件计算。设计书只写 `C_fix+C_dist+C_energy+κE`，并把 `cost.py:209-213`当成现行口径，既漏了若干项，也没有写 `max(E−quota,0)` 的条件。应改成：命题 1 是“其他成本项和配额状态不变时的局部差分”，不是直接从完整 A1 无条件推出。

**证据（代码）：** `solver/src/setp_solver/cost.py:170-225` 给出实际总账；`cost.py:221-224` 给出碳配额条件；设计书现有写法见 `algorithm_full_design_20260816.md:58-80`。

### 2.2 命题 2、68.1/86.8/125.5 和实际能耗

**判定：数值锚过；全模型机制表述改。**

在 `ΔC(d)=ΔF−δ(τ)d` 且 `δ(τ)>0` 的线性简化下，`d*=ΔF/δ(τ)`及“`d>d*` 时 EV 更有利”的推导成立。当前冻结日复算得到 68.1、86.8、125.5 km，脚本明确登记了三档阈值，重建报告也明确说明正式搜索证据仍为 0；因此这三个数字可以作为设计锚，不能写成正式车队结果。

**证据（代码/探针数字）：** `solver/scripts/run_mechanism_validation_v3_step_c.py:41-46`；`solver/scripts/build_private_instance_rebuild_20260811.py:1174-1176`给出阈值的固定成本溢价除以单位里程节省；`solver/reports/instance_rebuild_20260811/report.md:73-90`明确写出三档值和“正式实验没有启动”。

当前完整成本不是只按日里程线性累加：源码按每条弧的载重、路网弧指标、速度/时间和车辆类型计算燃油或 EV 驱动能耗。因此，`|d−d*|`可以作为 C4 的事前搜索偏置和效应观测框架，但不能被称为完整模型下的排序定理。图纸第十一章已经写了命题 2 的线性假设，但第六章把它直接写成 F1 排序规则，仍需加“简化模型偏置，最终以完整评价器复核”。

**证据（代码）：** `solver/src/setp_solver/cost.py:303-358`显示能耗随弧、载重、路网和车型计算；设计书的命题和 C4 用法见 `algorithm_full_design_20260816.md:83-91,144-147`。

### 2.3 式 A1–A3 与 `population.py:140-235`

**A1：改。** 现行代码的精确映射应先列出八个成本分量，再说明哪些被论文记为 `C_energy`，并写清碳配额。否则 A1 不是“照现行实现写成公式”，而是一个尚未定义分组的摘要式目标。

**A2：部分过，新增部分改。** `population.py:154-185`确实按违规类型维护自适应罚系数，`:187-201`确实按违规幅度加权到总成本；这支持图纸的“按类型自适应”与罚分公式。可是当前代码不会凭空生成 `CHARGING_GAP` 或 `PARTICIPATION`，这两个类型必须等新的评价对象和装配路径接上后才成立。不能把未来接线写成现行实现。

**A3：过。** 当前 `DutyPopulation`按 `evaluation.feasible`分入可行/不可行池，图纸对双子种群的核心描述与代码一致；但“按 Φ 与多样性生存”的具体生存函数仍应给出当前调用入口或标为复用现有实现，不能只写概念名。

**证据（代码）：** `solver/src/setp_solver/algorithms/problem_hgs/population.py:140-201,204-235`；设计书 `algorithm_full_design_20260816.md:61-69`。

## 3. C7 对照用户原话

### 3.1 三个要点逐点核对

**① 分法不预先固定：部分兑现，需改实验口径。** 设计书把规则集 `R`作为候选集合，并声称开跑时不固定，这对“分法是决策变量”的方向是忠实的。但用户已经拍板：主两车场公平章报一种分摊方法，分法选择实验放到四车场，而且两者递进、不是并列。图纸现在在 C7 主段直接把四种分法全部放入 `R`，会把主两车场和四车场的实验合同混在一起。

**证据（用户决定/设计）：** `pending_decisions.md:396-415`；设计书 `algorithm_full_design_20260816.md:168-182`。

**② 模拟中挑：形式上兑现，定义还不够。** 对每个候选解把所有规则逐一评价，确实是“候选分法枚举后选择”的可复算版本。但 `Shapley/核仁`被写成一个合并条目，不是一个规则；`c({i})`、合作成本 `c(N)`、收入/成本是否含转运和碳配额也没有闭合；规则评价是一次账本计算还是要重新求路线，也没有写清。没有这些定义，“跑一遍遍模拟”的含义仍有两种解释。

**③ 分法反作用到路线：只在硬期部分兑现。** P66-5 已定开发期只观测、不约束，所以软期“只记账”不是违反用户原话，而是用户批准的施工顺序；但图纸必须明说这段尚未兑现③。硬期把最小参与违约放入搜索评价，确实会让路线避开让某企业低于单干的解；如果所有分法参与违约都为零，第二级只在分法之间破平，当前写法没有让“公平度指标”反过来影响路线。也就是说，当前硬期实现的是“参与可行性反作用”，还不是“所有公平目标都反作用”。

**证据（用户决定/代码）：** `pending_decisions.md:809-813`规定先软后硬；当前公平代码只是固定 `theta` 的 `PROFIT_FAIRNESS` 检查，见 `solver/src/setp_solver/check.py:39-42,1225-1265`和 `solver/src/setp_solver/search/evaluation.py:93-122,161-185`；设计书的反作用声明见 `algorithm_full_design_20260816.md:165-178`。

### 3.2 内层两级选择是否良定义

**判定：不过。** 目前只定义了“先最小参与违约、零违约再按公平指标破平”，还没有定义以下情形：

1. 最小违约量大于零时出现多个规则并列，是否保留并列集、按效率破平，还是报告“无可行公平分法”；
2. 公平指标是 `ΔGini`、IR 还是子联盟稳定性，当前仍是 OPEN；指标方向、量纲和比较顺序没有冻结；
3. 指标缺失、不可计算、NaN、子联盟样本为空时，候选是淘汰、记为不可比，还是退回固定分法；
4. 多个规则指标完全相同或两企业规则数值天然相同时，如何保证确定性；
5. “Shapley/核仁”必须拆成两个规则并给出各自可计算接口；
6. 图纸写的转归集 `I`遗漏了 `0≤x_i`，而决定册给出的定义包含这一条件；同时应定义收入、成本、转运和碳成本进入 `c(N)` 的口径。

**证据（决定册/代码/文献）：** 转归集的原始定义见 `pending_decisions.md:435-442`；设计书当前公式见 `algorithm_full_design_20260816.md:180-182`；联网核到的 Rodríguez-Pereira 等 2026 文章确实讨论 Gini、Shapley 和稳定性，但网页摘要不能替代图纸声称的 Table 12 页码，见 [Bath 原始论文记录](https://researchportal.bath.ac.uk/en/publications/a-comparison-of-cost-sharing-models-in-horizontal-cooperative-rou/)；Table 12 的页码当前仍是 `UNKNOWN`，不能把它写成已经完成的页码核验。

### 3.3 四车场实验的两笔账

**判定：过，且必须保留“不是正式结果”这句话。** 图纸记的两笔账是对的：六个旧候选是按旧的“可争夺最高”标准选的，尚未按 P65-3 的一阶协同收益新标准重排；此前“联合成本等于四场单干之和、差为 0”来自不跨车场重指派客户的拼接见证，不是联合优化已经证明没有协同。它只能作为实验前需要复核的历史口径，不能作为四车场机制无效的证据。重选与否由用户届时拍板，图纸没有越权替用户拍板，这一点保留。

**证据（当前事实）：** `CURRENT_PROJECT_CONTEXT.md:196-205`；设计书 `algorithm_full_design_20260816.md:184-191`；同一份候选报告也明确 formal search 为 0，见 `solver/reports/instance_reselect_synergy_20260815/report.md:41-47`。
