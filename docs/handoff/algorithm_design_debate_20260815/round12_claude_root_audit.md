## 一、疑点 A 判：清白（`FACT`，行号在手）

P31 用户令"完整成本进搜索/入群/生存/父代选择"。实核：

- **生存**：`ExternalPopulation` 按 `penalised_cost` 回调排序做偏置适应度
  （`ExternalPopulation.py:144,155,237-263`）；我方传入的是
  `complete_penalties.cost(full)`＝**完整模型成本＋违规罚**（`integrated_private.py:439,887`）。
  可行解罚为零 → 生存就按**真实总成本**。
- **best**：内核 `_best()`＝可行池优先（`IntegratedGeneticAlgorithm.py:228-232`）；
  `_better()` 可行严格支配不可行（`:243-251`）；可行时按 `adapter.objective`＝真值。
- **父代选择**：二元锦标赛按同一偏置适应度（`ExternalPopulation.py:167`）。

**即：只要一个 EV 解是可行且真值更便宜，它必然成为 best。** 三次终解全无 EV，
逻辑上只剩两类解释——**EV 改善从未以"可行"身份存在**，或**存在过但活不过种群动态**。

## 二、根错嫌疑收窄到两处（等你的追踪，我不猜死）

**嫌疑 B（我现在最重）·教育接受语义**：`search_cost` 在修复臂用
`total_cost + repair_booster × violation_cost`（`integrated_private.py:957-965`）——
booster 会**接受带违规的 EV 改善**去修，但若修不干净，它们只能进不可行池，
永远不参与 best 竞争。你查的"28 次接受、真值省 1358 元"**如果全是不可行身份**，
则一切自洽：接受是真的、省钱是真的、零保留也是必然的。
→ 追踪只需回答一个字段：**那 28 次接受时 `feasible` 是 true 还是 false**。

**嫌疑 C·交叉稀释**：解码器按父代车型提示分配槽位（你引过 `hybrid_decoder.py:940-945,1017-1025`）。
种群 24/25 是 CV 时，EV 个体每轮被交叉，子代大概率解回 CV——
**少数派基因在无保护机制下的标准灭绝动力学**。若 B 不成立而 C 成立，
处置方向完全不同（那是多样性管理问题，Vidal 的种群本有多样性项，但它保护"结构差异"
不特别保护"车型差异"）。
