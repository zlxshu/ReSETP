## 目标（一句话）

把 copied 路线内核从"按代理连续自走到局部最优"改造成
**"代理只产出有界 promising 候选，完整真值逐个评价并拍板执行谁"**——
让一本钱账第一次指挥局部搜索的每一步。

## 设计要点（提案，怎么实现你定）

1. **候选生产**：内核 local search 改为产出 top-λ 候选表（按代理增量排序），不就地执行；
2. **真值拍板**：候选表交现有 `DutyIncrementalEvaluator`（或你判断更合适的现成件）算完整成本
   与可行性，**按真值选一个执行**；证不出改善的不执行；
3. **λ 与调用频率**：你说得对——**不能照抄 Goeke 的 50**，用本机短探针标定
   （P88：最短能判定即停；探针只看吞吐与真值命中率，不下性能结论）；
4. **完整评价的开销现实**：这会显著增加真值调用次数——SC-V2 缓存已在、D2 已修、
   内存已治，但**若探针显示不可负担，如实停下**，把"每圈真值预算"作为标定量摆出来，
   不硬扛也不偷偷降级回代理；
5. **默认开关纪律**：新边界走独立开关，**默认关＝与当前行为逐位一致**（保住全部既有基线）；
   开启＝新语义。默认何时翻开属结构冻结清单（届时随 S5 一起交用户）。
