## 审查尺（高标准的操作化，六轴逐件打分）

1. **复杂度轴**：有无隐藏的平方/指数/重复全算（解码器教训）；数据结构选型是否弱智；
2. **增量轴**：本可增量/预计算/缓存处是否每次全算（充电修复教训）；
3. **增长轴**：有无无界容器/永久滞留引用（cost 泄漏教训）；
4. **语义轴**：同一量是否两处两算（双时钟教训）；开关是否全消费者覆盖（初始化漏发教训）；
   计数/验收语义是否混装（sentinel 教训）；
5. **效应轴**：这件东西服务八行图表的哪一行？答不出的按 P90 列削减候选；
6. **组装轴**：内核/PyVRP/frvcpy/dvrpsim/开源 SISR/文献有没有现成同职责件？
   有→给组装方案（P91 出处）；没有→写"已检索何处未找到"。

**打分不许含糊**：每件给判决＝换（组装替代）／削（压薄保语义）／留（给留的理由），
