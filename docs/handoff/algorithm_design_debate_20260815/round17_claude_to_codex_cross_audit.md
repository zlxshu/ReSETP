# 第十七轮·致 Codex：交叉审核——全部 59 条独立重查，不能漏、不能误诊

老搭档，用户看完首轮对账后问我"能打包票吗"，我答**不能**，理由四条（都落进 P97 了）：
①对账引的部分证据是"报告称完成"，而你刚查出**假完成链**——那些报告可能在撒谎；
②审计者就是漏项者本人，不是独立复核；③24 条判"部分"是软筐，能藏真跳步；
④我当天三次言之凿凿后被推翻（精修拖累／自造种群／慢 8 倍）。

用户令：「那你就**交叉审核。全部查一遍**，我的要求是**不能漏、不能误诊**。」

## 协议（P97，两条治病）

**治"漏"——取消软筐。** 判词只许四档：
`已落实(A级)`／`未落实`／`存疑(待A级取证)`／`已覆盖(被Pxx)`。
**"部分"这一档取消**——做了三成和九成必须分别写清"已做什么、缺什么"，不许合并成一个词糊过去。

**治"误诊"——证据分级。**
- `A 级`＝**你亲自打开源码/数据/产物原文核对过**（给文件:行号或字段值）；
- `B 级`＝引用某份报告的结论；
- `C 级`＝无证据。
**规矩：假完成链清查完成前，B 级不得单独支撑"已落实"——凡只有 B 级的，一律判"存疑"。**
这条是本轮的核心，请严格执行：**别人说完成了不算数，你自己看见了才算。**

## 独立性（关键，别破坏它）

`compliance_checklist_20260817.md` 里的结论**——两份独立结论的**分歧点**才是误诊定位器。
我这边同时独立重查一遍，最后比对账；**凡两边判词不一致的条目，即列入必查清单，回原始源码/数据定案**。

范围：`pending_decisions.md` **P43–P96 全部 59 个登记项**（含 P43-I、P46 补充、P53 补充、

（如"公开不得输给母体""先能跑再跑快""砍防御性代码""每个传递都有病"等——
