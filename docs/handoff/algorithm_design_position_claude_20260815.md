**传导（本设计的实体，不是修辞）**：
1. 提案域用真约束（G1 开关）——上层不再提出下层必死的候选；

3. **交叉降层**（见下）——重组产物由补全栈负责变成完整可行 Duty；
4. 预筛结论回流：预筛拒绝率按通道统计，供通道的提案生成器收缩邻域（`OPEN`：具体机制待对辩）。

**明确不做**：`time_varying_carbon_charge` 不再作为独立提案通道（两探针合计 3,064 提案 **0 接受**；
P44 一本钱账下它按算术就赢不了——碳价 0.075 时择时省的碳钱 < 电价差损失）。

它在搜索循环里，只是不再作为竞争性提案通道）。`SCOPE`：这不动模型、不动评价器，只动搜索配置。

**并行线（公开侧，两手抓另一手）**：先补种子测量（28 题多种子是唯一能回答"到底赢没赢"的动作，

**风险清单（最可能翻车处）**：
1. 路线层交叉解码成本：每个后代过补全栈，若单次解码≈秒级则交叉吞吐塌方——先用 30 秒吞吐门杀；
2. 统一算例上 EV 迟迟不出现：A2 快模式 2 循环终解 10CV/0EV/0 充电、成本改善 0.0——
   `BOUNDARY`：2 循环无结论（DEPOTSWAP 同预算 2 循环曾出 3EV 解），但**必须列为观察哨**，
   若成型算法长跑仍 0 EV，按"先证算例作用空间、再查算法"的既有规矩分诊，不得直接改算例；
3. 秒/循环：新算例快模式实测约 175 秒/循环（349.7s/2 循环，A2）——比 GZ-FS 的 59.85 慢近 3 倍，
   收敛标定前必须再做一轮提速或预筛收缩，否则 P47 标定本身跑不起；
4. 外置盘负载噪声（P43-K）：全部对照同批次净机，探针数字永不跨批次比较。
