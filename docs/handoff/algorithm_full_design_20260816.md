**本算法以复制并独立编译的 HGS 路线搜索为主体，通过 ①真约束提案域、②充电—排程子问题求解与缺口罚分、

## 第二章　问题形式化接口与评价数学（审查硬伤 1 已修）

### 2.1 式 A1：一本钱账（照 `cost.py:170-225` 实际实现逐项列出）

F(S) = C_fix + C_km + C_fuel + C_elec + C_occ + C_time + C_trans + C_carbon

| 项 | 含义 | 代码出处 |
|---|---|---|
| C_fix | 实体车日固定成本（CV 170／EV 220） | `cost.py` cost_fix |
| C_km | 按车型的非能源里程成本（EV 0.9145 含电池折旧） | cost_km |
| C_fuel | 燃油推进成本 | cost_fuel |
| C_elec | 充电电费（按实际充电时刻分时计价，30 分钟槽分摊） | `_charging_electricity_cost` |
| C_occ | 公共站占用费（车场充电无此项） | `_charging_occupancy_cost` |
| C_time | 路线时间成本＝route_time_seconds/3600×单价 | `_e5_route_time_seconds` |
| C_trans | 跨场服务费＝跨场次数×`cross_site_cost`（P12 已定 c^tr=0，故当前恒为 0，但公式保留） | cost_transship |
| C_carbon | **(E − Q)·κ**，Q＝碳配额；**Q=∞ 时该项恒为 0** | `cost.py:221-224` |

其中 E ＝ e_cv_direct + e_ev_indirect（燃油直接排放＋充电间接排放，P44 合并计价）。
**注**：Q 为常数，不改变解之间的排序；但公式须如实写出，不得简写为 κ·E。

### 2.2 式 A2：搜索用罚分评价（现行实现，`population.py:140-201`）

Φ(S) = F(S) + Σ_v ω_v · m_v(S)；v 遍历违规类型，m_v＝该类型违规幅度之和。
ω_v 按类型自适应：每 U 个解统计该类型可行占比 f_v，与目标带比较后 ×升/降因子，截断于 [ω_min, ω_max]。
**当前已存在的类型**：TIME_WINDOW、BATTERY、CHARGING_POWER、PROFIT_FAIRNESS（固定 θ 检查）等，
由 `check.py` 产生。
**本设计拟新增**：`CHARGING_GAP`（C2）、`PARTICIPATION`（C7）——
**⚠️ 二者是目标架构，当前代码不产生这两个类型**（审查硬伤 2/4）。
纪律：Φ 只用于搜索排序与生存；**最好解只能取自完整可行解，按 F 报告**。

## 第三章　两个可证明的模型性质（模型性质，非算法收敛保证）

**命题 1（充电时移的碳价盈亏平衡；局部差分性质）**
*前提*：一段固定电量 E 的充电整体从时段 a 移到 b；**F 的其余七项与碳配额状态均不变**；
电价 p、碳强度 g。则总账改善 ⟺ p_b − p_a < κ(g_a − g_b)，临界 **κ\* = (p_b−p_a)/(g_a−g_b)**。
*证明*：两案仅 C_elec 与 C_carbon 不同（Q 为常数抵消），差 = (p_b−p_a)E − κ(g_a−g_b)E，负即改善。∎
*数值锚*：夜谷(0.3182, 0.3574)→13:00(0.7921, 0.0355) 得 κ\*=0.4739/0.3219=**1.472 元/kg**；
现行 κ=0.075 为其 **1/19.6**。
*解释力*：探针 T 的 1,775:0（碳最多省 0.5788 而非碳至少涨 6.0031）与之同向同量级。
*边界*：这是"其他项不变"的局部差分，**不是完整模型下的无条件定理**；跨窗拆分时为逐段求和形式。

**命题 2（车型临界里程；线性简化模型性质）**
*前提*：EV 相对 CV 日固定成本溢价 ΔF>0，单位里程可变成本差 δ(τ)>0 **视为常数**。
则换 EV 改善 ⟺ d > **d\* = ΔF/δ(τ)**。*证明*：ΔC(d)=ΔF−δ(τ)d 线性单调。∎
*数值锚*：68.1/86.8/125.5 km（谷/平/峰）；统一算例见证日里程 72.2–254.4 km 横跨该带（下/内/上 1/2/7）。
*边界（审查硬伤 7）*：**完整模型的能耗按每条弧的载重、路网指标、速度与车型计算
（`cost.py:303-358`），不是日里程线性累加**。故 d\* 只能作为 **C4 的事前搜索偏置与效应解释框架**，
**不得称为完整成本下的排序定理**；每个候选的接受一律回到完整评价（式 A1/A2）。
*承担的实验*：用户的"比较优势随条件切换"框架（P43-D）——方向由 d 与 d\*(τ) 的相对位置决定，
而 τ 由路线与班次决定，三实验在此耦合。

**C7 公平：参与约束（下层）＋分摊联立（上层）**

**原始意图锚（用户原话逐字，2026-08-14）**：
「算法在分配初期就不固定分法，哪个更公平更有效率，我就怎么分」；
「我全跑一遍一遍模拟，看看哪个分法最优，我就最后怎样作用到路径上，**使得最后的路径的分法一定是最优的分法**，
这是算法创新！……我的目的是让分法服务我的碳排放和成本，保证我的多车场既能维持下去又能赚到钱。」
三要点：①不预先固定分法；②模拟中挑；③**反作用到路线**。

**账目口径（审查硬伤 4，先定义再谈选择）**：
- c(N) ＝ 联合求解下的总成本（式 A1 的 F）；c({i}) ＝ 企业 i 单干基准（P28：只服务自己客户、
  用自己车辆设施，最终算法 10 种子取最好利润对应的成本），**冻结后方可用于硬期**；
- x_i ＝ 分摊给企业 i 的成本；转归集 **I = {x : Σ_i x_i = c(N), 0 ≤ x_i ≤ c({i})}**
  （饶卫振 2019 印刷 p.1524；**V1 漏写 0 ≤ x_i，此处补回**）；
- 参与违约 v_i(S,r) = max(0, x_i(S,r) − c({i}))；规则评价**只做账本计算，不重求路线**。

**分法规则集 R（拆开，各自可计算接口）**：r1 均分（equal division，P63-4 术语）／
r2 按送货量比例／r3 按单干成本比例／r4 Shapley 值／r5 核仁。**r4 与 r5 是两个规则，不合并**。

**内层选择（良定义版，审查硬伤 4）**：对候选解 S
1. 计 V(S,r)=Σ_i v_i(S,r)，取 V 最小的规则集合 R\*；
2. **若 min V > 0**（无规则能让所有企业不亏）：保留 R\* 全体，记候选为"参与不可行"，
   按 V 值进入 A2 罚分（不淘汰），报告 R\* 与 V；**不做公平指标破平**；
3. **若 min V = 0 且 |R\*|>1**：按**一个开跑前冻结的公平指标**破平（候选指标：ΔGini／IR／
   子联盟稳定性，出处 Rodríguez-Pereira 等 2026, *TR-E*，**Table 12 页码 `UNKNOWN` 待核**）；
   `OPEN`：指标选哪个、方向与量纲，**带文献交用户拍板**，代理不自定；
4. 指标不可计算/缺失/NaN/样本为空 → **退回固定规则 r1**，并在运行记录标记该次退回；
5. 仍并列 → 按规则编号升序破平（确定性保证）。

**反作用机制（兑现③）**：硬期把 min_r V(S,r) 以 `PARTICIPATION` 类型计入式 A2，
即求解 min_S [ F(S) + ω_P·min_{r∈R} V(S,r) + 其他罚项 ]——
**分账摆不平的路线在搜索中被扣分，分法由此改变路线胜负**。
`SCOPE`（审查已指出，如实写明）：硬期实现的是**参与可行性反作用**；
"公平指标本身反作用到路线"仅在零违约并列时通过破平间接生效，**不是全目标反作用**。
软期（P66-5 已定顺序）只记账不扣分——**该期不兑现③，是用户批准的施工顺序，非设计缺失**。

**实验口径（V3 施工书异议 D.1 采纳后的改写，遵 P67-4＋P63-1，两条同时成立）**：
- **选择接口处处运行**（P67-4：「本身算法就是挑最优秀的分法报」是算法的**常态行为**，不是特设实验）——
  主算例两车场上它照常运行，只是 r1/r4/r5 等必然同值（Modica p.3 等三处页码级证据），
  选择自然退化，**报告呈现一种分法**（P63-1 得到遵守：报一种 ≠ 只算一种）；
- **分法选择实验（珠三角四车场）**：规则差异在此可见，作专项对比与论述；
- 两者递进，不并列。
**开工前提（两笔账，缺一不开跑）**：①现有四车场六例（`china81_suite_v3_20260812` prd 150c/200c）
按旧判据（可争夺最高）选出，未按 P65-3 新判据重排；②此前"联合＝四场单干和、差 0.000000"

**该实验开工前须按新判据复核/重选并实测一阶空间；重选与否由用户届时拍板。**
