先证作用条件存在，再谈算法与调参。

### 2.3 算法层（真正的算法问题，只有一条链）

慢 → 跑不到收敛 → 看不出行不行 → 定不了预算 → 一切正式实验开不了跑。

慢的解剖（本轮全部查实）：
1. **解码器指数枚举**（主因之一，已证）：块长 b 的燃油车块终点标签 `2^(b-1)` 个；
   支配规则要求"严格更小"而同切点标签时间相同、燃油车能量恒为 0 →
   **完全相等的标签一个都删不掉**，两两扫描最坏 `Ω(4^b)`；
   且标签保存的历史**下游根本不读** → 数学上冗余 → 可无损改写为 DAG/前驱链（**重写在途**）。
   文献参照：Prins 2004 `O(n²)`、Vidal 2016 `O(n)`——**我们把多项式问题写成了指数**。
2. **充电修复不增量**（另一主因，P76-1 profile 实证 92%）：动一趟重解整车整日。
   处置分两路：甲安全缓存（逐位）／丙下界剪枝（改语义）——**P78 用户保留，冻结中**。
3. 历史上还有：教育过深（SC10 已给开关）、初始化慢（SC0 已修）、D2 重复探测（已修）。

**方法论结论（前瞻性最重要的一句）**：瓶颈是**分层**的——SC10 把圈数从 11 放到 441，
解码爆炸才第一次显形。**每修掉一层，必须立刻在新深度重新剖析**，否则下一层永远看不见。
