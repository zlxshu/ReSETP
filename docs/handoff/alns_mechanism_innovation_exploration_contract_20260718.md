# ALNS 分机制创新探索合同

## 授权边界

用户于2026-07-18明确授权代理自主探索、尝试和形成备选方案，包括检索高性能开源算法/算子、追溯文献算子、设计精细的新算法或算子、建立隔离原型和运行非正式性能探针。用户保留最终批准权；未经批准，任何候选不得合入正式ALNS入口、不得写入正式实验合同、不得用于E1--E7正式重跑，也不得形成论文创新主张。

探索产物必须标记为`EXPLORATION_ONLY_AWAITING_USER_APPROVAL`。每个候选至少记录问题机制、算法思想、原始论文、开源仓库与许可证、移植位置、与标准ALNS的差异、预期收益、计算复杂度、预算记账方式、失败风险、隔离探针结果和用户裁决状态。

## 研究计划

研究按五个与论文机制一一对应的主题并行进行，每个主题至少完成两轮：第一轮广泛检索论文和开源实现，建立候选地图；第二轮针对缺口核对原论文、代码、许可证和适配条件，并设计最小隔离探针。

第一主题是混合车队与补能联合决策，目标是增强车型选择、路线—车辆联合修复、充电站插入、SOC可行修复和非线性充电。优先找已在EVRP/EVRPTW上验证的联合邻域、标签算法、充电重排和资源约束最短路组件。

第二主题是多车场合作与责任重划，目标是增强跨车场客户交换、责任边界重构、车场负载均衡和货物/车辆共享。优先找MDVRP、协同VRP和location-routing中的跨场破坏修复、ejection chain、route-pool set partitioning与large neighborhood。

第三主题是时变碳和分时电价，目标是把碳—价冲突从简单参数权重提升为可单独识别的时间调度机制。优先找time-dependent EVRP、charging scheduling、resource-constrained shortest path、动态电价和碳感知充电中的精确子问题或高效局部算子。

第四主题是参与公平，目标是让个体理性约束在搜索中可达、可激活且不靠事后筛选。优先找profit-sharing、epsilon-constraint、lexicographic acceptance、feasibility pump、Lagrangian/penalty adaptation和公平协同路由的公开实现或可复现算子。

第五主题是动态滚动重规划，目标是增强事件到达后的稳定性、响应速度、路径扰动控制、动态责任重分配和碳调度。优先找dynamic VRP、rolling horizon、request insertion、route freezing、regret/ejection和online ALNS的高性能实现。

## 证据优先级

最佳候选是“原始论文方法明确、公开代码可读、许可证允许研究复用、与本模型机制匹配、可在统一完整评价预算下独立消融”的算子。只有论文无代码时可以重实现，但必须逐式追溯；只有代码无论文时只能作工程候选。自主创新候选必须写出它解决的具体模型难点、与近邻方法的区别和可证伪消融，不能只换名字或调参数。

## 探针纪律

E7清洁重跑结束前，禁止修改`winner.py`和其他受保护核心。所有探索代码进入独立目录，不由正式runner导入。探针先做预算0/1/2/5、可行性、活性和小样例速度门，再做固定开发集；不得触碰Solomon正式测试集或中国正式81实例结果。候选比较必须使用真实完整评价计数，G0未闭合前只能做功能/活性探针，不能宣称性能胜负。

## 用户审批包

每个主题最终交付一个候选排序包。代理推荐不得自动实施。用户可以逐项批准“继续原型”“进入机制门”“合入正式ALNS”或“拒绝”。批准记录统一进入`docs/handoff/model_change_approval_register_20260718.md`，实施后再更新HANDOFF、memory、代码测试和实验五记录面。
