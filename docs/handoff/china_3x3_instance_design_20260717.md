# 中国 3×3 算例设计预注册（C31 历史探针）v1

> **当前主集已改为 81 个算例。** 本文件只保留旧的 3 区域×3 规模探针设计和历史记录；当前 10/15/20/25/50/75/100/150/200 客户、每档 01/02/03 变体、车场数 1/2/3 的权威合同见 [`china_81_instance_design_20260717.md`](china_81_instance_design_20260717.md)。旧 C31 目录不得与 81 集混表。

状态：2026-07-17 用户已拍板方向；本文件是**预注册设计**，在任何优化实验接触这些算例之前写死生成规则。数据可得性探针（任务 D）和用户终审后出 v2 冻结版。本文件不改变 E7 收口、G0、NL 内核的既定顺序；C31 集的正式采纳点 = 非线性统一重跑（届时替代英国坐标系的 L-main v2 成为主场景算例）。

## 1. 决策背景（2026-07-17 用户裁决链）

1. 保持完整科学链条（NL->NL 与统一重跑不砍）。
2. 主场景转中国。字面"全国算例"被否决：模型物理（90 km/h 当日班次、80 kWh 电池、单日 48 槽碳曲线、实体车多趟）不支持跨省数千公里网络。
3. 等价设计 = **3 个电网原型区域 × 3 档规模**，"全国代表性"由北/南/西三种电网原型承担。
4. 英国轨退役为留档对照：数据与已封存结果不删、不重跑、不进新主线表。
5. 算例几何允许风格化（Solomon 口径：VRP 界接受人造坐标），但**碳曲线与价格是处理变量，必须保持官方/发表来源**。
6. 先搜公开中国算例（任务 C），找到满足四要素（多车场+EV+充电站+时间窗）的公开集则优先复用；否则按本文件自建。

## 5. 生成与验收流程（顺序硬性）

1. **探针**（任务 D 前半）：三区域逐要素查数据量（POI 数、充电站数、园区数），出可得性判决；任何区域不足则回本文件改选区域，不得静默换。
2. **草稿构造**（任务 D 后半）：按第 3、4 节规则生成 9 个 DRAFT 算例（文件与目录显式标注 DRAFT），零优化搜索；结构自检（客户数、时间窗合法性、车场/站坐标真实来源登记、同一 schema 通过现有实例读取器）。
3. **结构门**：现有检查器 warm start 零违约可行性探针（允许小预算构造性检查，不作性能结论）。
4. **用户终审**：用户看草稿地图与参数表，拍板 v2 冻结。
5. **正式采纳**：只在 NL 统一重跑批次；与旧 L-main 结果永不混表。
