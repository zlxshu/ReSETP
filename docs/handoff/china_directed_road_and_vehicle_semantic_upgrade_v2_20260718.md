# 中国有向道路矩阵与车辆物理语义升级设计

**状态：** `DESIGN_FROZEN_IMPLEMENTATION_WAITING_FOR_E7`  
**原因：** 当前求解器只有距离矩阵，并在成本、检查、充电、排班和动态重规划中统一用 `distance / 25 m/s` 计算时间。仅把欧氏距离换成有向道路距离，仍不能实现正式道路旅行时间，也会继续沿用英国/Goeke 固定 90 km/h 的物理口径。

## 1. 不能只增加一个 duration 文件

正式中国道路语义至少需要三张同路径矩阵：

| 矩阵 | 单位 | 用途 |
|---|---|---|
| `road_distance_m` | m | 里程成本、滚阻能耗、路线长度 |
| `road_duration_s` | s | 时间窗、到达时间、服务排班、动态响应 |
| `road_speed2_distance_m3_s2` | m³/s² | 沿最快路径逐道路段累加 `v² × d`，用于空气阻力能耗 |

三张矩阵必须来自同一条“最短旅行时间”有向路径，不能分别求最短距离和最短时间后拼接。道路段速度优先使用可解析的 `maxspeed`；缺失速度的道路等级默认值必须在正式搜索前由中国法规、路由方法文献或公开路由器配置冻结。当前探针中的道路等级速度只是技术假定。

## 2. 为什么需要第三张矩阵

对一条由多个道路段组成的路径，若每段长度为 `d_e`、速度为 `v_e`，则：

`D = Σ d_e`  
`T = Σ d_e / v_e`  
`S = Σ v_e² d_e`

平地、分段匀速时的机械能可精确聚合为：

`E_mech = 0.5 c_d ρ A S + (m_curb + load) g c_r D`

EV 行驶电耗为：

`E_EV = α_e E_mech / 3.6e6`

CV 的 CMEM 油耗还包含发动机摩擦空转项，因此同时使用 `T` 和 `E_mech`。这个设计比直接采用 `D/T` 作为整段平均速度更严谨；后者会把交叉口、低速支路和快速路混成一个速度，并因空气阻力与速度平方相关而产生系统偏差。

本设计仍不声称有实时交通。`road_duration_s` 表示冻结 OSM 路网和冻结速度规则下的静态自由流/规则化旅行时间。

## 3. 有向性与货车限制

道路构图必须处理 `oneway`、环岛方向、道路类型和显式的 `access/vehicle/motor_vehicle` 限制。中国 OSM 对高度、重量、时段、通行证和地方货车限行覆盖不完整，因此正式报告必须把这些字段写成覆盖局限，不能声称已完整复现货车监管。

所有节点必须记录道路吸附距离和匹配 OSM node ID。车场使用核实后的货车入口，不使用园区质心；客户和充电站若吸附距离超门限则在正式搜索前淘汰并记录，不能在看到结果后替换。

## 4. 求解器统一入口

`Instance` 需要新增可选的旅行时间和道路能耗聚合矩阵，并提供唯一访问函数：

- `distance(from_id, to_id)`
- `travel_time(from_id, to_id)`
- `speed2_distance(from_id, to_id)`
- `road_arc_metrics(from_id, to_id)`

成本、检查、充电插入、固定路径重排、多趟排班、公平子实例、动态事件、证书执行和 ALNS 两套充电支持代码必须全部改用上述入口。禁止一部分模块读取 duration、另一部分继续 `distance / v_speed_ms`。

旧英国和国际公开基准 bundle 没有 duration 时，兼容层可显式使用其冻结 `distance / v_speed_ms` 历史语义；中国 V2 bundle 缺任一正式矩阵时必须 HALT，不能静默回退。

## 5. 车辆类型参数

中国混合车队不能继续共用一个全局 `Q_capacity`、`m_curb`、`A_frontal` 和 `B_battery_kwh`。每种车辆配置必须保存完整、不可拼接的：

`vehicle_type_id / fuel_type / payload_capacity_kg / curb_mass_kg / gross_mass_kg / frontal_area_m2 / battery_kwh / drivetrain_parameters / source_ids`

CV 与 EV 的载重约束、弧能耗和固定成本按实际分配的车辆类型读取。若现有路线对象只通过 `CV`/`EV` 字符串判断，升级时必须将车辆类型 ID 写入路线和证书，避免同一动力类型内未来加入不同车型时再次返工。

## 7. 验收

正式实现至少通过以下回归：

1. 有向非对称小图证明 `i→j` 与 `j→i` 可不同，单行反向不可达。
2. 三张矩阵来自同一路径，逐边重算与矩阵一致。
3. 旧 bundle 的兼容结果与封存哈希/复算一致。
4. 中国 V2 缺 duration 或能耗聚合矩阵时硬 HALT。
5. 成本、检查器、排班和动态事件对同一弧给出同一旅行时间。
6. 车辆类型载重和物理参数在 CV/EV 路线间正确分离。
7. 独立复算器不调用求解器成本函数也能重建油耗、电耗、到达时间和违规数。
