# 中国主线全实验切换与英国轨退役合同

**状态：** `PRE_REGISTERED_WAITING_FOR_E7_AND_CHINA_V2_GATES`  
**生效边界：** 当前 E7 清洁重跑及其科学收口完成后生效。  
**目的：** 将 E1–E7 的正式主实验统一切换到中国 V2 数据和模型口径，同时完整封存英国历史证据，避免跨国家、跨物理模型、跨价格口径拼接。

## 1. 算例数量和层级

中国正式主线不是“3 个层级各 3 个，共 9 个算例”。它是三个区域原型，每个区域覆盖九个客户规模梯度，每个梯度生成三个客户集合互斥的重复算例：

`3 个区域 × 9 个规模梯度 × 3 个互斥重复 = 81 个正式算例`

三个区域为京津冀、珠三角、成渝。九个规模梯度暂按 `10/15/20/25/50/75/100/150/200` 客户登记；若文献合成审计发现该梯度不具可辩护性，必须在任何正式搜索前统一修订并重新生成，不能在看到算法结果后修改。

“互斥”至少表示同一区域、同一规模下三个重复的客户源 ID 不重叠；跨规模是否采用嵌套或互斥设计由文献合成方法预注册决定，并在台账中明确，禁止含糊使用。

## 2. E7 与切换时点

当前 E7 是英国历史合同的最后一个科学收口任务。E7 完成包括清洁计时、28 日重放、独立不变量审计、总审计和论文展品闭合；仅有计算记录不算完成。

E7 完成前，允许开展中国数据取证、文献合成、生成器开发、道路包下载和零搜索静态检查，但不得并发运行会污染 E7 清洁计时的大型道路图解析或优化搜索，也不得修改 E7 保护文件。

E7 完成后，先冻结中国 V2 基础设施，再依次完成内核语义升级、零搜索可行性门、小规模受控搜索和正式实验。不得因为“已决定中国化”而跳过冻结门。

## 3. 英国轨怎样退役

退役不等于删除。所有英国原始数据、旧算例、E1–E7 历史结果、哈希和失败记录保持只读封存，用于追溯、代码回归和说明研究演化，不得改写成中国结果。

英国轨退役后：

- 不再进入中国主线的参数表、主结果表、统计汇总或结论分母。
- 不再用英镑价格、英国电网、Goeke 英国投影、英国车型或英国充电功率填补中国缺失字段。
- 不再对英国自建算例投入新的正式算法预算；当前 E7 科学收口是唯一例外。
- Solomon、Homberger、CVRPLIB 等国际公开标准算例继续作为算法外部有效性证据；它们不是英国情景，不受本退役规则删除。
- 若论文需要交代英国历史结果，只能在研究演化或稳健性边界中单列，明确其算法、物理和价格版本，不能与中国 V2 合并统计。

## 4. 中国 V2 全实验接入前的硬门

只有以下条件全部通过，E1–E7 中国正式搜索才允许启动：

1. 81 个实例的客户、需求、服务时间和时间窗由冻结生成器产生；每个构造字段有方法、文献来源、随机种子和逐值追踪。
2. 车型按车辆类型读取完整中国实车配置，不再只有全局统一载重、整备质量、迎风面积和电池。
3. 九城普通商业仓库/物流园车场完成场址、车辆入口、WGS84 道路吸附和普通货运准入审计；敏感口岸、保税、铁路和港区不作主情景默认。
4. 公共充电点和车场充电配置逐项标明 `HARD_SOURCE`、`DERIVED_EXPLICIT` 或 `SCENARIO_PROXY`；未知现场桩数不得伪装成实测。
5. 每个正式节点集具有固定日期、固定哈希的有向道路距离和时间矩阵；不可达、单行、权限、速度来源和道路限制覆盖边界有报告。
6. 各地区 48 槽车场电价、公共充电电能费和服务费口径闭合；缺失项不得从别省复制。无法取得的服务费只可进入预注册情景。
7. 中国碳曲线以省级逐时模拟/投影的真实数据性质表述，代表日和哈希冻结；不得称实时实测边际碳强度。
8. 非线性充电、时变电价、有向旅行时间、车辆类型参数在同一内核版本中由成本、检查、搜索、动态重规划和独立复算共同使用。
9. 81 例全部通过零搜索容量、时间窗、续航、充电并发、道路可达和车队下界审计；失败原样保留，不得按结果移动节点或放宽窗口。
10. 小规模受控搜索证明预算计数、可行性和成本分项可复算后，才允许启动正式批次。

## 5. 车场与候选充电设施

主车场优先选择常见、正常、可公开核查的商业仓库、配送中心或普通物流园，要求运营事实和道路入口分别有证据。海关监管区、军民合用设施、危险品仓、铁路编组站、港口封闭作业区和超充示范工程不得因数据丰富而自动成为主车场。

若真实车场现场充电台账缺失，可以采用两类科学情景，但不得写成现场实测：

- 已取得规划许可或公开设计文件的设施，可预注册为“假定已投运的规划容量情景”。台账必须同时保存规划状态、假定投运说明和设备上限。
- 对真实车场增设候选充电设施，可作为“投资决策情景”。候选点必须在搜索前依据道路可达、货车准入、配电/场地合理性、服务覆盖和公开设备规格生成；投资成本、功率和并发规则必须有来源。不得依据优化结果反向挑点。

## 6. 参数冲突与全国统一

全国统一的是语义、来源等级、生成方法和审计门，不是所有地区共享同一个数值。地区电价、道路时间、碳强度和站点服务费保留真实差异；同一车型物理参数、物理常数和全国标准才统一。

参数冲突按 `china_parameter_lock_and_v2_freeze_contract_20260718.md` 的逐级硬门裁决：适用范围先行，真实一手证据优先，普遍正常运营决定主情景，学术常见方法用于合成字段，无法闭合则降级情景或 HALT。禁止主观加权平均和结果后调参。
