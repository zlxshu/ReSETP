# 中国 V2 订单属性冻结合同

需求量、服务时间和客户承诺窗不冒充企业真实订单。公开检索没有得到一个许可清楚、可机读、同时含中国客户需求量和硬时间窗的多车场电动车配送数据集；LaDe 重庆数据有实际配送时空事件，但缺需求量和承诺时间窗。因此 V2 采用可复现的合成订单属性，空间位置、车辆、碳曲线、价格和基础设施仍分别使用其已登记的中国来源。

机器合同为 `data/ChinaInstances/china_order_attribute_contract_v2_20260718.json`。需求使用 kg，并按小件 20--80 kg、中件 81--200 kg、大件 201--350 kg 的三段混合生成；任何单个客户都不超过已选中国纯电物流车 1300 kg 额定载质量。服务时间按三段固定为 8、12、18 分钟，避免把一个未经来源支持的连续装卸公式伪装成测量规律。

三种实例变体不是结果导向随机种子，而是预注册的时间窗压力档：01 为宽窗，02 为中等，03 为紧窗。所有窗口落在中国本地时间 06:00--22:00 的 30 分钟网格上。具体窗口必须等道路距离和道路时间矩阵冻结后再生成：先以最近车场和确定性角度扫描构造载重不超过 1040 kg 的零搜索见证路线，再按变体宽度围绕其服务时刻落窗，最后由独立审计回放载重、行驶、服务和时间窗。见证只证明至少存在一套容量/时间可行排班，不是最优解，也不得作为算法 BKS。

如果见证失败，当前实例直接 HALT。禁止在看到失败或算法结果后放宽窗口、降低需求、增加车辆或移动客户；这条规则用来阻止过去“算例生成后再救火”的漂移。电池、SOC、充电功率和桩并发可行性不由本合同证明，必须在非线性核心和真实充电设施合同闭合后另过能源见证门。
