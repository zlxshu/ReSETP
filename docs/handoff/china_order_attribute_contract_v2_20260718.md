## 待审批方法 MC-001

候选需求转换是：

`demand_kg = round(source_volume_m3 / 7.2m3 × 1000kg)`

其中1000kg来自当前福田厢式电车的额定载重。五个源体积档1.0/1.5/2.0/2.5/3.0m3会对应139/208/278/347/417kg。该方法保持订单占源车体积容量的比例，再映射为订单占目标车载重的相同比例。

这是容量占比场景代理，不是物理密度换算，也不是实测货重。用户可批准其作为正式基础情景、只作为敏感性情景，或否决并要求双容量模型。完整利弊和审批状态见 `docs/handoff/model_change_approval_register_20260718.md` 的MC-001。

候选服务时长为6/9/12/15/18分钟，直接来自论文的0.1h/m3案例参数；若获批，必须标成文献案例参数，不得称实测停站时长。

候选基础时间窗方法是对1222条交付订单整行联合经验重采样，同时保留映射需求、服务时长、时间窗起点和宽度之间的关系。宽窗和紧窗只能作为另行批准的敏感性方法，不能用01/02/03表示。
