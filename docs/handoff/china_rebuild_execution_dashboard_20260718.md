非线性充电核心必须完成NL到NL的正式求解；旧线性解在非线性复算中出现不可行与方向反转，只能作升级证据，不能冒充完成。

## 验收标准

每个数据或方法包必须包含来源URL/DOI、访问日期、本地快照、原始字段、单位、转换或构造公式、适用边界、SHA-256、独立回读和明确PASS/HALT。构造值不得冒充观测值，代理值不得冒充全国统一真实值。

每个正式实验包必须包含`metadata.json`、`raw_runs.csv`、`decision.json`、`artifact_hashes.json`和`report.md`；同实例同起点同预算，完整评价计数闭合，零硬约束违规，保存解独立复算，失败原样保留。

算法创新必须有原始论文/开源许可证或清晰自研差异，算子实际被调用且改变候选，增量消融可证伪，在统一真实预算下相对标准ALNS和两套强基线给出方向、效应量和显著性。名称包装、标准AlphaUCB/模拟退火、阶段预算和调参本身不算创新。

E3--E7只有在用户批准的统计合同下同时达到预定方向、实质效应门和校正显著性，才可支持论文头条主张。未达到时状态是“算法或设计尚未完成”，不能降低用户目标，也不能修改有效历史数据。
