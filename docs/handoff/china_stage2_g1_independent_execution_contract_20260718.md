## 1. 用户授权与覆盖关系

用户在确认“可以不等 G1、直接独立完成”的工作范围后明确要求开始执行。本授权解除此前“暂时不进入阶段二”的总暂停，但只覆盖不依赖 G1 的数据、道路、参数、统计预注册、运行基础设施和零搜索审计。

本授权不覆盖：

- 非线性补能内核的正式实现、合入或验收；
- FC/CF/CP/DR 等机制算子的正式开发、合入或消融；
- 算法六臂增量门、强基线胜负、Solomon/Homberger/CVRPLIB/PyVRP 正式测试；
- China81 求解器预检、E1--E7 正式搜索、论文结果或结论更新；
- 将 `formal_search_allowed` 改为 `true`。

上述工作统一挂账为 `WAIT_G1_FREEZE_AND_PHASE1_FORMAL_CLOSE`。只有 G1 冻结、阶段一正式结束后，才能按“非线性内核与联合回归→机制开发→强基线与公开算例→China81 最终预检→中国 E1--E7”的顺序恢复。

## 2. 本轮目标与终局边界

本轮目标是形成可独立复算的 China81 数据与实验基础设施包：

1. 冻结并构建本地 OSRM 道路环境；
2. 生成九城有向道路距离、时间和 `Σ(v²d)` 输入；
3. 闭合中国基础设施与运行参数的来源、代理和审批分类；
4. 依据已批准的 MC-005 位置分配和 MC-001 订单属性方法生成 81 个数据实例；
5. 冻结 E3--E7 分终点实质效应阈值和主要统计量；
6. 完成数据层零搜索审计、断点恢复、监控和五记录面。

允许的最高终局判定为：

`PASS_CHINA81_DATA_AND_EXPERIMENT_INFRA_READY__G1_PHYSICS_SEARCH_PENDING`

该判定不证明最终 SOC、非线性补能、算法性能或论文结论，也不授权正式搜索。

## 4. 四条执行支线

### A. 本地道路与三矩阵

- 验签五份冻结 PBF、OSRM 26.7.3 二进制和 CV/EV profile；
- 为每份 PBF、每个 profile 构建可复现本地路由图；
- 统一客户、车场和公共站 WGS84 道路节点；
- 对每个有向点对独立请求 Route API；
- 从同一返回路线保存距离、时间和 `Σ(v²d)`；
- 禁止对称复制、欧氏倍数、直线或公共端点回退；
- 不可达点对在读取算法结果前 HALT。

### B. 基础设施与中国运行参数

- 按最新最小充分口径保留九个普通物流设施和情景道路接入点；
- 不重新引入已由用户取消的门禁、预约、月台和现场真实桩阻断；
- 公共充电站、车辆、电价、柴油、碳价、固定费、里程费、占用费、收入和跨场费逐项分类为观测、来源代理、构造代理或待批假设；
- 未分类值不得进入 China81 数据包；
- 本轮只生成独立中国配置，不替换正式求解器默认值。

### C. China81 数据实例

- 使用 `china81_customer_location_assignments_mc005_final_v2_20260718`；
- 按 MC-001 从完整经验行联合重采样需求、服务时间和交付时间窗；
- 冻结结果无关随机种子；
- 保证同一“地区×规模”内 01/02/03 客户身份和订单种子互斥；
- 汇合道路矩阵、基础设施和中国运行配置；
- 不运行优化，不使用算法搜索修复坏实例。

### D. 统计与运行基础设施

- 保留 MC-002 已冻结的三图聚合、5→7 结果盲扩样、27 格配对随机化、Holm 和 E7 运行时门；
- 在各实验族解盲前冻结实质效应阈值与主要统计量；
- 完成任务 manifest、断点、恢复、监控、五记录面和独立审计器；
- 只能用空任务、人工夹具或零搜索数据验证。

## 5. 汇合门与停止条件

四条支线汇合后执行 81 实例数据层零搜索审计。至少检查：

- 81/81 可加载、来源、配置、种子、谱系和哈希完整；
- 三复本身份和订单种子互斥；
- 需求、服务时间、时间窗和研究时域一致；
- 所有节点在冻结路网上可达；
- 三矩阵同路径、维度一致、方向有记录；
- 车场、公共站、电价槽和碳槽完整；
- 未分类代理为零；
- 正式搜索评价为零；
- AppleDouble、缓存和临时文件不进入哈希。

由于非线性核心仍挂账，本轮只能检查补能数据充分性和保守能量包络。
最终 SOC、充电时间和非线性补能可行性必须等待 G1 冻结后的统一物理内核复算。

任一支线发生以下情况立即停止相应单元：

- 需要未批准的模型、单位、参数或代理；
- 需要修改受保护求解器语义；
- 本地道路不可达且只能靠换点或回退掩盖；
- 输入哈希漂移、结果后选点或三复本重叠；
- 发现与 G1 未提交文件存在写冲突；
- 正式搜索入口被意外调用。
