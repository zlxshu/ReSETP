## 四、贯穿全局的两条方法学结论

**一｜墙钟预算下跑满上限的运行不可复现。** 同一代码、同一种子，机器负载不同则完成代数不同，落在不同解上。实证：A 臂（关闭 SISR，代码路径未变）在未触顶的 PR11A 上迭代数与成本**逐位相同**（13576 / 6782.223），而在触顶的 PR13A、PR15B 上分别相差 +0.279 与 −22.716。**配对差中除种子噪声外另叠负载噪声。** 已清除的污染源：Docker Desktop 未运行时残留的 `docker-agent` 进程占用 165% CPU。

**二｜测量必须先于判定。** 本轮多个判定（SISR 一度被判"输在实现"、协同一度被判"消失"又被判"真实存在"）皆因尺子问题而反复。分层测试规程与"先查搜索是否分化"即为此设。**在搜索未分化的预算下，任何零件判定都是在报运气。**

## 2026-08-12 收尾结案（唯一档案：`overnight_closeout_20260812.md`）

### 新增「能写的」
