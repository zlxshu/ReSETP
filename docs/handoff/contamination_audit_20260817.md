## 一、传染链（逐环点名，每环给证据与处置）

### 环 1｜所有代理时代的搜索读数 → **降为回归锚点**

`FACT`：2864.86 世系、oracle 3532.27/3534.60、SC8/SC10/SC11 全部圈数与成本、
公开精修 AB 的两题读数、三臂 3228.07——全部产自代理指挥的搜索。
`DECISION`：**一律只作回归锚点与接线证据，不作性能/效应证据**（P73/P79 已废其结论性，
本审计把根因补上：不只是种子噪声，是搜索方向本身被代理带偏）。焊洞后按 P88 重取。

### 环 2｜机制提案引擎的"二次机会"架构 → **重判存废（可能大幅简化）**

`FACT`：时变碳择时通道是**在普通修复已按电价/碳价局部择优之后**才生成"其他车释放充电资源"
的二次候选（审计 B3，`charging.py:1209-1225`）；5210 提案 0 接受。
`INFERENCE`（本审计核心判断之一）：**整个机制提案外挂层是为"核心看不见机制"而造的补偿**。
真值一旦指挥每一步（焊洞后），择时偏好会内生进搜索——二次机会通道可能整层冗余。
`DECISION`：焊洞落地后做一次通道逐个"仍有增量吗"重判；冗余即删（P90：删掉不心疼，
它们本来就是绕路的产物）。**这可能是最大的一笔简化红利。**

### 环 3｜交叉/解码的车型提示继承 → **独立第二伤口，焊洞治不了它**

`FACT`（round12 追踪）：子代按**第一父代**车型提示分配槽位；第 20 圈 0-EV 不可行第一父代的
子代顶掉了 6-EV 可行 best。**这是与源头并列的独立缺陷**：即使真值指挥局部搜索，
交叉仍会按血统稀释 EV。
`DECISION`：焊洞验收里"EV 观察"若显示 EV 仍被稀释，此环立刻升为下一件；
修法先查现成（P91：Vidal 多样性管理原文＋内核现成件）。

### 环 4｜教育层统计与限深旋钮 → **标定作废，旋钮保留**

`FACT`：SC10 的 N=∞/3/1 三档数据、"每圈 688 候选"等分布全部取自代理时代。
`DECISION`：**开关本身保留**（它是机理工具），三档效果的一切印象作废；焊洞后如需再标，重测。

### 环 5｜罚分管理器 → **从未真正工作过，焊洞后必须重标**

`FACT`：注册窗口 50 vs 实际注册 3（B1），自适应从未触发——**在代理时代它基本是摆设**。
焊洞后真值评价流量大增，注册流完全变样。
`DECISION`：焊洞后按新注册流重定窗口（内部标定，AGENTS 6.5：来自本机数据）。

### 环 6｜充电修复层与 P78 提速决策 → **92% 瓶颈画像作废，P78 继续 park 反而对了**

`FACT`：「充电修复占 evaluate_move 92%」的画像（P76-1）取自代理时代的候选分布；
焊洞后真值调用密度、候选构成全变。
`DECISION`：**P78 的甲/丙拍板必须等焊洞后的新画像**——此前 park 是误打误撞的正确。
SC-V2 缓存、D2 修复、内存修复为结构性修复，**不受传染**（逐位一致已证）。

### 环 7｜初始化设计 → **待观察**

`FACT`：witness＋扰动的多样性设计服务于代理时代的种群动力学；EV 灭绝动力学焊洞后会变。
`DECISION`：不预改；焊洞后若 EV 存活仍依赖初始种子，再议（避免又造轮子）。

### 环 8｜SC3 开销 2.54× → **重测**

`FACT`：2.54× 在代理时代测得；真值指挥下近可行候选的产生率与修复价值都会变。
`DECISION`：SC3 默认关不变；焊洞后重测其开销与收益再定默认。
