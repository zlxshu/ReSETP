# E1 280 kWh完整模型与车型结构收口（2026-07-11）

## 人话判决

E1的正面主结构已经成立。复用冻结E2中50c、100c、150c、200c共20条mixed保存解，并新增200c五个种子的CV-only正式搜索。所有mixed和CV-only行都零违规、严格完成4000次评价，成本分项加回总成本的最大误差为`1.82e-12`。

200c下，mixed平均由EV承担86.06%的客户、87.16%的需求和82.17%的距离，平均有59.8次充电。CV并非象征性存在：五个种子中mixed使用4--14台CV实体车和14台EV实体车。mixed相对CV-only为4胜0平1负，配对平均成本优势0.671%。这支持“现代电池场景下，电车承担主要配送任务，油车保留补充作用，且系统产生大量真实充电”的论文表述。

EV-only没有闭合。五个种子的直接转换均因至少一条CV路线没有可行车场充电窗口而无法形成合法全EV起点。该结果只能记为`NOT_FOUND`，不能写成“EV-only数学不可行”；不同的路线重构仍可能找到全EV解。100c冻结E2证据中已有一个全EV可行mixed最优解，也说明不能把局部构造失败推广成全规模不可能。
