# E2 当前 China81 设定下的算法探索终止结论

- 编号：`E2-CURRENT-SETTING-NO-CREDIBLE-PATH-001`
- 日期：2026-07-25
- 状态：`FINAL_STOP_PENDING_SCOPE_DECISION`
- 保护项：三视角 HGS、corrected China81 v7 和全部失败证据只读

## 1. 最终结论

在当前冻结的 China81 数据、完成器和完整评价口径下，已经没有一个同时满足以下条件
的未验证算法方向：

1. 有一手文献或公开实现支持；
2. 与全部已停止路径实质不同；
3. 直接命中当前正式算例中真实活跃的矛盾；
4. 能先用低成本门证伪；
5. 有希望在不付出数倍计算代价的情况下深化强 HGS。

因此本轮算法探索应当停止，不再发明下一候选。该结论不是“任何未来算法在数学上都
不可能更好”，而是“在当前证据和冻结设定下，继续试候选已经从研究变成结果驱动试错”。

## 2. 最后一个未覆盖候选及结果

文献和失败矩阵只留下“资源类型感知染色体”：客户顺序与
“所属车场 × 燃油/电动车”标签共同遗传。

只读活动审计证明标签不是完全死亡变量：

- `HGS-M` 中 322/405 个解同时使用燃油车和电动车；
- 193/405 个解至少有三种车场—动力标签；
- 但电动车只承担 7.8277% 客户；
- 520 次充电全部发生在车场，公共充电站使用为 0。

T0 零目标门通过：六客户穷举与 DP 一致，六个父解的原切分都可枚举，200 客户单标签
最多 3,160 个状态，没有状态爆炸。

冻结 G0 随后一次启动六任务。50 客户两臂完成；100 和 200 客户的两臂均在成绩比较前
失败。即使资源标签完全固定为原较强父解，只改变客户顺序，也无法在注册有限车队和
时间窗下切出可行路线；共同继承标签同样失败。最终判：

`FINAL_STOP_TARC_TYPED_CHROMOSOME_LOSES_MEDIUM_LARGE_FEASIBILITY`。

不得追加修复器、放宽车队/时间/状态、换题、换父代或重跑。

## 3. 为什么三视角不能直接接替为论文算法结论

三视角 HGS 仍是机械闭合、完整物理模型可行、独立复算通过的受保护备份，但已有公平
证据不支持把它写成“视角互补产生显著协同”：

- 等算力 P0 中，完整体对单视角 HGS 为 4 胜 7 平 4 负；
- 对同代理多重启控制为 2 胜 10 平 3 负；
- corrected v7 的完整性门通过，但论文效果门已判
  `HOLD_E2_STAGED_PORTFOLIO_NOT_PAPER_STRONG`；
- 当前正式解中公共充电站从未使用、沿途多次充电为 0，主要差异集中在少量车场
  出发前充电和约 7%--8% 的电动车客户。

所以它可以保留为可靠求解器和后续任何新设计的强基线，不能继续写
`1+1+1>3`、`1+1>2`、真混合或由三种物理视角带来因果提升。

## 4. 全部已关闭的能力路径

本项目已经以冻结小门覆盖并停止：

- HGS 后接/内嵌通用 ALNS、ILS、VNS；
- 强 HGS 向独立 ILS 顺序交接；
- 普通局部动作、连续块和可行性引导大邻域；
- 固定次序 Split、路线对重切、路线池/路线列 MIP；
- 全资源标签、对偶价格和资源—时隙定价；
- 8 客户联合路线—车场—车型—充电精确邻域；
- HGS 代理误排教育；
- 客户顺序与低维车场—动力标签共同遗传。

继续换名组合这些部件不再构成新研究问题。

## 5. 真正的阻断点

当前 China81 声称研究多车场、有限异构车队、共享充电、时变电价和碳强度，但正式最优
附近的实际活动集中在客户分组和普通路径顺序：

- 公共充电站和沿途充电在 405 个正式解中没有被触发；
- 电动车占比较低；
- 总车队上限没有形成普遍紧约束；
- 完成器先要求全燃油路线骨架可行，再逐路线尝试电动化。

这意味着，继续增加充电同步、公共站选择或资源价格算法，很可能优化的是论文模型中
存在、正式实验中却没有被激活的机制；继续增加普通路线动作，又会回到已经被强 HGS
覆盖的空间。

## 6. 继续所需的范围决定

若仍坚持“问题定制、可归因、真正强于 HGS”的算法论文，下一步不应是再试一个算法，
而应另立一个范围变更：

1. 用外部运营证据重新审计并预注册 China81 的电池、补能网络、车队供给、车场功率、
   路线长度和时段冲突，使论文声称的资源矛盾在不看算法成绩的情况下确实活跃；
2. 先做零搜索活动门，要求公共/沿途补能、有限车队或共享时隙至少有两类在预定比例
   的算例中形成约束；
3. 活动门通过后，把该数据版本视为新的正式 E2，从所有算法臂共同重跑；
4. 再基于活跃矛盾设计一个问题耦合操作，而不是从算法名称反推故事。

这会改变正式实验范围并废止当前 China81 结果的论文资格，必须由用户明确批准；不能
由代理自行启动。若不批准范围变更，则只能保留三视角 HGS 为工程求解器，并重写论文
为模型/情景/管理机制贡献，删除算法 SOTA、真混合和协同主张。
