# E2 改变客户次序的真混合算法：文献与失败证据审查

- 日期：2026-07-25
- 状态：`REVIEW_COMPLETE__ONE_CANDIDATE_ONLY__NO_SEARCH_RUN`
- 用途：在选择下一候选前，解释已失败方法为什么失败，并把文献能支持和不能支持的内容分开。

## 1. 当前事实

`unordered_route_pair_mip_20260725/direct_gate_v1` 已在三道结果前冻结的新题、六个固定
起点上完成 2850 个路线对小型 MIP。全部局部目标变化均为 0，未产生一个需要进入完整
评分的新候选，最终严格改善为 0/3。MIP 是否精确、时限是否更长已经不是关键问题：
该方法只重新切分两条路线，同时固定每条路线内部的客户先后次序；当这些次序已是强
HGS 的局部最优时，精确重切也没有新的排列可选。

因此，下一候选必须同时满足两点：一套独立搜索实际改变客户次序；所有送入比较的候选
仍经 China81 共用完成器、完整物理模型、独立检查器和精确评分。只增加 MIP 时限、
路线列数量、路线对数量，或继续在固定次序上做切分，均与已观测死因无关。

## 3. 文献给出的可复用规律

### 3.1 丰富电动车路径：路线次序搜索与完整路线评价分层

Hiermann 等（2019，EJOR，DOI `10.1016/j.ejor.2018.06.025`）处理燃油、插电混动和
纯电混合车队时，让遗传搜索、局部搜索和大邻域搜索改变客户访问次序；给定客户次序后，
再用分层路线评价决定充电站和能源使用，最后用集合划分重组搜索历史中的高质量路线。
这说明精确路线评价和集合划分是“裁判与重组器”，不是客户次序的创造者。

Keskin 与 Çatay（2018，COR，DOI `10.1016/j.cor.2018.06.019`）同样把固定客户次序的
充电优化作为路线子问题。它支持“次序搜索与充电决定分层”，但不支持只靠固定次序
子问题产生全局路线创新。

### 3.2 强 HGS 加专用大邻域：动作必须对应真正耦合的业务决定

Zhao、Archetti、Pham 与 Vidal（2025，arXiv `2506.03172`）不是机械追加通用 ALNS，
而是针对库存路径中“同一客户跨多日访问相互耦合”设计一个专用大邻域：一次移除并
最优重插该客户的全部访问，用预处理和动态规划降低开销，再把它嵌入 HGS。可迁移的
原则是：只增加一个由问题耦合关系直接定义的、能够改变服务结构的大动作；不能由
组件名称或数量代替问题依据。

### 3.3 跨搜索空间：短暂放宽一类约束后必须完整恢复

Zheng、Liu 与 Ong（2024，arXiv `2410.19580`）在 EVRP-TW-SPD 中先到不含电量约束
但仍含时间窗和取送约束的对应问题空间改变客户次序，再尝试恢复为完整电动车可行解；
无法恢复时立即终止该方向。可迁移的原则是：较宽松空间只负责发现新次序，正式候选
必须回到完整模型。不能把放宽后的目标当成绩，也不能一次放宽车场、时间窗、车队和
充电等全部关键约束。

### 3.4 独立 ILS 可以作为 B，但经典 CVRP 代码不能直接作为 China81 证据

Máximo、Cordeau 与 Nascimento（2024，INFORMS JOC，DOI
`10.1287/ijoc.2023.0106`）的 AILS-II 是可独立运行的自适应迭代局部搜索，公开代码
为 MIT；其证据范围是经典容量路径问题，缺少 China81 的多车场、时间窗、油电车、
有限车队、共享充电桩、分时电价和碳强度。仓库已有 PyVRP 0.13.4 的独立 ILS 及
China81 适配路径，适合作为最低成本的“另一种次序生成器”，但必须经共同完成和精确
评分，且不能把 CVRP 文献成绩移作 China81 成绩。

Penna 等（2019，ANOR，DOI `10.1007/s10479-017-2642-9`）的 HILS 说明独立 ILS、
变邻域下降和集合划分可处理多车场、异质车队、时间窗等丰富路径问题；其报告中频繁
联合车辆重分配未显著改善，提示本轮应把有限预算集中在客户次序和路线质量，而不是
反复重做车型分配。

## 4. 唯一候选与创新边界

本轮只保留研发代号 `HGS-ILS-XD`：

- A：PyVRP 0.12.2 的真实 HGS，可独立运行；
- B：PyVRP 0.13.4 的独立 ILS，可独立运行；
- A+B：两者各自搜索客户次序，在一次预先固定的中点交换经完整模型核验的路线和解，
  然后各自继续搜索；最后只对双方产生的完整可行路线做有限车队与共享桩约束下的
  限时路线池重组。

“HGS + ILS + 路线池”本身已有充分先例，不得声称为新。只有下面这一项可以作为待证
研究点：在城市、日期和半小时一致的能源/碳参数，有限异质车队和共享充电桩约束下，
把双方路线先经完整模型核验，再进行一次双向中点交换，并用完整评价次数做共同预算，
是否能产生可追踪的第二阶段增益。未通过公平对照前，它只是可证伪假设，不是创新结论。

## 5. 为什么这与刚失败的方法实质不同

无序路线对 MIP 的搜索变量只是“在哪里切”，客户相对次序始终不变。独立 ILS 的扰动
和局部搜索会改变路线内部及路线之间的客户邻接关系；HGS 与 ILS 的搜索轨迹、接受方式
和历史记忆不同。候选首先只检查 B 是否能提供 HGS 五种子路线池中不存在、又能被完整
模型接受的新客户邻接关系。若这一最基本互补性不存在，立即停止，连 A+B 性能实验都
不运行。

## 6. 结论

证据不支持继续强化固定次序的精确重切，也不支持再机械叠加 ALNS/VNS/MIP。证据只
支持用独立 ILS 做一次低成本、结果盲的互补性检验；通过后才允许做严格同预算的
A、B、A+B 检验。任何小门通过都不授权论文、E3、China81 全量、公开 BKS 或 SOTA。
