# E2公开算例表格指标的文献溯源

状态：2026-07-17 完成逐表核对。本文档只决定“记录和展示哪些指标”，不对算法结果作任何预判。

## 1. “CPU”在标杆论文中的实际含义

陈雨蝶等（2023）在标准算例实验正文中先说明程序语言、CPU主频和内存，再规定每种算法运行时间均为1 min、独立运行10次。其表1报告“最优解、最优解误差、平均解、平均解误差”，表2以 `instances、m、Ks、Q、BKS` 为基础，为各算法报告 `best/%` 与 `avg/%`。因此，硬件中的 CPU 是处理器信息，表格或正文中的运行时间是求解耗时，两者不是同一指标。

陈雨蝶等（2025）表5沿用 `instances、Q、BKS、Best.、Avg.` 的标准算例结构；表6在自建模型上为 GA、VNS 和混合算法分别列“值、CPU”，并在表尾给出 `Min、Avg、Max`。这里的 `CPU` 是一次求解所耗的计算时间，而不是 CPU 评分。

Nagata等（2010）的 Solomon/Homberger 表格进一步把二者拆开：六类算例分别报告平均车辆数和平均距离，表尾报告累计车辆数 `CNV`、累计距离 `CTD`、计算机 `Computer`、平均求解时间 `CPU(min)` 和独立运行次数 `Runs`；多次运行的方法同时列 `Best` 与 `Ave.`。论文明确说明 `CPU` 为每个实例的平均计算时间，多次运行时另示运行次数。

吴廷映等（2026）的 ALNS 算例表以路径数 `RN`、总成本 `TC`、运行时间 `RT` 和相对差异 `Gap` 为主；小规模表同时比较 CPLEX 与改进 ALNS，大规模表比较改进 ALNS 与基础 ALNS。这说明“结果质量、路径数、耗时、差异”应同时出现，不能用单一目标值替代算法证据。

Wang等（2025）的近年 VRPTW ALNS 表按问题规模报告平均目标值 `Aver.`、相对改进 `Impr.` 和时间 `Time`，并在正文另列 CPU/GPU 型号及训练时间。该结构可作为补充，但其目标、数据和训练过程与本文公开 Solomon BKS 实验不完全相同，不能直接搬用数值。

## 2. 本文采用的指标

Solomon主实验采用SINTEF分层BKS：先最少车辆，再最短双精度总距离。BKS必须记为二元组 `(K^{BKS},D^{BKS})`，不能只抄一个距离数。

逐实例原始结果至少记录：实例、类别、种子、车辆数 `K`、总距离 `D`、是否达到BKS车辆数、在达到BKS车辆数时的距离Gap、是否命中完整BKS、完整评价次数、候选评分次数、进程CPU时间、墙钟时间、首次达到本次最好解的时间、可行性、超时和失败代码。

论文标准算例逐例表采用陈雨蝶式信息层级：`实例、BKS车辆数、BKS距离`，随后为本文算法列 `Best车辆数、Best距离、Avg车辆数、Avg距离、Avg Gap、CPU、BKS命中次数`。为避免56行表破坏正文版面，展示实例在看结果前固定为六类中按名称排序的首、末各1例，共12例；完整56例进入紧邻的类别汇总和正式证据包。若版面允许，增加标准差；若版面不足，标准差进入紧邻的类别汇总表，不能完全删除。

类别汇总表采用Nagata式指标：六类的平均车辆数与平均距离，表尾给出 `CNV、CTD、Computer、CPU、Runs`。本文不得把不同距离精度、不同目标或不同硬件上的原始CPU时间直接当作速度优越证据。

自有复杂模型上的算法嫁接表采用吴廷映/陈雨蝶式结构：每种算法报告 `Best、Avg、SD、CPU、RT、可行率`，并给出相对冻结基线的配对Gap和达优次数。公开基准表与自有机制表分开。

## 3. CPU与时间的冻结定义

本文原始记录同时保存两种时间：`process_cpu_seconds` 是单个求解进程实际消耗的CPU时间，论文中若列名为 `CPU/s`，必须指向该字段；`elapsed_seconds` 是墙钟时间，论文中写作 `RT/s` 或在正文明确说明。`Runs` 为每个实例的独立种子次数。

Apple M1、4个性能核、4个能效核、内存、操作系统、语言和版本在正文实验环境中统一交代。PassMark仅用于DIMACS补充口径的跨机器时间审计，不进入SINTEF主表，也不替代论文中的 `CPU` 或 `RT`。

## 4. 不可混用的口径

SINTEF口径是分层目标、双精度欧氏距离、总距离保留两位小数；DIMACS口径是车辆数上限下的距离单目标、每条弧截断至一位小数。两者的BKS、Gap、车辆数和CPU时间均不得放入同一列。既有DIMACS零搜索审计保留为补充方法资产，正式论文Solomon主表转为SINTEF口径。

论文中的BKS标注是快速发现线索。最终采用值必须回到权威页面或原始论文，并核对算例版本、车辆一级目标、距离精度、可行性、运行次数、计算平台和结果日期。SINTEF 56份详细路线已经由Python独立复算，审计结果见 `baselines/e2_alns/e2_solomon_sintef_bks_audit_20260717/`。
