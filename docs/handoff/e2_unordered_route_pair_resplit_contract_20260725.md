# E2 无序路线对精确重切最低成本合同

日期：2026-07-25  
编号：`E2-URP-MIP-001`  
状态：`USER_APPROVED_AUTONOMOUS__G0_AND_FRESH_DIRECT_GATE_ONLY`

## 1. 要解决的已证实问题

上一版把无序路线集合压成单条客户长链，只允许长链中相邻路线跨边界重切。正式
0/3 停止后量化确认，中大题仅覆盖 19.2% 和 6.0% 的父解内路线对。本候选删除这项
伪顺序限制，不修改目标、评价器、物理规则或封存成绩。

## 2. 内核

对一个完整可行父解中的每个无序路线对 `(r_1,r_2)`：

1. 保留两条路线内部客户相对顺序，形成 `r_1+r_2` 与 `r_2+r_1` 两个方向；
2. 只生成跨越两条原路线边界的连续客户片段，并保留两条原路线作为回退列；
3. 每列用现有路线局部完整口径确定车场、车型、非线性充电方案、成本和充电时隙；
4. 从全局车队和共享桩容量中扣除未动路线的占用，得到该路线对的剩余资源；
5. 以限时 MIP 恰好覆盖该路线对客户，并逐项满足剩余车队和逐时隙充电容量；
6. 只有完整整解检查和精确评分通过且严格改善时才接受。

该过程是受限精确大邻域，不调用 HGS，不改变随机流。若内核通过，后续算法 B 才可
定义为独立迭代的路线对 MIP 大邻域搜索；本门本身不构成独立算法或论文证据。

## 3. G0

使用人工小例验证：非相邻路线对能够产生并选择新边界；未动路线占用会正确缩减车队
和某站某半小时时隙容量；原两条路线保证无损回退；局部 MIP 解放回整解后成本闭合。
同时运行既有路线列、解码和完整评价合同测试。任一失败即 HALT。

## 4. 新题直接效果门

在读取目标结果前，按实例 ID 哈希从三个预先固定档选择未参与此前候选的新题：
京津冀 50 客户、珠三角 100 客户、成渝 150 客户。每题使用 v7 五个种子的封存
MV-HGS-SP witness，并先求五父解整路池的最优可行组装解；五个父解及该组装解共同
作为六个固定起点。

每个起点遍历全部无序路线对。路线对 MIP 限时 2 秒；每题总墙钟安全上限 20 分钟；
单个路线对最多 5000 列，超过即 fail closed；三个实例最多 3 workers，底层线性
代数各 1 线程。全部起点、路线对、生成列数、MIP 状态、bound、gap、候选验解和
改善来源均记录。

通过必须同时满足：

1. 三题及所有最终输出完整可行，父解和旧整路池成本复放一致；
2. 新内核在至少 2/3 题严格优于 `min(最好父解, 旧整路池)`，绝对容差 `1e-6`；
3. 至少一次严格改善来自父解文件次序中原本不相邻的路线对；
4. 三题均不劣于回退基线；
5. 无超列、资源、目标闭合或验解错误。

通过判 `PASS_URP_MIP_DIRECT_HEADROOM`；否则判
`STOP_URP_MIP_NO_DIRECT_HEADROOM`。失败后不得在相同三题改变方向数、路线对、
时限、列上限、起点或判据。
