# E3累积消融正式收口（2026-07-11）

## 人话判决

E3正式30行全部跑完、全部4000评价、全部零物理违规、成本分项完全闭合，保存解和hash齐全。正式判决是`E3_PARTIAL_MECHANISM_SUPPORT`，不是“六层机制全部显著”。

最强证据来自时变碳：M3在同一路线、同一车型、相同总充电量和同一真实48槽碳曲线下，对比立即充电，5/5种子都降低EV间接排放，降幅为15.66%--28.44%，平均20.96%；共移动295次充电。这条可以正式支撑“碳感知择时充电有效”。

协同证据较弱但不是零：M1相对独立车场M0为4胜1平0负，平均成本低1.04%；但直接跨场服务只在1/5种子出现，共2个客户，主要改善由seed4的5.16%贡献。因此可以写“当前范围内协同有个别直接案例和总体成本信号”，不能写“跨场协同稳定、普遍发挥作用”。

公平在E3中没有成为绑定约束。M5五个种子均满足theta=1.0，但对应的M4无公平解本来就全部满足最小收益比大于1，范围约1.00008--1.01460；因此M5只能证明完整模型能保持公平可行，不能证明公平约束在E3里改变了决策。公平作用必须交给E6阈值扫描单独验证。

## 正式合同

- 场景：280 kWh任务内覆盖，真实48槽碳强度。
- 实例：`L-main-threeshift-200c-01`。
- seeds：1--5。
- 预算：每个M0--M5总计4000次评价；M0把总预算平均分给两个独立车场，不再给双倍预算。
- 算法：staged ALNS-LNS hybrid；旧粗糙碳算子关闭。
- 运行commit：`b9a59c46`。
- 证据目录：`baselines/e3_ablation/e3_submission_20260711/formal/`。

## 六层怎么解释

M0为独立车场、零EV电网碳、无碳交易、无公平；M1打开协同；M2加入日均电网碳核算；M3改为真实时变碳并做低碳充电；M4加入线性碳交易；M5加入theta=1.0收益公平。

M2和M3的绝对排放不能直接拿来判断择时效果，因为两者使用的碳强度尺不同。正式碳判据使用M3内部的同路线aware/naive配对。M4中的配额是线性成本常数，不声称配额本身改变路线。

## 关键数字

M0--M5平均总成本分别为9683.16、9575.94、9575.94、9548.18、9444.85和9435.72。该序列不是“每加一层必然降成本”的因果证明，因为不同层改变了碳核算和可行域，而且元启发搜索存在随机差异。

M1相对M0的五种子成本改善为0.027%、0.017%、0.004%、5.163%和0；平均1.042%。M1跨场客户数为0、0、0、2、0。

M3同路线低碳充电相对立即充电的EV间接排放降幅为23.45%、20.12%、15.66%、28.44%和17.14%，平均20.96%；5/5总电量严格一致。

M5最小收益比为1.00164、1.00034、1.00019、1.01332和1.00021，但M4相应最小收益比也均已超过1，所以公平绑定种子为0/5。

## 论文允许与禁止

允许写：时变碳感知在固定路线和电量下稳定降低充电间接排放；协同在部分种子产生跨场服务并在总体上降低成本；完整模型在theta=1下获得公平可行解。

禁止写：协同5/5稳定激活；公平约束在E3中显著改善收益；每加入一层都必然降低成本或排放；配额变化改变最优路线；六个机制均得到强支持。
