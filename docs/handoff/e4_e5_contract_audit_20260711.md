# E4/E5正式合同只读审计（2026-07-11）

状态：`CONTRACT_PREPARED / BLOCKED_BY_E3_DECISION`。本文件只冻结下一阶段设计，不启动E4/E5，也不修改正在运行的E3代码。

## 人话结论

旧E4/E5不能直接重跑。旧入口仍调用旧ALNS、默认80 kWh，并机械运行“碳价×碳配额”网格；旧E5还读取旧L-main报告。更关键的是，当前论文采用可买可卖的线性碳交易：`p_car(E-CE)`中的配额`CE`是与路线决策无关的常数。因此只改变配额不会改变最优路线、车型或充电时间。继续为每个配额重复搜索只会浪费算力，也可能把随机波动误写成配额效应。

E4/E5投稿版应合并成两层证据。第一层是已经完成的固定路线充电择时；第二层才是碳价改变路线和车型的响应。配额只做解析核算检查，不再作为重复搜索维度。

## 已经存在、无需重跑的证据

E2正式矩阵已经提供45组严格充电消融：同一实例、同一种子、同一路线、同一车型、相同总充电电量，仅比较立即充电与低碳择时。45/45保持路线和总电量一致，40组有真实充电移动并降低EV间接排放；其余5组来自15c无EV/无充电。该证据直接进入E4/E5的T6、F3和F4，不再另跑一批同义实验。

正式表图必须展示：每次充电原时段和新时段、48槽碳强度、各槽充电量、充电电量加权平均碳强度、EV间接排放、总充电量一致性和违规数。不能只画两个总碳柱子。

## E4碳价响应设计

### Stage A：接线短门

旗舰实例200c、seed1、400次评价，仅测碳价因子`0/1/4`。使用280 kWh、冻结staged hybrid、真实48槽碳强度、碳感知充电调度、统一CV起点和统一裁判。目的只检查碳价真正进入搜索、结果可恢复、成本分解闭合和解零违规；不拿400次结果写趋势。

### Stage B：单种子阈值屏

同一200c、seed1、4000次评价，预注册碳价因子：`0, 0.5, 1, 2, 4, 8, 16, 32`。其中`0.5--2`是现实邻域；`4--32`明确标为假设性压力区间，只用于识别算法/车型响应阈值，不赋予现实政策含义。

必须报告：总成本、去掉碳交易常数后的运营成本、总排放、CV直接排放、EV间接排放、EV/CV实体车辆和任务/距离份额、充电次数和电量、跨场服务数、实际评价数和违规数。响应判据不是“总成本变了”，而是路线签名、车型结构或总排放发生超过随机复算误差的变化。

### Stage C：五种子确认

不机械确认全部八档。固定确认现实邻域`0.5/1/2`；若Stage B首次出现可解释的路线或车型变化，再加该阈值档及其前一档。每档seeds1--5、4000次评价，批内并行运行。Stage B没有任何结构响应时，不继续扩大碳价；论文写“现实碳价下路线层不敏感，主要减排来自固定路线充电择时”。

## 配额如何处理

固定任一保存解和碳价，解析计算`CE=0.8/1.0/1.2 E_base`三个配额下的成本。必须验证：三者路线、车型、充电时间、总排放完全一致，成本差严格等于`-p_car ΔCE`。这是一项公式/实现一致性检查，不是三次搜索，不声称配额改变决策。

若论文希望研究真正影响决策的配额，必须另行引入不可交易硬上限或分段/不对称交易规则，并重新经过模型审查；当前投稿不得静默改变碳交易模型。

## E5如何并入

E5不再做充电功率、车场桩数、公共桩数或电池容量大扫描。投稿版E5只保留固定路线“立即充电—低碳择时”机制、非线性充电曲线和功率参数来源。车场容量和公共桩可用性继续挂账，除非后续合法性检查证明当前解违反既有桩容量。

## 启动条件与停止条件

只有E3正式判决完成后才能启动。运行前必须确认新runner使用commit绑定的staged hybrid、280 kWh任务内覆盖、L-main v3 200c、4000评价、旧粗糙碳destroy/repair关闭，并复用E2充电调度模块。

出现以下任一情况立即停止：碳价没有传入搜索context；不同价格行实际使用不同起点；未跑满评价；保存解违规；碳感知与立即充电总电量不同；配额变化导致路线变化但理论上只应改变常数；旧ALNS或旧报告进入新证据目录。

## 预期论文边界

最强可写结论是：“电动化降低直接燃油排放；在路线和用电量固定时，时变碳感知将充电负荷转移至低碳时段并降低间接排放；路线和车型对碳价的响应只在实验证据显示的区间内成立。”
