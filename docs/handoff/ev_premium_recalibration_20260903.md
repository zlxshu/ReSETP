# 电动车日固定溢价重标定：证据与换算（2026-09-03 晚）

用户令：溢价按购置差价重新标定，数值要文献（厂家报价／行业报告）；改参数要兼顾每一个实验、实现三大目标。

## 一、为什么现值 50 元/日站不住

- 现值来源：陈婉茹等（2023）表 7 电动车固定成本 550、燃油车 500 元/辆，差 50。原文单位是"元/辆（每个派车周期）"，
  不是"元/车日"；项目已把它降级为"量级参照"（P64）。08-11 用它验算时前提是**一车一天一趟 82 km**（平衡日里程 69–140 km）。
- 09-03 实测：多趟后一辆车一天约 155 km；电车每公里省 0.60 元（油 0.98 vs 电 0.24；行驶成本电车 0.92 反而比油车 0.78 贵，已含电池折旧 0.2445）；
  一天省约 93 元 > 50 元溢价。趟间充电 13–30 分钟（已按实际估）抵不上。于是纯电最优（表9 第一遍 0/6＝2434.41 最低）。
- 结论：不是参数被改过（09-03 逐项核对无复活），是标定前提（单趟）被多趟推翻。

## 四、对各实验的影响（三大目标：效应明显／速度合格／质量上乘）

按 155 km 日里程，电车每日省 93 元：Δ≈80 时电车仍略占优（混合偏电）；Δ≈110 时油车略占优、里程长的车才用电——**两档都落在真正权衡带内**，
表9 会出现甜点而不是单调；表11 碳价升高时车队会从油向电迁移（现在 0–5 元/kg 全程纯电、无迁移，叙事空）；
表8/表10 的时变碳机制仍作用于剩下的电车（电车数由 5–6 降到 3–4，充电时刻效应量级会收窄，须复核）；表12/13、14/15 结构不变。
速度不受影响（参数不改搜索）。
