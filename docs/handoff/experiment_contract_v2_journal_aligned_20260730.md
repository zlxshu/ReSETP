## 4. 结构性对照（本合同的核心变更）

**诊断**：目标期刊机制章的效应量是 −3.44% 到 −52.24%，因为对照的是**结构不同的模式**（独立/分区/联合配送、单/多隔间、共享/不共享），**不是边际参数扫描**。而 E3 一直在做参数扫描，且死磕在效应最弱的零错配点上，得到 0.353%。

**历史证据支持机制本身有货**：旧 L-main 200c 的 25% 错配 = 10/10 胜、省 **16.55%**；50% 错配 = 10/10 胜、省 **24.72%**。正落在期刊效应量区间。

### E3 — 三臂结构对照（取代 0/25/50 参数扫描）

对照维度是**「谁被允许服务谁」**，直接对应陈雨蝶 2025 的独立/分区/联合三分：

| 臂 | 语义 | 对应期刊概念 |
|---|---|---|
| **IND**（独立配送） | 每个客户只由其**登记车场**服务；登记关系是行政/历史形成的，与地理最优不一致 | 独立配送 |
| **ZONE**（分区配送） | 每个客户改由其**最近车场**服务；空间责任理顺，但仍不允许跨场 | 分区配送 |
| **JOINT**（联合配送） | 任意车场可服务任意客户，跨场责任自由重划 | 联合配送 |

**两个可分离的效应**：
- `IND → ZONE` = **空间组织价值**（改的是谁负责谁，客户点没动）
- `ZONE → JOINT` = **剩余协同价值**
- `IND → JOINT` = 总价值

这与 `paper_north_star_20260713.md` 已封存的发现完全一致（空间重组 −25.002%；地理已理顺后协同仅再省 4.157%，空间交错时协同省 19.826%），**不是新造的故事，是把已有发现摆成期刊惯用的结构**。

**错配率不再是扫描轴**，降级为 IND 臂登记关系的**描述统计量**（报告"登记关系与最近车场不一致的客户占 X%"）。

### E6 — 三态结构对照（保持，明确 binding 口径）

| 臂 | 语义 |
|---|---|
| **I**（Independent） | 不合作回退，复用 E3 的 IND 最终解 |
| **U**（Unconstrained） | 合作无参与约束，复用 E3 的 JOINT 最终解 |
| **F**（Fair） | 合作 + 参与保障（θ=1，各成员收益不低于 I） |

**取消 α 网格**。理由：历史 54 个 spec 中 **24 个在无约束下已自然满足双方不吃亏**，只有 30 个有 binding 空间；粗网格（α=0.25→0.5 仅 1 次方案切换）必然扫空。θ=1 是参与保障的**自然结构端点**，不是任选的阈值。

**「24/54 无约束即帕累托改进，仅 30/54 需显式公平约束」本身就是一个可发表的发现**，必须如实报告，不得当作失败。

## 6. 成本纪律

机器为 8 GiB M1。硬要求：
1. **先最小探针，后必要全量**。收敛探针只在主实例单种子上跑。
2. **并发遵循项目实验手册** `docs/handoff/READ_ME_FIRST_FOR_AGENTS.md` 第 91 行：安全时，8 逻辑线程机器尽量使用 6--8 个独立进程；任务数不足时只启动真实任务数，内存、温度、磁盘写冲突或总吞吐恶化时按证据降级。
3. **逐单元进度日志**（这是 2026-07-29 三次误杀的直接教训：无阶段性输出的健康进程会被判定为死亡）。
4. 每个任务**独立 monitor/watchdog**，以产物推进和终态为判据；**PID 精确存活检查，禁用 `pgrep -f`**。

## 7. 边界

本合同规定实验规程，**不预设任何结果方向**。任何臂的效应可正可负可零，如实报告。若某机制在结构性对照下仍无效应，那是一个诚实的科学结论，按 `VALID_BUT_WEAK` 或 `MECHANISM_BUT_TIE` 标签写入，不得改门救援。
