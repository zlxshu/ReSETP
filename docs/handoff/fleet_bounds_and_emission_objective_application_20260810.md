## 一、车队上限的数值方案

数据依据：`data/ChinaInstances/china81_finite_fleet_authority_v3_20260802/fleet_caps.csv`（144 行，覆盖全部算例×车场）。该表在电动化档位推导时已算出每个车场两个既有量：

- `base_all_cv_routes_Rd`：该车场需求全部由燃油车承担所需的路线数；
- `base_all_ev_routes_Re`：全部由电动车承担所需的路线数。

**拟定上限**：每个车场 `cv_cap = Rd`、`ev_cap = Re`，不设额外总量上限。

三个"充分、合理、有限"逐条对应：

1. **充分**——任一车型单独就能包圆该车场全部需求，算法从全油到全电的整个搭配区间都真实可达，不存在被上限剪掉的搭配；
2. **合理**——数值不是拍的，来自既有权威表按需求推导的路线数，来源链与哈希在权威表包内；
3. **有限**——按算例合计约为现车队的 2.1–2.5 倍（如珠三角 50 客户：现 8 辆 → 上限 18；成渝 150：现 24 → 上限 53），远非无限车队。

配套事实：未启用车辆不产生任何成本（`cost.py:164-170` 只对实际出车计费），"多给车位"不改变任何现有解的成本；每车场充电桩维持现状 2 × 22 kW 不动——若算法想多用电动车，充电容量与夜间时长会自然约束它，**车型搭配由真实约束和成本账内生决定**，这正是本设计要的效果，不是缺陷。

原 25% 固定车队保留为历史参照情景，不覆盖、不删除。

## 二、排放进目标的三种形式（互斥，本申请不代选）

现状：排放已在目标里，但只通过碳价 0.07502 元/kg 折算（全国碳市场现价档），在总成本中占比过小，不足以驱动决策——这是算术上限取证的结论。

- **形式甲：碳价政策情景（申请人推荐）**——保持单目标"总成本最小化"不变，碳价设两档：现行市场价 0.07502 元/kg（主情景，如实标注）＋政策情景价（文献先例：陈雨蝶同刊论文以 0.25 与 3 元/kg 做碳价—配额组合分析，其结论是"高价高配额"才能驱动企业减排）。两档都完整跑，正文如实呈现"现价下碳信号微弱、政策价下算法主动改变车型与充电"本身就是有政策含义的发现。模型、算法、叙事都不用改写。
- **形式乙：双目标**——成本与排放做非支配前沿。效应最直观，但研究问题、模型章、评价口径、叙事全部改写，动静最大。
- **形式丙：维持现价单目标**——不动。碳的分量靠车队上限放大的作用空间自然增长，但现价折算下仍可能偏弱。

情景价具体取值若选甲，从文献先例（0.25 / 1 / 3 元/kg 等）中定，选定后先受控短试，不得按效果倒选。

## 三、批准后才做什么

1. 生成器新增"内生车队"参数类（每车场 cv_cap=Rd、ev_cap=Re，全部车位注册为可启用空班表）；原车队类保留；
2. 若选甲：碳价情景参数入配置，两档均为正式臂；
3. 三地区各一个 50 客户受控短试验证接线与作用空间，如实报；
4. 未经再次批准不进正式实验。
