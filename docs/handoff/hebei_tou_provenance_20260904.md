# 河北南网（石家庄）2025年2月分时电价时段核查

**一句话结论**：2025年2月（属"冬季12月、1月、2月"），12:00–15:00 **是**低谷时段。依据是河北省发展和改革委员会《关于进一步完善河北南网工商业及其他用户分时电价政策的通知》（冀发改能价〔2022〕1364号，2022年12月1日起执行），该文件把"冬季（12月、1月、2月）"的低谷定为"1—6时、12—15时"。仓库快照 `data/ChinaPrices/official_snapshots/china_2025_02_nine_city/hebei_2025_02_api.json` 中的《关于阶段性调整工商业用户低谷电价浮动比例有关事项的通知》（冀发改能价〔2025〕121号）只把低谷的浮动比例从下浮70%调整为下浮75%，**没有改时段划分**，所以2025年2月执行的仍是1364号文的时段表。脚本 `baselines/china_instances/build_china_stage2_static_inputs_20260718.py` 第36–50行给石家庄写的时段划分（低谷1–6时、12–15时；尖峰17–19时；高峰16–17时、19–24时）与1364号文冬季条款逐段一致。

**重要限制（务必先读）**：本次核查**没能拿到1364号文的官方一次源全文**（河北省政府信息公开网页 info.hebei.gov.cn 的目标页反复"Socket is closed"连不上；沧州市发改委转发页正文是图片，读不出文字；石家庄市政府转发页给出的PDF直链 `http://fgw.sjz.gov.cn/atm/7/20230215112200181.pdf` 实测已失效，返回"页面不存在"）。下面的时段数字来自三份互相独立、内容完全一致的二手转述（两家行业媒体的原文逐字引用 + 一次通用检索聚合），且与仓库内官方电价快照JSON里对1364号/121号的引用（文号、生效逻辑、浮动比例调整方向）完全吻合，可信度高，但**不是我亲眼看到的政府原文PDF**，请知悉。

## 一、仓库JSON快照本身写了什么

`data/ChinaPrices/official_snapshots/china_2025_02_nine_city/hebei_2025_02_api.json` 的 `content` 字段是"国网河北省电力有限公司2025年2月代理购电价格公告"，**只有电价数值表（尖峰/高峰/平段/低谷/深谷的元/千瓦时），没有写几点到几点属于哪个时段**。它的"注2"原文：

> "分时电度电价由表格电价基础上根据河北省发展和改革委员会《关于进一步完善河北南网工商业及其他用户分时电价政策的通知》（冀发改能价〔2022〕1364号）...等文件规定形成。其中：平段电价由代理购电的平段上网电价执行，高峰时段电价在平段电价基础上上浮70%；尖峰时段电价在高峰电价基础上上浮20%，低谷时段电价根据河北省发展和改革委员会《关于阶段性调整工商业用户低谷电价浮动比例有关事项的通知》（冀发改能价〔2025〕121号），浮动比例由下浮70%调整至下浮75%，市场化用户参照执行。"

即：这份快照只证明了两件事——(a) 2025年2月的分时电价体系法律依据是1364号文（时段划分）+121号文（低谷浮动比例上调）；(b) 121号文只动了"浮动比例"（-70%→-75%），没提时段划分改变。时段划分本身要去1364号文原文找，快照里没有。

## 四、特别说明：午间低谷是否分月份/是否含2月

是分季节的，但**2月明确包含在内**——1364号文把"冬季（12月、次年1月、2月）"和"其他季节（3、4、5月及9、10、11月）"两组月份都定为低谷含"12—15时"（即全年除6/7/8三个夏季月以外，午间都是低谷）；只有"夏季（6、7、8月）"的低谷不含午间，改为"0—8时"整段（光伏大发期改用不同的削峰填谷逻辑）。所以本次核查的2月，午间12—15时低谷是成立的，不是把夏季规则错套到了2月。
