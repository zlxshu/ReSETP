4. **替换时仍保留的硬边界**：`min()` 只保证同轮 incumbent 不劣化；未证明最优的 MIP 输出叫“限时解”；公开等迭代下无统计可区分差异；本地候选不是社区 BKS；任何新批必须同时报告预算、CPU、墙钟、失败/负例和证书状态。

## 7. 审计结论

当前稿并非“只差把新 China81 数字填进去”。存在三类相互独立的欠账：一是明确会由洁净批替换的旧 China81 数字；二是已经被新车型和新油价裁决作废的参数；三是即使洁净批完成也仍无证据的行业、文献、通用性和 E3--E7 结果性主张。论文回填必须按这三类分开处理，不能用一份新 `raw_runs` 对所有强词一次性放行。
