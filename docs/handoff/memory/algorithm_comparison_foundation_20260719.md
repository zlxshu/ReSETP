# 2026-07-19 算法比较基础拨正

## 当前权威结论

算法比较不再用临时 Solomon 六题和混杂对手。用户批准按陈雨蝶等（2023、2025）
的研究分工重建：

- 公开标准题负责证明完整算法有公开竞争力；
- 自建复杂题负责证明算法能处理本文完整机制；
- 外部强手与母算法/组成算法分开选，不用无角色的“大乱斗”。

本项目对应关系固定为：

1. 公开：CVRPLIB X-100，最终正式表覆盖全部100题；
2. 私有：China81 only，本轮不运行；
3. 公开主表：BKS参照、HGS母算法、AILS-II大题强手、HGSRR最近混合体、
   SISR组成方法、本文完整混合算法；
4. China81主表：相同完成器的HGS路由核心、独立ReSETP ALNS、完整混合算法。
