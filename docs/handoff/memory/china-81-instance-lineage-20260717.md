## 数据来源边界

- 客户地点：已有 OpenStreetMap Map API 快照中的命名 POI，保留 OSM 类型、编号、名称/品牌、源响应哈希；这是实际地图标注，不是政府经营主体名录。
- 车场：V2使用九个有官方运营来源和地图UID的物流场址候选；正式入口WGS84、普通货车准入、营业时段、停车与场内桩仍待闭合。旧OSM工业用地不能冒充正式车场。
- 公共站：OSM只承担候选发现和地图身份；正式站必须补齐功率、枪数/容量、运营与车辆适用边界。缺字段时默认1桩/60 kW的旧做法不得进入正式实例。
- 需求、服务时长、时间窗：V2为中国车辆载重和06:00--22:00运营时段约束下的可复现合成订单，主窗使用统一`base_balanced`分布；不再继承Goeke属性，也不能称中国企业真实订单。
- 碳：仓库 `china_tvci_source_gate_20260717_v2` 的中国省级 S1-2025 预测数据，不能称实测实时碳强度。
- 距离：V2只接受冻结OSM快照和路由器生成的WGS84有向路网距离/时间矩阵；直线距离×1.4仅属于旧DRAFT。

## 不能越过的门

81结构确认不等于正式实验授权。正式搜索前仍需互斥客户池门、九城入口与准入、车场/公共站充电参数、道路矩阵、中国价格与车队合同、订单见证、非线性内核，以及既定E7和ALNS G0闭合。
