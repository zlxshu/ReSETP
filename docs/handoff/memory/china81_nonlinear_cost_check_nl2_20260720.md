# China81 非线性充电成本—检查 NL2

日期：2026-07-20

权威判定：`PASS_NL2_NONLINEAR_COST_CHECK_AND_TIMING`

NL2 把唯一非线性曲线内核接入静态充电修复、ALNS 充电修复、多趟碳择时、成本、
间接排放、场站利润和独立检查器。新动作必须携带起止电量与曲线 ID；高 SOC 慢充的
每个半小时槽按实际分段功率积分，不再用整段平均功率摊分。历史 L100 动作仍按封存
解释读取，带曲线元数据的 L100 动作与历史结果逐位一致。

固定 80→100 kWh 的 NL90 动作从第 1500 秒开始，实际持续 1080 秒；首槽真实电量
`8.333333333333334 kWh`，旧均匀摊分为 `5.555555555555555 kWh`，次槽
`11.666666666666666 kWh`，总量闭合 20 kWh。把持续时间缩短一分钟后，成本端和
检查端均拒绝；在 NL90 参数下省略起止电量和曲线 ID 也失败关闭。

同一非线性多趟固定方案的精确碳择时把夹具排放从
`0.7265247116695909 kg` 降为 `0.12108745194493127 kg`，充电起点发生变化。
该结果没有运行路线搜索，只证明择时器、槽积分和评价器相互一致，不是 China81 算法
性能或碳减排结论。

目标回归和 Ruff 通过。全量回归为 835 通过、12 失败、1 跳过；相对 NL1 多出的
5 个通过项正是 NL2 新测试。受修改路径影响的四个失败已用冻结提交模块与同一数据
复现，其他失败仍为保护哈希、环境或旧探针契约漂移。开发中的动态导入回归、错误测试
文件名和临时工作树缺大文件均原样记录于证据包。

权威证据目录为
`baselines/model_verification/china81_nonlinear_cost_check_nl2_20260720/`。本门
`search_evaluations=0`、`formal_search_allowed=false`。动态多趟仍有恒功率公式，
China81 仍缺按车辆 profile 读取三套道路矩阵的正式适配器；下一门固定为 NL3，
不得提前运行三题或 81 题算法胜负。
