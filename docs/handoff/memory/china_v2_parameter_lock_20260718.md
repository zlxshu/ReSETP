## 2026-07-18 碳—价日历纠错

旧中国81草案只读取 `2025-01-01` 一天，不能代表年度稳健性；旧“每区域12个代表日”和随后构造的2026年7月插值方案均已被后续正式裁决覆盖。当前正式主面板是原始S1-2025的2025年2月完整28日，且已取得同月七价区电价表覆盖九城。日历数值已对齐，剩余HALT是车场合同档位与默认日用户选择；机器合同和解释见 `china_parameter_lock_v2_20260718.json` 与 `docs/handoff/china_carbon_tariff_calendar_alignment_contract_v2_20260718.md`。

九城电价证据现为：北京、广州、深圳、东莞、佛山、成都、重庆已取得近期数值或完整原表；天津、石家庄仍缺正式1–10kV绝对价。北京仍缺国网原始发布URL，深圳及其他已取表城市仍缺主车场合同选行。不得用峰谷倍率反推总价、用不满1kV替代1–10kV、或把2026-07价表伪装为2025同月价。

用户进一步裁决正式日期优先采用2026并增强机制可见性。上游S1工作簿只发布2025、2030等五年节点，故不存在可直接引用的原始2026页。正式候选改为同省同小时 `CEF_2026=0.8×CEF_2025+0.2×CEF_2030` 的透明分段线性插值，并预注册2026年7月完整31日。该选择不读取优化结果，基于现有2026-07价表、夏季峰尖谷机制和整月不挑日；只能称构造的2026 S1插值情景。旧2025每区域12日降为敏感性/档案，不再是正式主日历。

7月外生解释性选择读取93个区域—日后发现，碳强度与电价档位相关系数全部为负，没有成本—碳双赢日。旧“双赢日”标签在正式结果产生前即被纠正为“冲突最弱日”；另保留冲突最强、最大日内灵活性和典型日。该事实可支撑成本—碳稳定张力的研究动机，但不能预言路线优化结果。

用户最终要求原始数据没有2026页就回退2025，故2026插值包和7月案例包降为方法档案，禁止进入正式实验。对2025原始S1全年逐月做结果盲选外生评分后，2月的三地区平均最高八槽—最低八槽差约360.5 gCO2/kWh、连续4小时差约358.0，两项全年第一。正式主面板改为2025年2月完整28天，反向/弱效日不得删除。能源数据中心接口已取得北京、天津、河北、广东、深圳、四川、重庆七套2025-02电网原表扫描和API原文，覆盖九城；具体主车场电价行仍由真实合同类别决定。
