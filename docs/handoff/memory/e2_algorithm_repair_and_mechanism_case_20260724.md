用户批准 v6 机械修订：先记录每任务真实搜索核查数；若少于280，仅对固定的 HGS-F 已保存解重复调用完整模型评价器补足差额。重复核查不生成候选、不进入路线池、不消耗随机数、不改变解或成绩；真实数、补足数、合计数都写入 raw_runs.csv 和任务报告。v6 另立目录并在正式运行前冻结 formal_preregistration_v3.json，任何超过280、固定解不可行、评价异常或哈希漂移立即 HALT。该登记不改变算法或 E2 结论门；独立重放、强度门和 S3--S5 仍须在 v6 后重新执行。
