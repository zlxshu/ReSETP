三个月、十五个以上算法候选全部停止的根因已查明，且与算法设计无关。

**证伪的两个假设。** 路线固定时，291 个可行电动候选中 291 个严格比燃油便宜
（平均省 60.97 元，节省与里程线性相关 r=0.9758），故"电动车不经济"不成立。
强制填满电动车位后与封存解逐位相同（81/81），故"完成器贪心太保守"亦不成立。

**真正的闸门。** 电动车额定载质量 1000 kg 对燃油车 1735 kg；两者总质量同为
4495 kg，整备质量差 735 kg 与载重差 735 kg 完全相等——固定总质量下电池精确吃掉
载重。搜索最小化车辆数使路线载重中位达 1667 kg，紧贴燃油车上限，于是 2667 个
电动候选**全部**因 `CAPACITY` 失败，仅 9.8% 的路线在物理上可电动。

**断崖而非渐变。** 可电动化路线比例随电动车载重门槛变化：1000 kg→9.8%、
1300 kg→11.2%、1500 kg→15.2%、1600 kg→28.1%、1735 kg→100%。任何低于燃油车
载重的电动车都近乎无效，因为路径优化总会装到较大的那个容量。

**三条杠杆全部实测封死。** 载重再平衡增益 0（普查证明解已装箱死紧：中位接收方
剩余 137 kg，中位最小客户 139 kg，需挪走 667 kg）；拆分路线动用 69.1% 闲置电动
车位，683 次尝试全部被否决，最好一次仍多花 136.83 元对固定成本 170.00 元。

**推论。** 69.1% 电动车位永久闲置、公共充电站 405 解零使用、电动车仅承担 7.8%
客户，全部由此单一原因解释。冻结 G3 门要求平均降幅 ≥0.50%，在当前车型参数下
不可能达成。三个月内所有针对充电、碳、车型、跨场机制的候选，都在优化一个未被
激活的机制。

**未执行的参数问题。** 参数候选表原推荐福田 ES1 载货/栏板配置（1300 kg），代码
采用同款厢式配置（1000 kg）；两者均为官方来源，但换用 1300 kg 只能把比例从 9.8%
抬到 11.2%，不解决问题，不得以换车型救结果。任何参数变更须走审批登记并重跑 E2。
