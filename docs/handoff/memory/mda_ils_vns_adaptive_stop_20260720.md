# MDA-ILS-VNS 自适应控制层停止

日期：2026-07-20

## 判定

机器判定与独立复算均为：
`STOP_ADAPTIVE_LAYER_KEEP_FOUNDATION`。

这只淘汰AILS-II启发的当前自适应扰动力度/接受层，不撤销已通过的
`swapstar_best`强母体。

## 做了什么

在PyVRP 0.13.4 ILS加“刷新最好解时调用SwapStar”的强母体上，预先冻结三种自适应
候选。候选每30次用第10/20/30次搜索后的真实结构距离反校原生扰动次数，目标从
20降至10或30降至15；其中一臂另用逐步收紧的近期阈值接受。全部为本项目独立实现，
没有复制AILS-II Java源码。

## 结果

基础臂在5/100/1000固定迭代下与旧工作器逐位一致。A组PR11A/PR17A/PR21A、seed3、
每臂30秒中，最好自适应臂`adaptive_d20_10`对基础母体为0胜0平3负：

- PR11A：`6747346→6766500`，退步0.2839%；
- PR17A：`6356087→6378058`，退步0.3457%；
- PR21A：`6293521→6337353`，退步0.6965%。

候选只完成母体57.8%、56.2%、55.0%的迭代。三种自适应臂的平均BKS gap分别为
1.583%、2.706%、1.835%，基础母体为1.136%。因此A组直接停止，PR16A/PR20A/PR24A
确认块没有打开。

## 证据边界

12个正式开发解全部完整、可行并通过原题独立验解；22件普通制品哈希、行为等价、
三对差值和保护文件哈希独立复算无误。AppleDouble旁车仅在该证据目录中清理，普通
制品未改。

当前证据说明：AILS-II的“目标结构距离”思想有来源，但其CVRP扰动强度数值不能直接
解释为PyVRP的客户扰动次数；在本项目等墙钟下，它先损失约四成搜索循环，质量也全面
变差。不得在已见A组救档位、目标或采样点。
