# MDA-ILS-VNS 后期分阶段路线精修停止

日期：2026-07-20

## 判定

`STOP_LATE_STAGE_VNS_KEEP_FOUNDATION`。

## 依据与实现

陈雨蝶等（2025）在算法进度达到60%--80%后接入VNS。基础门中，刷新最好解时的
SwapStar在六次未见运行里共调用320次、形成84次严格路线级改善，总耗时约0.225秒。
据此只试70%进度后每500/250次额外调用两档。额外精修使用独立派生随机流，不直接
消耗母体随机流。

## 结果

基础臂在5/100/1000固定迭代下逐位等价，1000迭代下两档额外调用恰为1/2。
A组PR11A/PR17A/PR21A、seed4、30秒中，最佳`late_vns_500`对基础母体：

- PR11A：`6774840→6773831`，改善0.0149%；
- PR17A：`6378038→6378038`，平；
- PR21A：`6291964→6291964`，平。

总目标只改善1009，即约0.0052%；吞吐保持约100%。三题后期精修分别调用19、20、27
次，但严格路线改善均为0，因此这点微胜不能归因于额外VNS。按预登记“至少2胜”门
停止，没有打开PR16A/PR20A/PR24A。

## 边界与后路

9个开发解、行为等价、调度次数、21件普通制品哈希、独立可行性和保护文件均复算通过。
不得在已见A组改70%、500/250或增加算子救援。

保留的仍是`mda_ils_vns_foundation_20260720`中已通过的`swapstar_best`。下一步若继续
公开性能增强，应转向结果前冻结的母体参数优化或真正更强的母体；不要继续微调
SwapStar时点。
