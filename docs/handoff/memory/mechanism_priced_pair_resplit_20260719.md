## 要解决的问题

旧的单客户电动化搬移会被后续完整收尾撤回，整条燃油路线退役又无法跨过暂时变差的过渡。本候选不强迫某一种车型结果，而是把两条已有路线的客户重新接起来、重新切成两条路线，并在候选排序时提前考虑车场责任、车型、补能和碳时机。它要先回答一个很窄的问题：同一批切分中，机制计价能否找到“里程排序看不见、完整模型却更好”的候选。

结构依据来自Potvin、Rousseau（1995）的2-opt*路线重接、Prins（2004）的序列切分、Vidal等（2014）的多属性专用评价，以及Hiermann等（2016）的车型—补能局部强化。这些论文只支撑结构方向，不保证本项目有效；本候选为仓库内独立实现，未复制第三方源码。

## 一次性行为门

行为门只用人工小夹具，不调用ALNS、HGS、winner或完整路线搜索。机制臂与只看里程的删减臂共享同一组39个候选、同一完成器、同一完整检查器和同一上限；各臂只精算排序前4个。

绑定夹具中，源解和不改路线边界的反事实成本均为`249.81140845994744`。机制计价臂得到成本`150.06492395356452`的可行解；只看里程的前4没有改善，仍为`249.81140845994744`。独立穷举显示完整成本最好的切分只排在里程排序第13位。可见变化是客户C2从跨场服务移回D0路线，跨场服务由2处减到1处；该夹具没有电动车路线，因此不能拿它证明车型、补能或碳机制的效果。

不绑定夹具中，两臂均逐位返回输入，没有制造虚假改善。公共单桩紧窗负例中，两条路线单独可行，但同时充电触发`STATION_CAPACITY`并被拒绝；放宽时窗正对照使用同一完成器把一辆车移到3600秒后通过，证明负例不是完成器不会错峰造成的伪失败。

最终机器检查为27/27，防篡改检查为11/11。两臂各做4次联合完整复算；完整路线搜索、ALNS和HGS调用均为0。

## 不能据此声称什么

这份证据只证明：人工夹具上，机制计价确实能把一个完整模型更好的切分送进有限精算名单，而只看里程会漏掉它；共同资源检查、计数和失败关闭也按合同工作。

它不是搜索性能证据，不证明候选能在新鲜问题上被主搜索找到，不证明胜当前v7、纯HGS或纯ALNS，也没有分别证明电动化、补能、碳、公平或动态需求的增益。人工夹具中的成本差不得写成算法改善率。

## 当前暂停点

用户要求完成本候选后暂停复盘。因此不执行合同中原本排队的两道新鲜极小搜索题，不做三种子、正式benchmark、China81、E2--E7重跑或阶段二。总体算法目标保持未完成；复盘后若继续，必须另立结果盲、同起点、同完整评价预算和同墙钟的性能合同，不能回到本夹具调参救援。
