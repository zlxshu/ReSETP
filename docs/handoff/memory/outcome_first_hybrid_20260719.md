# 2026-07-19 结果优先混合算法阶段一记忆

用户最终锁定范围：公开性能只使用带独立 BKS 的原始开源算例；私有性能只使用
China81。阶段二继续禁止。所有第三方算法必须同时登记论文引用、源码版本和许可证，
所有项目文件留在 ReSETP。

`SEG-GEN-02` 已独立实现有界多车场连续段候选：64个源段、每段6个位置、48个
路线局部精算、12个车型/补能/碳联合完成。5项单测、G0接入冒烟和零搜索行为门通过；
它能保留预完成看似较差、联合完成后更优的候选，单车场精确不动作，完整评价无偷算。
英国夹具只作行为回归，不作私有性能证据。用户收紧范围前生成的 donor03 输入搜索
次数为0，运行器已失败关闭。

公开开发共使用三组互斥的原始 Solomon 100客户题，BKS均来自既有SINTEF独立复算表，
且只在每组全部求解结束后由父进程关联。第一组两秒核心侦察显示项目ALNS在R/RC类
快速压车辆，PyVRP HGS在C类更强。由此冻结两个十秒融合候选，均使用2秒ALNS、
7.5秒HGS和0.5秒切换余量：

- `ALNS-WARM-HGS-01`：对项目ALNS 6胜0负，对纯HGS 3胜2平1负；五题最好，但R111
  多一辆车，汇总不敌HGS，停止。
- `ALNS-DUAL-ELITE-HGS-02`：共同初解与ALNS暖启动解同时进入HGS种群；对项目ALNS
  5胜1平0负，对HGS 2胜1平3负，汇总仍不敌HGS，停止。

两个候选都通过时间公平、独立可行性复算、输入/保护文件不漂移和BKS隔离检查，但
均未满足“总胜纯HGS和纯ALNS”的硬目标。公开融合开发到此停止，不改比例、不造第三
候选、不跑56题。不能声称算法优化成功或benchmark冠军。
