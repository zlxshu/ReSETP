## 六、防"造轮子"：与最近先例的区别

最近先例 Miyabe 等（2025），*Journal of Energy Storage* 132:117626：路线+充电+时变碳联合优化，
但碳信号来自**充电站本地光伏余电**（非区域电网碳强度）、纯电动单车型、单车场、无多趟、
14–16 客户 3 车、Gurobi 6 小时到时限取当前最好解。本文在碳信号来源、混合车队、多车场、多趟、
规模与求解方法上均不同，可一句话区分。

其 56 算例结果可作本文引言靶子（Claude 已逐页核对原文 p.13–14）：
普通燃油 VRP 30.8 kg-CO₂、**普通电动 EVRP 反而 32.7**（为充电绕路里程增加）、低碳 EVRP 25.7。
即"电动化本身不等于减排"有实证。另：春/夏/秋减排 22.7%/17.9%/19.6%，**冬季仅 7.2%**，
是"当 X 时应 Y"条件规则的现成范式。

**没有任何一篇同时覆盖：混合车队 + 多车场 + 多趟 + 硬时间窗 + 车场与公共站两类充电点。**
这是"前人没有同时考虑"这条研究不足的实证依据，不再是凭印象写。

其余可迁移建模：Lin 等（2021）整时段占用；Shi 等（2025）连续区间对分段价格积分；
Yao 等（2023）连续到达 + 离散时段启停；Zhen 等（2020）多车场多趟返场时刻；
Cheng 等（2022）分时碳目标 + 站级功率约束（无路线）。
判断题证据：路线**会**改变（Lin 平均多约 32 km；Zhao 等 2024 的 88 实例中仅 2 个路线不变）；
11 篇中**没有一篇**证明正确计入分时碳项后原目标必然变差；真实代价是
Cheng 等（2022）减排 26% 但**交付能量减少 12.61%**——即服务量下降，故服务量红线必须执行。

## 七、T5 三臂探针结果：不可用于判断方向，查出评价链内部矛盾

产物：`docs/handoff/carbon_objective_probe_20260804/`，终态 `PROBE_COMPLETE_DRAFT_METHOD`，
`DRAFT_METHOD_AWAITING_USER_APPROVAL`。算例 `cn-jjj-50c-01`，臂 O（成本）/C（成本+碳）/P（石家庄式电价），
3 种子 × 预算 100/1000，共 18 次运行。

`FACT`：18/18 完整合法解、违约 0、完成客户数与完成需求量在全部 6 个配对中差异均为 0
（服务量红线守住，不存在"少送几单伪装成减排"）。受保护文件未动。

**三条 Claude 独立复算的发现：**

`FACT` **一、燃油排放占系统全口径的 75–82%**，充电排放只占 18–25%。
充电时机这个杠杆在系统全口径上的天花板本来就低，这一点此前没有量化过。

`FACT` **二、存在压倒性混杂因素：EV 实际承担的工作量。**
充电电量在 6 个配对里只在两个模式间跳——约 48–54 kWh 或约 87–99 kWh。
电量高时系统排放约 171–190 kg，电量低时约 200–210 kg。
即系统排放的变化主要由"EV 干了多少活"决定，不由"什么时候充"决定。
臂 C 与臂 P 观察到的多数"效应"实为该混杂，不是时机效应。

`FACT` **三、决定性矛盾：同解同电量下碳感知反而更脏。**
预算 1000、seed 1 的 C–O 配对：`route_signature_changed=False`（路线逐位相同）、
充电电量同为 87.55 kWh、里程同为 645.2 km，但充电排放由 43.06 kg 升至 57.30 kg，
即实际吃到的平均碳强度由 0.4919 升至 0.6545 kg/kWh。
**同一套路线、同样的电量，碳感知臂选了更脏的时段——逻辑上不可能，碳感知至少应打平。**

`INFERENCE`：最可能的成因是搜索侧使用的碳项与最终完整评价所用的充电排程不是同一套——
搜索优化了一个代理碳值，最终评价重新排了一次充电。未经定位不得写成结论。

`DECISION`：**本探针不能回答"路线会不会为碳而变"**，因为该问题的判据被上述矛盾污染。
按用户 08-04 定的规矩"如果变差了，大概率是我们自己本身的代码问题"，先定位再重跑。
探针不作废：它首次量化了燃油占比、暴露了 EV 工作量混杂、并查出了评价链不一致。

`BOUNDARY`：探针完成不等于批准任一草案方法，不授权正式实验，不授权论文主张
（`paper_claim_allowed: false`）。臂设计与配置在看到结果前已写入 `preregistration.json`。

**下一步须先解决的两件事（未开工）：**
1. 定位并修复"搜索碳项与最终充电排程不一致"。
2. 重设探针以隔离时机效应——至少要控制或分层报告 EV 工作量，
