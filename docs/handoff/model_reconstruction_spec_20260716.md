# ReSETP 两层模型重建规范

日期：2026-07-16  
状态：设计冻结候选；尚未替换正式稿模型  
目的：用与实际求解器证书一致的结构替换当前混用单趟/多趟下标的弧式模型。

## 1. 为什么不继续给现有公式补下标

当前模型把节点弧选择、实体车、多趟、途中充电、趟间充电、阶段继承和共享充电容量压在同一组变量上。简单把 `w` 加到所有变量仍会留下三个问题：同一充电站一辆车一天可能多次访问，充电会话需要独立索引；出发车场与返回车场若共用一个节点时间变量会形成正时间闭环；动态阶段的“当前可用时刻”和实际离场时刻不能共用一个变量。

求解器实际先形成配送趟，再把不重叠的趟链接到实体车并生成充电证书。因此，论文也应采用“可行趟/排班模式—实体车选择”的两层表达，而不是继续维护一个与程序结构不同的巨型弧式模型。

## 2. 第一层：可行配送趟

阶段 `tau` 的一个可行趟 `r` 是有序节点序列、车型、离场时刻、回场时刻、客户服务关系、弧载重、弧能耗及途中充电会话的完整证书。它必须单独满足：客户时间窗、车辆容量、源节点与汇节点分离、途中电量传播、安全电量、连续充电区间和站点访问规则。

对每个趟预先计算：

- `a_ir`：趟 `r` 是否服务客户 `i`；
- `q_r`：车型；
- `l_r,b_r`：离场与回场时刻；
- `d_r,f_r,e_r`：距离、油耗与行驶电耗；
- `c_r`：不含跨车场责任与参与约束的运营成本；
- `E_r`：燃油直接排放与已确定充电量对应的排放账本；
- `o_srt`：途中充电会话在站点 `s`、时段 `t` 的实际占用；
- `y_srt`：对应充电量。

“可行趟”不是把错误藏到集合中。生成器必须输出可复核证书：每条弧载重、服务时刻、到离站电量、充电开始/结束、分时重叠和排放。E1 用极小实例和独立评价器验证这些证书。

## 3. 第二层：实体车排班模式

对实体车 `k`，模式 `p` 是与其车型和继承状态相容的一列有序配送趟。模式内部已经保证：

1. 第一趟从车辆在 `tau` 的真实位置与最早可用时刻开始；
2. 后续趟从所属车场的源副本离场，并返回汇副本；
3. 相邻趟不重叠；
4. 趟间补电完整落在前趟回场和后趟离场之间；
5. 正在执行或正在充电的历史前缀不回滚；
6. 每次充电是一个连续区间，其时段量由实际区间重叠得到；
7. 车场归属 `d(k)` 唯一，跨场共享只改变服务客户，不改变车辆所有权。

令 `P_k^tau` 为实体车 `k` 的可行模式集合，二元变量 `z_kp^tau` 表示是否选择模式 `p`。对每个模式预计算客户覆盖 `A_ikp`、运营成本 `C_kp`、排放 `E_kp`、各站点时段占用 `O_stkp`、各客户实际服务车场及收益贡献。

## 4. 主问题

当前阶段只优化尚未执行部分，历史成本、排放和收益作为报告状态，不放入影响相对选择的常数项。基本目标为：

```text
min  sum_{k,p} (C_kp + c_CO2 E_kp) z_kp
     + sum_{i,k,p} c_{i,d(k)}^tr A_ikp z_kp
```

其中 `c_CO2` 是线性碳价。若论文确实要研究排放上限，则另加 `sum E_kp z_kp <= E_cap`；若研究配额买卖，则用买入量、卖出量和不同价格显式结算。固定 `CE` 下的 `p(E-CE)` 只比 `pE` 多一个常数，不再写成会改变路线的配额机制。

客户唯一服务：

```text
sum_{k,p} A_ikp z_kp = 1,  for every active customer i.
```

每辆实体车最多选择一个模式：

```text
sum_p z_kp <= 1,  for every vehicle k.
```

共享充电容量：

```text
sum_{k,p} O_stkp z_kp <= C_s,  for every station s and slot t.
```

若候选模式的充电区间以连续时间记录，最终统一评价器还需逐区间检查并发数，而不是只依赖离散时段上界。

## 5. 参与约束而不是“收益公平”

车辆集合 `K_d` 是车场 `d` 的所有权划分。客户由模式中的实际服务车辆决定服务车场。车场 `d` 的阶段收益为该车场车辆完成客户所获收入减去同一模式的归集成本。参与约束写为：

```text
historical_profit_d
+ sum_{k in K_d,p} pattern_profit_kp z_kp
>= theta_d * stand_alone_profit_d.
```

它只表示个体理性或参与底线，不表示利润均等、比例公平、Shapley 分配或谈判公平。若后续希望研究公平，必须另行定义可比较的公平准则与转移支付规则。

独立经营基准必须在相同时间范围、相同需求与相同收入/成本口径下单独优化，并验证基准利润为正。E6 各档只改变参与下界；若较低档方案已经满足更高档要求，可复用同一方案，但必须记录方案来源和实际搜索次数。由固定候选池筛得的结果只能称为“已观测保障曲线”，不能称为每档全局最优或 Pareto 前沿。

## 6. 充电调度子问题

对固定模式产生的每个充电会话 `q`，记录站点、最早开始 `r_q`、最晚完成 `d_q`、所需补能量和按站点固定功率得到的持续时间 `delta_q`。决策是连续开始时刻 `s_q`，并满足：

```text
r_q <= s_q,
s_q + delta_q <= d_q.
```

会话与时段 `t` 的实际重叠长度定义为：

```text
g_qt = max(0, min(s_q+delta_q, Tbar_t) - max(s_q, Tunder_t)).
```

若站点功率为 `pi_s`（kW），则 `y_qt=pi_s*g_qt/3600`，总充电量为 `pi_s*delta_q/3600`。各时段电量来自同一连续会话的真实重叠，不能在不连续低碳时段自由分配。站点并发按连续区间核验。E4 固定路线、车辆、客户、会话电量和合法窗口，只改变 `s_q`，用预测碳强度决策、实际碳强度结算。

## 7. 动态状态

每次触发需要继承：已完成客户、已承诺且不可撤回客户、车辆位置、当前时刻、剩余载重、SOC、正在进行的服务/行驶/充电、已发生成本、排放、收入、车场收益和充电站占用。取消已完成订单无效；取消在途承诺订单如何处理货物必须由业务规则决定。需求变化只作用于尚未完成部分，不能改写历史载重消耗。

模式生成的时间下界为车辆真实最早可用时刻，不是把“当前时刻”直接等同于下一趟离场时刻。正在进行的充电保持原开始时刻和已完成电量；后续未执行部分才可重排。

## 8. 与当前实验的兼容性

E2 的路线解可转换为每车模式并由统一评价器复算；E3 的客户责任只改变跨场允许关系与服务成本，不改变坐标、需求、时间窗；E4 只重排模式中的充电会话；E6 在同一模式生成规则下改变参与下界并重优化；E7 的滚动阶段每次生成与继承状态相容的新模式。

这次模型重建不要求重跑封存 E1/E2。先对已保存解做“旧解—新模式证书”兼容回放；只有发现评价值或可行性改变，才触发单独的影响评估，不能直接改写封存结论。

## 9. 放行测试

1. 单客户路线 `d+ -> i -> d-` 可行，且不会形成时间闭环；若把 `d+` 与 `d-` 合并，测试必须失败。
2. 两趟同车时，后一趟离场不早于前一趟回场加合法充电持续时间；重叠和不连续充电必须失败。
3. 两辆车争用单桩时，并发超过 `C_s` 必须失败。
4. 客户覆盖恰为一次；遗漏和重复必须失败。
5. 固定 `CE` 的变化不改变最优模式选择；碳价或真实排放上限可以改变选择。
6. `theta=0` 退化为无参与约束；`theta=1` 要求双方均不劣于独立经营；基准利润非正时测试拒绝比例约束。
7. 旧解转换为模式后，成本、距离、油耗、电耗、充电量和碳排放与统一评价器在容差内一致。
