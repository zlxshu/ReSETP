- 编号：`MPD-ILS-VNS-D1-001`
- 日期：2026-07-20
- 状态：`USER_AUTHORIZED_AUTONOMOUS_EXECUTION__PREREGISTERED_BEFORE_CODE`
- 工作名：`MPD-ILS-VNS`（Multi-Phase Diversified ILS-VNS）

## 1. 为什么是新架构，不是救参数

有限参数竞速已按合同 STOP，`race_08`不得继续调参或在已见确认题救援。但其未见块
留下了可复用的互补事实：宽邻域强扰动在6对中赢基础母体4对，合计目标和平均BKS gap
更好；基础母体在另2对更好，而且每秒完成的循环约多45%。

因此本候选不把`race_08`改写成通过，而把两种节奏组成一台分阶段机器：

1. 快速母体先获得稳定解；
2. 宽邻域强扰动负责中段跳出原盆地；
3. 快速母体回来精修；
4. 原生SwapStar继续只在刷新最好解时做路线级VNS；
5. 五个ReSETP机制专家在阶段交界处常驻问询。公开原题缺少车型—充电、碳、责任成本、
   公平和动态字段时按输入语义自然不适用；China81接口具备后再插入真实候选，不设人工
   公开开关。

这与陈雨蝶等（2025）的“前期主搜索、后期VNS精修”同属分阶段混合故事，但本项目根据
实测互补证据增加了中段多样化和末段回收。文献上，AILS-PR把多样化与强化结合，
MDVRP的VTNS用shake负责多样化、粒度局部搜索负责强化；本项目不复制其代码，只借
结构原则。

来源：陈雨蝶等（2025），DOI `10.12011/SETP2024-2027`；
Máximo、Nascimento（2021），DOI `10.1016/j.ejor.2021.02.024`；
Yücenur、Demirel（2021），DOI `10.1016/j.cor.2021.105269`；
PyVRP，DOI `10.1287/ijoc.2023.0055`。

## 2. 冻结四臂与公平计时

所有臂总算法墙钟相同，阶段建邻域、阶段切换和机制问询均计入预算；阶段间只传递当前
最好完整可行解、同一罚项管理器和同一连续随机流，不并行、不额外加时。

|臂|时间分配|用途|
|---|---|---|
|`foundation`|快速母体100%|强对照|
|`wide`|冻结`race_08` 100%|宽搜索单体|
|`wide70_fast30`|宽70%→快30%|陈式广搜后精修|
|`fast20_wide60_fast20`|快20%→宽60%→快20%|稳定起步—多样化—收口|

快速母体参数就是已通过的`swapstar_best`；宽节奏参数就是已停止但冻结的`race_08`：
邻居65、等待权重0.5、时间窗违约权重0.5、非对称邻居、历史100、扰动5--25。
这里不得修改任何一个常数，不增加第五臂。

每个阶段都用同一PyVRP ILS、节点邻域和记录触发SwapStar；变化只有冻结的搜索节奏。
最终输出取全程各阶段最好完整可行解。

## 3. A组整机选择

- 已见开发题：PR11A、PR17A、PR21A；
- seed 7，单线程，每臂每题60秒，四臂同批；
- 只在两个多阶段臂中按平均BKS gap、最坏gap、总目标、名称选择唯一候选。

只有唯一候选同时满足以下条件才打开B组：

- 三题总目标分别低于`foundation`和`wide`；
- 相对两个单体都至少2胜、最多1负；
- 全部解完整、可行并独立验解；
- 机制专家五项均有问询账，公开缺失语义按输入自然不适用。

失败即`STOP_MPD_ILS_VNS_PUBLIC_ARCHITECTURE__PIVOT_CHINA81`，不救比例。

## 4. 未见B组确认

仅A组过门后打开从未用于性能调参的PR16B、PR20B、PR24B，seeds 1--2，
每臂每题90秒。只运行`foundation`、`wide`和唯一多阶段候选。

PASS须同时满足：

- 候选六对总目标分别低于两个单体；
- 相对每个单体至少4胜、最多1负；
- 任一负例不超过0.25%；
- 相对两个单体中平均BKS gap更低者，再改善至少0.10个百分点；
- 全部解独立有效，阶段总计时不超预算容差，保护文件不变。

未过即STOP并转China81，不在B组改比例、参数、随机流或机制问询。
