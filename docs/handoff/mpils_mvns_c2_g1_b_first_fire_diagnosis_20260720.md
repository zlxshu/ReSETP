## 结论

首发判定为 `FAIL_G1_B_FIRST_FIRE__DIAGNOSIS_REQUIRED`：三题对同批新跑母体为
0 胜、0 平、3 负。六个解全部完整、可行并通过独立验解，六臂墙钟合规，五机制
常驻、四项限额和保护文件门均通过；失败是性能失败，不是完整性事故。

两发协议中的 A 组常数诊断可以启用。直接证据表明，当前 `trigger_after=128` 和
`cooldown=128` 使昂贵的段扰动触发过密，是首发性能损失的明确原因；但专用动作的
成功率也低，所以稀释触发只能消除已确诊的伤害，不能预先保证第二发获胜。
