# 论文全书蓝图：结果驱动版

状态：2026-07-13 最新版。本文取代同日旧版中“时间杠杆唯一主线”、“四把锁”和尚未执行的充电实验设计。章节结构是当前最优解，不是不可修改的先验。

## 0. 总原则

论文设计与实验结果双向作用。研究问题决定哪些比较值得做，实验结果决定哪条主线真正能站住。可以换叙事、调章节、补缺失对照；不能删掉不利结果、按方向选算例或调到好看为止。

全文图表执行同一包装规则：标题只用中性名词短语；一张图或一张表只回答一个问题；内部实验代号、程序字段、版本名和文件名不进读者层；每件展品必须交代比较对象、样本单位、分母和限制；不仅靠颜色区分类别。图表形式可以参考现有论文，但比较变量和结论必须来自本文问题，引用必须跟着使用处。

## 1. 当前章节树

### 第 1 章　引言

现实背景从三个矛盾进入：多车场合作可以重新组织服务范围，但收益取决于原有客户责任是否已经符合地理；油电混合车队的减排既来自少跑路和少烧油，也来自同一度电在什么时间充；静态系统总收益还必须经过参与方接受和动态状态不可回滚两道现实门。

文献综述按问题群而不是按实验代号组织：协同多车场路径与公平；油电混合车队与多趟排班；分时碳强度与充电时机；动态重规划与状态继承。不再声称“只要把四个机制放在一起就原创”。

### 第 2 章　问题描述与数学模型

保留多车场、油电混合车队、客户跨场服务、实体车连续多趟、充电和电量衔接、两层排放、参与方收益下界和动态状态继承。一辆车一日多趟的时间线用于说明模型语义；客户归属地图不上移到本章，避免同一张图同时担任“问题示意”和“实验输入对照”两个故事。

### 第 3 章　求解方法

说清统一解表示、路径搜索、实体车多趟可行性检查和固定配送方案后的预测充电子程序。算法比较只证明尺子有竞争力，部件拆分只证明哪些部件改善求解，不让它们同时承担管理机制发现。

### 第 4 章　数值实验与结果

#### 4.1 模型与算法可信度

基础可行性检查回答模型是否产生可执行的油电混合多趟配送；算法比较回答求解方法是否有竞争力；算法部件拆分回答优势来自哪些部件。这一节是证据地基，不写成论文的主要管理发现。

#### 4.2 客户归属的空间组织与协同价值

第一小节比较固定客户分工时，空间交错划分与按地理关系划分的直接差异。第二小节在每种归属结构内只开放跨车场重新分工权，计量合作的剩余增量价值。结论是“地理组织先获取大量效率，合作主要修复空间交错的责任”，不是“合作具有固定收益率”。Fernández 等已报告聚集客户通常留下较少协同收益，所以方向本身不作原创声明（[Fernández 等，2018](https://doi.org/10.1016/j.ejor.2017.08.051)）。

#### 4.3 预测驱动的充电时机与排放

完全固定上一节的路线、车辆、客户服务关系、每次充电电量和总电量，只比较“有空即充”与“按次日预测选择合法时刻”。预测碳强度用于决策，实际估计碳强度用于结算。结果同时报告充电环节和运营总排放，并分清前夜首趟与日间趟间来源。电网数据及时间槽语义以英国国家能源系统运营商方法说明为准（[NESO](https://www.neso.energy/data-portal/national-carbon-intensity-forecast/national_carbon_intensity_forecast_methodology)）。

#### 4.4 协同收益的参与条件

公平实验只回答两个问题：公平要求提高多少系统成本，什么时候变得不可行。是否将本节与 4.2 合并为“协同价值的产生与接受”，等正式结果出来后再裁，不照搬 Luna 的章节树。Soriano 等可作为多车场利润公平的相邻文献与图形参照（[Soriano 等，2023](https://doi.org/10.1016/j.ijpe.2022.108669)）。

#### 4.5 动态订单下的收益存续

动态实验检查新增、取消和需求变化后，已执行路线不能撤回、车辆时间和电量必须继承时，协同和低碳收益还剩多少。它是存续检验，不重新证明前两节，也不在没有对照时写成交互因果。

### 第 5 章　结论与启示

结论按“地理组织—协同剩余价值—前夜充电补充减排—参与条件—动态存续”的实际证据收束。公平和动态数据未出前，最后两段只保留问题位置，不写结论方向。

## 4. 算例与现实解释边界

正式配送网络继承 [Goeke 与 Schneider（2015）](https://doi.org/10.1016/j.ejor.2015.01.049)建立在污染路径基准上的混合车队算例；原始基准论文明确说明节点代表英国城市（[Bektaş 与 Laporte，2011](https://doi.org/10.1016/j.trb.2011.02.004)）。项目已合并三班任务、增加第二车场并按坐标重算欧氏距离。从九份 `nodes.csv` 逐一复算的客户/车场最大点间距离为 168.716–248.085 公里。所以正文使用“基于英国城市坐标构造的区域/城际配送场景”，不写“真实英国道路运营”、“真实企业订单”或“城市末端配送”。

电网数据使用英国全国半小时预测和实际估计。算例没有唯一电网分区身份，因而这是可复核的全国情境，不冒充某一英国城市的当地电网。
