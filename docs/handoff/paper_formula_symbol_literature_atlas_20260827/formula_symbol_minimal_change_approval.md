# 现稿公式与符号最小修改审批单

日期：2026-08-27

## 审批范围

本审批单只涉及 `docs/paper_v2/paper_main.tex` 的公式、符号及其紧邻解释。不给论文增加新研究内容，不改算法、数据、实验结果和图表。

执行原则：

1. 只采用原论文中成体系出现的公式和符号；
2. 不从多篇论文各抽一部分拼成新公式；
3. 原文没有直接依据的表达不补写，只标明暂不能改；
4. 获批后先在独立候选目录修改，不覆盖当前主稿；
5. 修改完成后提交逐项对照和候选 PDF，再决定是否回写主稿。

## 建议批准的最小修改

### 1. 混合车队机械功率、电耗和油耗

- **现稿问题**：`P_{ij}`、`e_{ij}`和`f_{ij}`使用车辆参数，却没有车辆下标；`u_{ij}`也没有与车辆、配送趟绑定。现稿的`\beta_{0k}^g,\beta_{1k}^g`不是所引文献直接使用的符号。
- **拟修改**：将式（机械功率、电耗、单位时间油耗率和弧段油耗）整体改用陈婉茹等（2023）的成套表达和原符号：`T_{ij}^k(u_{ij}^k,v_{ij}^k)`、`b_{ij}^k(u_{ij}^k,v_{ij}^k)`、`G_{ij}^k(u_{ij}^k,v_{ij}^k)`、`f_{ij}^k(u_{ij}^k,v_{ij}^k)`。本文恒速假设只在文字中令`v_{ij}^k=v`，不另造能耗公式。
- **原文依据**：陈婉茹等（2023），论文第3323页，式（1）—（4）；Goeke和Schneider（2015），论文第4页，式（1）—（3）。
- **同步影响**：符号表、碳排放式和电量约束中的能耗符号随之统一；不改任何参数数值。
- **建议**：批准。

### 2. 删除现稿自推的“线性电耗退化式”

- **现稿问题**：`g_v`和`\omega^E`没有在所引原文中按现稿形式出现，且漏掉车辆下标。
- **拟修改**：删除式`eq:linear_energy`及其推导说明；能耗只保留上一项的文献原式。
- **原文依据**：陈婉茹等（2023）式（1）—（4）已经给出完整能耗表达，不需要另设该退化式。
- **同步影响**：仅删除一条重复推导，不改变研究内容。
- **建议**：批准。

### 3. 电耗换算系数名称

- **现稿问题**：现稿把乘在机械功率上的系数称为“效率系数”，与原文含义不一致。
- **拟修改**：随第1项直接采用原文的电动发动机换算系数`\phi^d`和电池放电换算系数`\varphi^d`，删除现稿`\alpha_k^e`及“效率系数”表述。
- **原文依据**：Goeke和Schneider（2015）第4页式（2）；陈婉茹等（2023）第3323页式（2）。
- **同步影响**：符号表和能耗段落。
- **建议**：批准。

### 4. 非线性充电时长

- **现稿问题**：现稿按SOC分段求和的时长式没有在Keskin、Montoya或Diefenbach原文中以该形式出现。
- **拟修改**：删除现稿求和式，采用Montoya等（2017）的完整充电函数表达：进入电量、离开电量分别通过同一充电函数反函数映射为充电时刻，充电时长为两者之差；保留原文的`\hat g_i`、`q_i`、`o_i`和`\Delta_i`体系，不自行展开成新的分段积分式。
- **原文依据**：Montoya等（2017）第4页第2.2节，`\hat g_i`及`\hat g_i^{-1}`定义；第5—7页式（10）—（25）、（34）—（38）。Diefenbach等（2023）第6页的`\eta(\tau)`及反函数只作同方向复核，不与Montoya符号混用。
- **同步影响**：符号表、充电时长引用、充电变量域。
- **建议**：批准。

### 5. 模式系数与决策变量分类

- **现稿问题**：`A_{ikp}`在符号表被写成决策变量，但在模式选择层实际是模式是否覆盖客户的固定系数；`O_{skpt}`同样是已生成模式的占用系数。
- **拟修改**：只改符号说明，将二者分别写为“0-1模式覆盖系数”和“非负整数模式占用系数”；不改覆盖约束和站点容量约束。
- **原文依据**：现稿第二层采用既定模式集合`\Omega_k`进行集合划分；Froger等（2022）第7—10页给出充电站容量和路径列属性的完整体系。
- **同步影响**：符号表两处文字。
- **建议**：批准。

### 6. 补齐变量域和必要索引

- **现稿问题**：当前只声明`z_{kp}`为二元变量，未集中声明`x_{ijr}`、`a_{ir}`及连续变量的取值范围，也没有集中定义节点、车辆、配送趟、模式、会话和时段索引。
- **拟修改**：按对应原文的变量分类，补充二元变量域、非负连续变量域和索引说明；不增加新的决策变量。
- **原文依据**：陈婉茹等（2023）第3325页式（22）—（26）；Zhen等（2020）第5页式（16）—（20）；Montoya等（2017）第7页式（34）—（38）。
- **同步影响**：符号表和完整模型末尾的变量域。
- **建议**：批准。

### 7. 预测排放与结算排放用语

- **现稿问题**：目标函数使用预测排放`\widehat E_{kp}`，相邻文字却称其为“碳结算成本”。
- **拟修改**：不改公式，只把优化阶段的文字统一为“按预测碳强度计算的碳成本”；执行后的`E_{kp}`保留为结算排放。
- **原文依据**：Cheng等（2022）第3—4页区分预测碳强度与实际碳强度的在线充电安排。
- **同步影响**：问题描述、成本构成和完整模型后的解释，共三处措辞。
- **建议**：批准。

### 8. 公共站服务费单位

- **现稿问题**：参数表给出公共站服务费0.4元/kWh，公式却使用未给数值的元/min占用成本。
- **拟修改**：删除`c^{\mathrm{occ}}H_{kp}^{S}`；将公共站服务费并入公共站时段单位电价`p_{s,t}^{e}`，充电成本只保留“单位电价乘充电量”的原式结构。
- **原文依据**：Lin等（2021）第6—8页式（1）的分时购电成本结构；Xiao等（2021）第13页式（23）的单位电能成本结构。
- **同步影响**：符号表、充电成本式和参数说明；0.4元/kWh数值不变。
- **建议**：批准。

### 9. Shapley成本分摊

- **现稿问题**：公式本身没有问题，风险在于联盟成本`C(A)`的计算口径可能不一致。
- **拟修改**：公式一字不改，只在公式前补一句：所有联盟成本必须使用同一客户数据、约束、成本边界和求解预算。
- **原文依据**：饶卫振等（2022）第9页式（17）。
- **同步影响**：算法章成本分配段落一句话。
- **建议**：批准。

## 暂不修改的项目

以下内容目前没有找到与现稿完全对应的单一原文体系。按用户要求，本轮不自行补公式：

1. 非线性充电与分时电量`y_{qt}`的完整连接；Montoya给出非线性充电，Lin给出离散时段电价，但二者不能直接拼成一条新公式。
2. 动态客户集合更新式和历史成本、排放累计式；邱莹莹给出定时、定量触发，但现稿两条集合与累计公式不是其原式。
3. 跨场协调成本`F_6`；已查文献存在跨场运输成本，但没有与现稿“按跨责任客户数计费”完全相同的原式。
4. 配送趟、实体车日模式和充电会话三者的完整接口；现有来源分别给出各自完整模型，没有一篇与现稿全部层次相同。

这些项目不获明确原文前不改、不补，也不宣称已经数学闭合。
