# 论文北极星：当前有证据的主线

状态：2026-07-13 最新版。本文取代同日“时间杠杆是全文唯一中心”和“四把锁”的旧说法。论文设计与实验结果双向调整，目标是形成有趣、可检验、能发表的发现，不是证明一个预先写好的口号。

## 1. 论文在问什么

当前最稳的总问题是：**在动态多车场油电混合配送中，客户责任的空间组织、跨车场重新分工和充电时机分别能带来多少成本与排放改善；这些改善能否被合作方接受，并在订单变化后保留？**

这个问题保留了论文的模型主体：动态、协同、多车场、油电混合与收益公平。它也保留分时电网碳强度的现实价值，但不再把协同、公平和动态都降成“充电时间”的附属。

## 2. 现在已经发现了什么

第一，客户坐标、需求和时间窗不变，只把客户责任从空间交错划分改为按地理关系划分，九张网络的平均总成本下降 25.002%，距离、燃油直接排放和用电量分别下降 35.478%、41.729% 和 23.869%，九张网络均同向。物理上的客户点没有被“聚类”，改变的是谁负责谁。

第二，在地理分工已经比较合理时，再开放跨车场重新分工，合作平均只再节省 4.157%，七张网络改善，统计证据不足；在客户责任空间交错时，同一权利平均节省 19.826%，九张网络全部改善。节省主要来自少跑路、少用油和少用电，不是稳定减少实体车数。“客户更集中时剩余协同收益更小”已有相邻文献报告，因而不得写成本文首次发现（[Fernández 等，2018](https://doi.org/10.1016/j.ejor.2017.08.051)）。

第三，把路线、车辆、客户服务关系和充电总量全部固定，只用次日碳强度预测重新选择合法充电时刻，充电环节排放下降 3.888%–4.877%，但放回燃油车直接排放后，运营总排放只下降 0.352%–0.523%。净节省的 95.5%–99.7% 来自前夜首趟充电，日间趟间搬动很小；合作没有稳定放大这项收益。约 4% 的充电排放改善量级本身也已有相邻研究报告（[Cheng 等，2022](https://arxiv.org/abs/2209.12373)）。

因而，当前最好的结果故事不是“合作一定带来大收益”，也不是“几点充电是唯一主线”，而是：**空间组织先获取主要的成本与能源效率，合作修复尚未理顺的跨车场分工，预测驱动的前夜充电再削减剩余电力排放。**

## 3. 原创性的诚实边界

现在可辩护的候选贡献，不是单个方向或某个大百分比，而是在同一批严格可执行的实体车多趟排班上，依次隔离并计量三层价值：客户责任的空间组织、跨车场重新分工的剩余价值、固定配送方案后的预测充电价值；并把局部充电减排放回油电混合系统的总排放分母。

这仍是候选贡献，不是已经完成的文献无重复证明。定稿前必须对最相邻的协同配送、混合车队、多趟排班和碳感知充电文献群逐项对照。算法贡献由已封存的算法比较和待完成的部件拆分单独支撑，不借管理发现冒充。

## 4. 尚未回答的问题

公平检验还要回答：系统总收益出现后，两家车场是否都愿意接受，公平要求提高多少成本。它是否与协同价值合并为一个上位章节，等数据出来再决定。

动态检验还要回答：新增、取消和需求变化发生后，已执行的路线不能撤回时，前述收益还能保留多少。算法部件拆分仍要回答“算得好是哪些部件带来的”。这三项没有数据前，正文不预写方向。

## 5. 当前优先级与禁区

当前的空间组织、协同和预测充电证据已封存，不再加档、加随机次数或调参救方向。下一批新实验仍按“先最小探针、后必要全量”执行。不把合成空间交错情境写成真实企业历史，不写“合作必然省车”，不把趟间空档缩短单独当成效率证明，不只报充电环节的较大百分比而隐去运营总排放的较小百分比。

配送算例继承 [Goeke 与 Schneider（2015）](https://doi.org/10.1016/j.ejor.2015.01.049)建立在污染路径基准上的混合车队算例；原始基准论文明确说明节点代表英国城市（[Bektaş 与 Laporte，2011](https://doi.org/10.1016/j.trb.2011.02.004)）。项目已合并三班任务、增加第二车场并重算欧氏距离。九张网络的最大点间距离约 169–248 公里，因而正文称“基于英国城市坐标构造的区域/城际配送场景”，不称“真实英国道路运营”或“城市末端配送”。
