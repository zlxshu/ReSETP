## 问题 1：怎么给"把分配放在优化之后"辩护？

**结论（FACT）：两篇论文都没有专门论证"为什么先优化再分摊"，都是直接采用这个顺序，把它当作合作博弈成本分摊问题的定义性步骤来处理，不是拿它和另一种做法（比如把公平做进优化过程）比较后选出来的。**

### 2022 论文

全文没有一段话讨论"能不能在优化过程中就把服务质量公平做进去"这个选项。结构是纯流程性的：

- 第 2730 页（PDF p10）把方法明确切成两个阶段，原文分别列出 Step1–Step6（第一阶段）和 Step7–Step10（第二阶段）：
  > "Step7：**协作任务完成后**，根据平台存储的历史数据和实时数据…对联盟成员进行服务质量评价"（第 2730 页，24 字）
- 表 5（第 2725 页）显示，14 个服务质量指标里有 5 个（A5、A11、A12、A13、A14）的数据来源标注为"实时数据"，其中 A13、A14 明确写"协作优化数据"——也就是说，这些指标本来就只有等路径方案和协作任务跑完之后才能算出来。

这构成一个**结构性原因**（INFERENCE）：服务质量指标里有一部分定义上就依赖协作执行后的实际数据，所以调整步骤在时间上只能排在优化之后。但论文没有把这个原因写成一段"为什么不能事前做"的论证，只是隐含在数据来源表里，读者需要自己拼出来。

### 2019 论文

同样没有讨论时序选择本身。第 1519–1520 页（PDF p03–p04）把问题定义为两个计算环节，原文：

> "协作配送的成本分摊问题是典型的组合优化合作博弈问题，需要两个计算环节：1）对优化问题建模，以用于求解成本分摊方法所需要的输入数据；2）采用合作博弈中的成本分摊方法"（第 1519–1520 页，48 字，跨页）

这段话把"先优化、再分摊"写成了合作博弈框架本身的定义性要求——因为要套用 Shapley/核仁这类建立在特征函数博弈 $(N, c)$ 上的解概念，就必须先有每个子联盟 $S$ 的特征值 $c(S)$，而 $c(S)$ 对协作配送问题而言就是"子联盟 $S$ 单独求解一次协作 VRP 得到的最优成本"（第 1518 页：**"求解一个联盟的协作配送成本等价于优化一个协作配送问题"**，20 字）。

**结论（FACT）**：这不是"两种时序方案里选了一种并论证"，而是"选定了合作博弈+特征函数框架，这个框架本身要求先有 $c(S)$"。论文没有讨论、也没有引用任何把公平/参与约束做进优化过程本身的替代思路（即 Soriano 2023 那种做法），两篇论文全文都没有出现类似"事前""ex ante""优化中保证参与"的表述——见问题 6。

## 问题 2：怎么定义"退出值/单干基准"？

**结论（FACT）：两篇论文的退出值（单干成本）都不是来自企业现状运营数据，而是用和联盟成本完全同一套 VRP 求解方法，把单个企业当成"只有 1 个成员的子联盟"重新求解一次得到的。分摊对象是成本，不是利润；两篇论文都没有讨论跨企业的收入归属问题。**

### 单干成本怎么算出来的

2022 论文：模型定义本身就把"任意 $n$ 个企业组成的子联盟"作为通用对象处理，单个企业只是 $|S|=1$ 的特殊情况，走的是同一个 ALNS 算法（第 2727 页，3.4 节）。可以直接用数据核实——表 8（第 2732 页）第 1 行 "$S=\{4\}$" 那一行的协作前后距离/成本完全相等（492.7/492.7，594.2/594.2），因为单成员"子联盟"协作前后是同一个解；这个 594.2 与表 9（同页）里"企业 4 单独配送成本 $C_4=594.2$"完全一致，证实两者是同一次计算的产物。

原文措辞（第 2724 页）："每个企业的分摊成本 $x_i$ 必定小于该企业独立配送的成本 $C_i$" ——这里的 $C_i$ 就是单干 VRP 解，不是账面历史成本。

customer/需求数据本身是构造的：第 2731 页写明"客户随机分布在边长为 70km×70km 的正方形区域内"、"客户需求量 $q_i$ 为随机数"；只有 14 个服务质量指标里的基本指标（关系/运营/成本绩效，A1–A10）来自真实的顺丰/中通/圆通/申通官方年报、国家邮政局通告等（第 2725 页，表 5）。也就是说：**企业身份和服务质量数据是真实的，但客户地理/需求数据是构造的，单干成本是在这个构造实例上重新优化出来的，不是四家企业各自的真实历史配送成本。**

2019 论文：同样的结构。模型（第 1520 页，3 节）"通过引入表示子联盟成员归属信息的二进制变量，建立能够批量求解指定联盟中包括的所有子联盟协作成本的量化模型"，单企业子联盟按同一模型求解。实验部分（第 1528 页）用的是"某城市 4 个牛奶配送企业"的构造算例（不是具名真实企业），客户坐标是给定的数值表，未标注来源于真实历史订单还是构造生成。表 2（第 1529 页）显示 $c(\{1\})=504.7$，与后文（第 1530 页）"协作前 4 个企业的配送成本 504.7、459.6、510.0 和 531.1"一致，同样证实单干成本是重新求解出来的。

### 分摊对象：成本还是利润

**FACT**：两篇论文自始至终都是**成本分摊**（cost allocation / cost sharing），特征函数 $c(S)$ 定义为子联盟协作配送的总成本（运输成本+车辆固定成本，2022 论文式 3；2019 论文式 1）。全文没有出现"利润分摊""收益分摊"或利润相关的特征函数 $v(S)$——2019 论文表 4 引用其他 5 篇文献时出现了 $v(S)$（"获利"），但那是在转述**别的论文**的数据用于验证 AIA 算法正确性，用公式 $c(S)=v(N)-v(S)$ 把利润博弈转成等价成本博弈（第 1532 页），不是这两篇论文自己的分摊对象。

### 跨企业收入归属

**未找到**。两篇论文都没有讨论客户订单交换之后，原属企业和实际配送企业之间的收入怎么分——2022 论文虽然有一个"协作前后价差补偿"指标（A14，表 4），但那是服务质量评价体系里的一个负向指标（衡量交换订单造成的配送费差额，用于服务质量评分，不是收入结算规则），论文没有把它上升为收入归属的一般性讨论。2019 论文完全没有涉及收入侧，只有成本侧。

## 问题 3：分配规则的完整数学形式，以及为什么选这个规则

### 2022 论文：Shapley + 服务质量调整

**经典 Shapley（第 2728 页，式 17，FACT，清晰页）**：

$$x_i = \sum_{S \subseteq N,\, i \in S} \frac{(|S|-1)!\,(n-|S|)!}{n!}\big[C(S) - C(S\setminus\{i\})\big]$$

原文对该规则两条性质的陈述（第 2728 页）："$n$ 个企业成本分摊值加和等于大联盟总成本 $C(N)$"；"每个企业的分摊成本 $x_i$ 必定小于该企业独立配送的成本 $C_i$"。

**为什么要调整经典 Shapley（第 2728 页，FACT，清晰页，直接引用）**：
> "由于 Shapley 值法的对称性假设，合作成员的个体差异被忽略…因此有必要对分摊值进行调整，使得企业服务质量与分摊值相对应，提升分摊公平性"（40 字）

**14 项服务质量指标（表 4，第 2725 页，FACT，清晰页）**，四个一级维度、各含若干二级指标：

| 一级指标 | 二级指标（编号） | 方向 |
|---|---|---|
| 关系绩效 | A1 受理需求所等待的时间 | 负 |
| | A2 响应时间便利程度 | 正 |
| | A3 配送人员知识经验 | 正 |
| | A4 企业社会声誉 | 正 |
| 运营绩效 | A5 操作流程及客户观察透明度 | 正 |
| | A6 配送周期 | 负 |
| | A7 配送网络覆盖率 | 正 |
| | A8 准时送达率 | 正 |
| | A9 运输能力与需求匹配程度 | 正 |
| 成本绩效 | A10 运价水平 | 正 |

指标来源（表 5，第 2725 页）：A6、A8 来自国家邮政局快递服务测试通告；A4、A7、A9 来自企业年报；A3 来自企业社会责任报告；A1、A2、A10 为企业官方运费时效公告；A5、A11、A12 为企业协作时上传数据；A13、A14 由协作优化数据计算。

**权重怎么定的（第 2725 页，式 1–2，FACT）**：熵值法（客观赋权）和层次分析法（主观赋权）各算一套权重，再用"博弈论综合赋权法"求两者的最优线性组合系数 $\alpha_1,\alpha_2$（最小化组合权重与两套初始权重之间的离差和，是个类似 Nash 均衡协调的极小化问题，式 2）。实验里实际算出的组合系数（第 2733 页）：$\alpha_1=0.0723, \alpha_2=0.9643$，归一化后 $(0.0698, 0.9302)$——即层次分析法（主观）的权重占了绝大部分，熵值法权重占比很小。论文对这个赋权法本身的合理性只给了一句引用性陈述（第 2725 页）："已有文献证明博弈论方法可以对指标进行更为合理的评估"，没有给出与其他组合赋权法的对比论证。

**服务质量综合评定值（第 2728 页，式 18–21，FACT）**：先对 14 个指标数据矩阵做去均值处理（$\alpha_{ij} = a_{ij} - \bar a_j$，式 19），乘以对应权重得综合权重矩阵（式 20），再按正/负指标分组求和：$YW_i$=正指标权重和，$XW_i$=负指标权重和，综合评定值

$$QW_i = YW_i - XW_i$$

（第 2729 页明确写出这个减法关系："$QW_i = YW_i - XW_i$"）。$QW_i \ge 0$ 表示企业 $i$ 服务质量高于联盟平均水平。

**调整公式（第 2729–2730 页，式 22–23；此处第 2729 页 PDF 原文 OCR 质量差，已用第 2730 页的流程复述交叉核实，变量下标以复述页为准）**：对除大联盟外的每个子联盟 $S$，考察其中任意两个成员 $i,j$：若 $i$ 的服务质量评定值高于 $j$（即协作中 $i$ 帮 $j$ 配送了部分客户订单），则计算 $i$ 为 $j$ 配送的订单数量 $R_{ij}$，将 $R_{ij}$ 与两者评定值差 $(QW_i-QW_j)$、惩罚成本系数 $\eta$ 相乘，累加进子联盟的调整后成本：

$$AC(S) = C(S) + \eta \sum_{i,j\in S,\, i\ne j} \max(QW_i - QW_j,\,0)\cdot R_{ij}, \qquad S\subsetneq N$$

大联盟成本 $C(N)$ 保持不变（第 2729 页："对除大联盟之外的子联盟成本进行调整"）。再对调整后的 $AC(S)$ 套用同一个 Shapley 公式（式 23）得到最终分摊值 $\Delta x_i$。文中明确的效果描述（第 2729 页，经交叉核实）：含低质量成员的子联盟调整后成本不低于原值，含高质量成员的子联盟调整后成本不变；据此 Shapley 规则会让低质量企业最终分摊值上升、高质量企业分摊值下降，且总和仍等于 $C(N)$（第 2734 页式 24 验证了这一点）。

**这个调整为什么合理，论文给出的理由（FACT，非防御性表述，是论文原文态度）**：第 2724 页——"服务质量较高的企业能够获得更多的成本节约，而服务质量低于联盟平均水平的企业则需为质量差距付出相应的代价"；第 2723 页（该页 OCR 质量差，大意可辨）大致是"服务质量较高的企业应当获得更多的节约以抵消潜在损失，服务质量较低的企业则应付出相应成本"。论文没有给出这个调整规则满足哪些公理性质（比如它是否仍然是合作博弈里"公平"的某个公理化解概念），只给了直觉性的因果描述加数值实验验证。

惩罚系数 $\eta$ 取值：主实验里直接设 $\eta=1$（第 2731 页），第 2737 页的极端情形敏感性实验里改设 $\eta=2$，论文没有讨论 $\eta$ 应该怎么标定，只做了取值敏感性的展示。

### 2019 论文：核仁解 + 近似迭代算法（AIA）

**核约束怎么写（第 1524 页，FACT，清晰页）**：转归解（imputation）集合

$$I = \{x \in \mathbb{R}^n \mid x(N)=c(N),\ x_i \le c(\{i\})\ \forall i\}$$

核心解（core）集合：

$$\text{core} = \{x \in \mathbb{R}^n \mid x(N)=c(N),\ x(S) \le c(S)\ \forall S \subsetneq N,\ S\ne\varnothing\}$$

不满意度（excess）：$e(S,x) = c(S) - x(S)$。核仁解定义为使子联盟不满意度向量（按降序排列）字典序最小的转归解：$Nu = \{x^* \in I \mid \theta(x^*) \le \theta(x)\ \forall x\in I\}$，其中 $\theta(x)$ 是把所有 $e(S,x)$ 按从大到小排序得到的向量。

**为什么选核仁解而不是别的规则（FACT，摘要+引言+结论三处重复表态，一致）**：
- 摘要（第 1517 页）："核仁解由于具有唯一性和公平性等特点，是成本分摊领域中公认的科学分摊方案"（25 字）
- 引言（第 1518 页）："核仁解因具有唯一存在性和处于核心解…几何中心位置等特点，受到众多学者的重点关注"
- 结论（第 1533 页）："核仁解具有唯一存在的特点，并且当核心解存在时核仁解会处于核心解的几何中心位置，因此是当前被公认的公平成本分摊方案"

三处表态口径一致：核仁解被选中的理由是唯一性 + 核心解几何中心位置，不是和 Shapley/MCRS 等规则逐条公理对比后选出来的，是引用"学界公认"作为理由。

**精确方法是什么、为什么不用（第 1524–1525 页，FACT，清晰页，直接引用）**：精确解法是循环求解线性规划（Kohlberg 1972 提出，式 33–37；后续 Owen 1974 等改进）：

$$\text{LP}_k:\ \max \varepsilon_k \quad \text{s.t.}\ \sum_{i\in S} x_i + \varepsilon_k \le c(S)\ \ \forall S \not\subset T_k,\ \ldots$$

论文明确指出这条路的两个难点（第 1525 页，原文）：
> "采用上述线性规划模型求解核仁解具有两个难点：1）每个模型均包含 $2^n+n-1$ 个约束条件；2）准确确定 $T_k$ 中包含的子联盟"

> "当前求解核仁解的文献中就有不少出现了类似错误"（15 字）

> "**这也是本文设计迭代逼近算法（AIA）求解核仁解的动机**"（19 字，第 1525 页）

这是全文里唯一一句直接讲"为什么不用精确方法"的话——理由是约束数量指数级、且容易在确定紧约束子联盟集合 $T_k$ 时出错（第 1532 页表 4 用 5 篇已发表论文的错误案例佐证了这一点，AIA 重算后发现这 5 篇论文的核仁解全部有偏差）。

**"近似"具体近似在哪一步（重要区分，FACT）**：AIA 算法本体（不含加速策略）在理论上对**凸博弈**是精确收敛到核仁解的——第 1526–1527 页定理 3–5 证明了"每次迭代都让当前转归解更接近核仁解"，且凸博弈下极限点唯一等于核仁解；第 1531 页的复杂度表（表 3）里，不加策略的纯 AIA 在能对比精确解的规模下 Dev% 也只有 1%–3%（这里的偏差来自实现时设了最大迭代次数上限 MaxIter，不是算法原理性偏差）。真正引入近似的是**策略 2**（第 1527–1528 页）：精确算法每步都要遍历全部 $2^n-2$ 个子联盟求最小不满意度 $S_{ij}(x)$，策略 2 改成只在满意度落在区间 $[e_{\min},\, e_{\min}+\beta(e_{ave}-e_{\min})]$ 内的子联盟里近似搜索，把这一步复杂度从指数级降到多项式级（$O(n^3)$），代价是核仁解的偏差从 0 变成一个很小的正数——实验里（第 1531 页表 3）平均偏差低于 0.02%，最大到 0.03%。**换句话说，"近似"不是对核仁解定义本身的近似，而是对"精确定位哪个子联盟最不满意"这一步的近似搜索**，用可控的小数值误差换取复杂度从指数级降到多项式级。

**局限性（第 1533 页结论，FACT，原文自陈，非本报告推断）**：
> "AIA 对于非凸博弈成本分摊问题，虽然在本实验中均求解得到核仁解，但从理论上不能保证一定得到精确的核仁解"

这与前面理论证明的适用范围（第 1521–1524 页定理 1–2：只有在顾客位置均匀分布假设下才能证明协作配送问题是凸博弈）是同一件事的两面——理论保证只覆盖凸博弈，非凸情形下 AIA 退化为"预内核解"（prekernel）的一种近似求法，论文承认这一点但没有给出非凸情形下的补救方案。

## 问题 4：怎么处理"合作总节省为负"或"核为空"的算例

**结论（FACT，两篇论文通读后确认）：两篇论文都没有出现过、也没有讨论过合作节省为负、某成员必然吃亏、或核为空的情形。所有数值算例里，每个成员在每个子联盟组合下的成本节约百分比都是非负的。**

具体证据：

- 2022 论文表 8（第 2732 页）列出全部 15 个子联盟的成本节约百分比 $sc\%$，从 0.00%（单成员，无协作）到 52.57%（大联盟），全部非负，没有一行是负数。
- 2022 论文第 5.3.3 节（第 2736–2737 页）专门设计了"依据企业在联盟中的重要性设计算例"，对比任意三企业联盟和大联盟——目的是说明某个成员对其他成员的边际贡献大小，但即便如此，表 16、表 17 里所有 $PSC\%$（节约百分比）依然全部为正；表 17 里特意构造了服务质量差距极端的情形（$QW_1=6$ 和 $QW_1=26$，惩罚系数 $\eta=2$ 的严厉处罚场景），四个企业的节约百分比仍然全部落在 35%–91% 区间，没有一个变成负数。论文在这一节讨论的是"惩罚机制会不会逼企业提高服务质量"（第 2737 页："惩罚机制的存在使得联盟成员倾向于提高服务质量"），不是"某企业会不会因为协作反而更亏"。
- 2019 论文的凸博弈证明（定理 1–2，第 1521–1524 页）本身保证了在顾客均匀分布假设下博弈具有超可加性（$c(S\cup T) \le c(S)+c(T)$），也就是从模型假设上就排除了"协作后总成本反而更高"的情形；论文也明确承认这个假设在现实中未必成立（第 1524 页："现实中顾客分布状态难以满足完全均匀分布，因此很多实际中的协作配送的成本分摊问题不一定会是凸博弈问题"），但没有讨论如果假设不成立、核为空时应该怎么分摊——核仁解本身作为一个解概念，数学上无论核是否为空都唯一存在（这是核仁解相对核心解的优势，论文引言里提到过这一点，第 1518 页），但论文没有专门用一节讨论"核为空时核仁解会给出什么样的结果、某些成员是否会被要求承担高于单干成本的分摊额"这个问题。
- 2019 论文实验部分（表 2，第 1529 页；表 14，第 1530 页）里核仁解 $x^*=(336.24, 293.64, 331.26, 253.06)$ 对应的节约百分比 33.38%、36.11%、35.05%、52.35%，同样全部为正。

## 问题 6：有没有讨论"事中/事前保证参与"

**结论（FACT，两篇全文通读后确认）：未提及。两篇论文全文都没有出现"事前""事中""ex ante""参与约束""公平约束嵌入优化"一类的表述或做法。**

两篇论文的方法论姿态是一致的、单向的："先用 ALNS/三阶段启发式把 $2^n-1$ 个子联盟的 VRP 全部解出来，得到成本 $C(S)$；再对 $C(S)$ 套用分摊规则（Shapley 或核仁解），事后判断结果是否满足个体理性（$x_i \le c(\{i\})$）"。这个个体理性条件本身是分摊解概念（转归解/核心解）定义的一部分，两篇论文都只是在事后检验或者数学上保证这个条件成立（比如 Shapley 值和核仁解都能证明落在核心解的必要条件区间内），没有讨论"能不能在生成候选路线方案的过程中就实时判断某个企业会不会吃亏、如果会吃亏就调整搜索方向"这类做法。这与 `docs/handoff/e6_participation_ex_ante_20260731/report.md` 报告里核实过的 Soriano 2023（把公平约束做进 ALNS 的重构和局部搜索环节）是完全不同的两条路——本次通读确认，目标期刊这两篇论文都不属于 Soriano 那条路。
