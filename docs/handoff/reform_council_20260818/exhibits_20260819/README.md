## 表12两方同值与转归集

本表只讨论两家企业的可转移效用成本博弈。总协同收益为

`c({A}) + c({B}) - c({A,B}) = 888.8726959573132 CNY`。

两方 Shapley 与核仁都把这项收益各分一半，所以本表把两种规则写成同一分摊成本，规则间极差为 `0.0 CNY`；这个同值结论明确限定在本次两方情形，不外推到三方及以上。两方成本博弈的转归集区间由个体理性与预算平衡直接得到：

- `ENT_A: [c({A,B})-c({B}), c({A})] = [1180.0246771843133, 2068.8973731416263] CNY`；
- `ENT_B: [c({A,B})-c({A}), c({B})] = [964.3086035691431, 1853.181299526456] CNY`。
