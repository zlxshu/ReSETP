# ReMIX PR17A 行为门审计更正

- 日期：2026-07-19
- 合同：`REMIX-BEHAVIOR-PR17A-001`
- 原证据：
  `baselines/algorithm_foundation/remix_pr17a_behavior_gate_20260719`
- 权威证据：
  `baselines/algorithm_foundation/remix_pr17a_behavior_gate_v2_20260719`

原证据的算法行为、最终解、独立复算结果和哈希均有效，但复核发现两处报告代码的
口径不够严：

1. 独立检查在总运行器中实际执行了五次，工作器的组件计数里却留下了一个值为零的
   占位字段；
2. “三个岛进入路线库”读的是三个岛的生成事件，没有直接读取路线库输入来源。

更正没有改变算法、种子、题目、预算、筛选规则或通过标准。v2 只删除误导的占位
字段、把五次独立检查记入总账，并从路线库真实输入清单核对三个岛。原证据保留作
历史现场，不再作为行为门的权威引用。
