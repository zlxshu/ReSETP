# ReMIX PR17A 多重混合行为门合同

- 编号：`REMIX-BEHAVIOR-PR17A-001`
- 日期：2026-07-19
- 状态：`PRE_REGISTERED__EXECUTION_ALLOWED`
- 所属审批：`EA-COMPARE-002`
- 题目：`PR17A`
- 随机种子：`1`
- 预算档：`0 / 1 / 2 / 5`
- 性质：接线与行为检查，不是性能试验

## 1. 这一步要证明什么

这一步只回答一个问题：几个算法工种是否真的共用同一份解，并把前一工种产出的
方案交给下一工种继续处理。

它不回答 ReMIX 是否胜过外部算法，不寻找参数，不刷新 BKS，不允许据此写论文
优越性结论。若接线门不过，六题开发块、28 题主表、China81 和阶段二继续关闭。

## 2. 冻结的四个工种

### 2.1 三岛 ILS 撒网

母算法采用仓库锁定的 PyVRP `0.13.4`。该版本的正式 `solve()` 实现是
Iterated Local Search，不是旧版 HGS。行为门固定建立三个独立小岛，种子流为
`1 / 1001 / 2001`，每岛只跑 `2` 次迭代。三个岛的作用只是提供不同路线结构，
不是在 PR17A 上调性能。

### 2.2 多父代路线交换

以一个岛的完整解为底稿，从另外两个岛各取一条不同的可行路线，覆盖到底稿中：
被供体路线服务的客户先从底稿原路线删除，再加入供体路线。只有覆盖完整、客户
不重复、各车场车辆数不超限的子代才可流入下一工种。

供体路线按“新边数量优先、距离次优”的固定顺序选择。该规则只用于让不同岛真正
交换结构，不在本题上试参数。

### 2.3 多车场—时间窗定向拆解重建

每个循环只拆一个长度为 `2` 的连续客户段。候选段先按两类公开题真实约束排序：

1. 客户相对当前车场与最近其他车场的距离差；
2. 客户时间窗余量。

被拆客户使用 regret-2 插入逐个放回。每个插入位置都用 PyVRP 路线对象检查容量、
时间窗、路线时长和车场车辆数；不得把不可行子代交给下一工种。这个动作只称为
“有界拆解重建”，不冒充一整套独立 ALNS。

### 2.4 PyVRP 邻域精修与精确路线会审

拆解重建后的完整子代进入 PyVRP `0.13.4` 的正式 LocalSearch，使用该版本默认
支持的节点和路线动作做一次完整精修。

三个岛和所有精修子代的路线进入同一个精英路线库。路线库用
`scipy.optimize.milp` 做一次 0-1 精确选择，约束为：

- 每个客户恰好被一条路线服务；
- 每种车辆类型的选中路线数不超过该车场可用车辆数；
- 只选择原本已经可行的路线；
- 目标为 V13 公开题的整数总距离。

精确会审产物还须重新构造成 PyVRP 解，并通过仓库独立检查器；MILP 求得数学可行
但业务检查不通过，仍判失败。

## 3. 预算含义

预算 `b > 0` 时，三岛各生成一次，然后依次执行 `b` 个完整循环：

`多父代路线交换 -> 定向拆解重建 -> PyVRP 邻域精修 -> 回灌精英库`

最后只调用一次精确路线会审。预算 `0` 时四个增强工种全部不得调用，结果必须与
同一次运行中的母算法逐位一致。

这些数字只为覆盖代码分支：

- `0` 检查能彻底关闭；
- `1` 检查最短完整供料链；
- `2` 检查重复调用与记账；
- `5` 检查有限循环仍不漏客户、不超车辆。

它们不是论文参数，不得在看过结果后解释成性能配置。

## 4. 通过标准

全部满足才判 `PASS_REMIX_PR17A_BEHAVIOR`：

1. 预算 `0` 的增强调用数为零，且与母算法确定性签名完全相同；
2. 预算 `1 / 2 / 5` 的路线交换、拆解重建、邻域精修调用数分别等于预算；
3. 每个正预算只调用一次路线会审，三个岛的来源都进入过精英路线库；
4. 至少一条子代谱系明确包含
   `island -> route_exchange -> destroy_repair -> local_search -> elite_pool`；
5. 所有进入最终候选集的解完整、可行，并通过独立检查；
6. 搜索、精修、MILP 和独立复算分开记账；
7. 产出 `metadata.json / raw_runs.csv / decision.json /
   artifact_hashes.json / report.md`，哈希可复核；
8. 没有修改 `cost.py`、`check.py`、`search/evaluation.py`。

路线会审若只选中一个来源，但其他接线条件全部通过，判
`HOLD_ROUTE_POOL_CROSS_SOURCE_UNPROVEN`，不得把“多个来源进入路线库”写成
“多个来源被会审采用”。

## 5. 立即停止条件

出现以下任一项立即停，不在 PR17A 上改参数救援：

- 增强关闭后改变母算法结果；
- 客户丢失、重复、路线不可行或车辆数超限；
- 任一昂贵调用没有计入自己的账；
- 某个工种只被调用但没有接收上游产物；
- 需要增加迭代、换种子或改筛选规则才能让报告好看；
- 需要进入六题开发块、China81、阶段二或正式外部跑分。
