## 1. 完成判定原则

## 3. hooks事件后的唯一收口顺序

1. 接收 hooks 的完成或异常事件。异常时保留现场并按其状态停止；完成时才读取正式 `decision.json`、`artifact_hashes.json` 和五记录面。
2. 对正式E7五记录面执行清单与任务矩阵检查，并运行`baselines/e7_dynamic/audit_e7_external_pause_timing_20260716.py`；任何阶段耗时若不小于已记录的13934秒外部暂停时长，均视为时效污染，不进入下游重放。若正式判决不是允许的完成状态或暂停污染门失败，不运行论文生成器，不扩大预算修饰结果；因外部暂停而失败时，只能按同一合同和断点重跑未获得无污染完成的原任务。
3. 确认正式重放目录不存在或为空后，运行 `baselines/e7_dynamic/e7_multiday_zero_search_replay_20260715.py`，生成28日电网日零路径搜索重放五记录面；若目录非空，保留现场并停止，不让旧干运行或失败残留混入正式清单。
4. 运行 `baselines/e7_dynamic/audit_e7_replay_invariants_20260715.py`，生成独立重放不变量五记录面。
5. 确认独立总审计目录不存在或为空后，运行 `baselines/e7_dynamic/audit_e7_multinetwork_formal_20260715.py`，生成独立总审计五记录面；脚本对非空旧目录硬拒绝覆盖。
6. 运行 `baselines/paper_story/build_20260715_formal_evidence.py`，生成E7七件论文展品；不得人工改写生成文件来改变方向。
7. 根据生成证据终修正文衔接和管理启示；中英文摘要、结果解释和结论的定量句由生成文件承担，不重复手工抄数。
8. 在HANDOFF、总memory、动态memory和PRD memory同步写入正式收口记录与统一标记。
9. 用统一XeLaTeX入口重新编译；检查实际输入时序、日志、A4页、正文提取与代表页视觉。保留`STHeitiSC-Medium`的ToUnicode警告，除非有经验证的等价母版修复。
10. 运行不带`--allow-pending-e7`的故事审计，再运行E7/论文定向回归、必要全量回归、`git diff --check`和保护源零漂移检查。只有全部命令各自成功且矩阵所有项均已证明，才允许报告总目标完成。

## 4. 明确禁止的捷径

不得把预检结果替代正式结果；不得因正式方向不理想删除失败流、换实例、调种子或扩大预算；不得把840行重放称为路径—充电联合优化；不得把滚动阶段当独立样本；不得只看净收益而隐藏收入、成本和服务量；不得以pending故事审计、局部测试或PDF可打开作为全目标完成证明；不得在正式E7完成前写入最终收口标记。
