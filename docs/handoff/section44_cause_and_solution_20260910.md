## 一、原因（4.4.2）
一句话：唯一存在"省钱与减排冲突"的窗口是首趟出车前（36% 电量），冲突价码 4.09 元/kg 是基准碳价 0.20 的 20 倍；总排放 64% 是燃油直排，车队卡在平价点，碳价 0.2 推不动。
1. 冲突只在首趟前窗口。午休/趟间窗口最便宜与最干净时刻相邻（12:19–13:00），三种看信号安排均已利用；只看碳较兼顾在该两窗口仅少 1.7 kg。
2. 首趟前：改干净时段每 kWh 多付 0.585、少排 0.143 → 4.09 元/kg；基准 0.20 下兼顾跟电价进谷段、只挑谷段末端 06:00；同方案上兼顾比即充多排 12.6 kg、比只看电价少 3.3 kg（零成本同价择时）。
3. 调时空间：放松窗口 36.9 kg；窗口锁≈18 kg（任何规则不可达）；价格锁≈18 kg（去干净时段 2 元/kg）。
4. 燃油直排 64.1%；3/3 与 4/2 差 4.00 元；各臂车队差异带来的排放波动（±12 kg）与调时效应同量级 → 基准下四臂比总排放是噪声。
5. 撤：原稿"增派电动车→回场提前→首趟前补电进入傍晚低碳时段"。四条件下首趟前补电开始中位均为前日 17:44–17:51，回场未提前。

## 二、解决方案（4.4.3）
一句话：两个条件各解一把锁——谷段对齐光伏时段解午休/趟间与电费；碳价过 0.5 解首趟前窗口、过约 1 推车队；两者到位后本文安排相对两种不考虑碳强度的做法同时省钱减排，车队仍混合。
- 谷段设在午间（政府/电网，零财政支出）：午休/趟间兼顾＝只看碳（24.86 对 24.86），充电费 −40 元；不解决首趟前（日历仍有 1–6 夜谷）。
- 碳价 ≥0.5：首趟前补电 2:00→5:00，+7 元/−14~15 kg（0.46–0.50 元/kg），116 份 100% 同向，北京与午谷时段均成立——本文机制自己的、可复现的那一块。
- 碳价 ≈1.0：电动车 3.3→4.4 辆（仍混合），燃油直排 −48 kg；由碳价推动，非充电规则专属。
- 合计（午谷×1.0）：对即充 −112.05 元/−51.51 kg；对只看电价 −20.56/−27.47（调时 −13.80、车队反馈 −13.67）；只看碳仍少 7.15 kg，但为 4.16 元/kg，碳价 1.0 下不应采纳——它是排放参照，不是本文安排的失败。
- 明说管不了的：首趟前最后 7 kg 需 4 元/kg 碳价或回场提前到下午低碳时段（动班次合同），本文不做。
