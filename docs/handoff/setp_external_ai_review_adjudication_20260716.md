# 外部中文 AI 审稿意见裁决记录（2026-07-16）

## 裁决原则

本记录把 DeepSeek、Kimi 等工具的意见视为待检验假设，不视为审稿事实。裁决顺序为：先查当前 TeX、PDF 和正式实验记录，再判断意见属于真实缺陷、需要补写的研究边界、定位调整，还是由 PDF 抽取/旧版本/误读造成的错误指控。任何会改变冻结模型、评价器、预算、种子或正式实验结果的建议，均不得仅凭外部 AI 意见执行。

## 已确认并修复的真实问题

| 外部意见 | 裁决 | 证据与处理 |
|---|---|---|
| PDF 中文乱码或标题不可读 | 部分成立，根因不是 TeX 源码损坏，而是原中文黑体缺少可移植的文本映射；替换为 Hiragino 后虽可抽取，但 Poppler 又不能稳定显示 | 改用 Arial Unicode MS 作为中文黑体回退，并显式修复首页标题样式。新 PDF 中标题、摘要、关键词、图表题均可见且可由 `pdftotext` 正确提取；20 页 A4 编译通过 |
| TVCI、ALNS、UCB 首次出现未解释 | 部分成立 | ALNS、TVCI 已在首次实质使用处给出中英文全称；UCB 已补为“置信上界（upper confidence bound，UCB）” |
| 10、3、5 次重复口径不一致 | 成立，原稿解释不足 | 正文已区分算法随机分布的10个种子、静态机制的3个成对种子、动态实验的5条预先固定事件流；三者不是同一类重复 |
| 28 个电网日选择规则不清 | 成立 | 已明确为2025年11月2日至29日的连续28日，不按结果方向筛选 |
| 零跨场摩擦成本缺乏解释 | 成立，但不自动要求新增敏感性实验 | 已明确 `c^{tr}=0` 用于识别没有组织协调成本时的协同收益上界，不能解释为企业扣除谈判、信息和管理成本后的净收益 |
| 算法表缺少随机波动 | 成立 | 表5新增跨种子变异系数；TVCI-ALNS与LNS分别为4.08%和4.02%，正文明确两者波动接近，不能声称稳定性优势 |
| “墙钟计算时间”“顺序插单”不够正式 | 成立 | 分别改为“实际计算时间（wall-clock time）”和“顺序插入基线”；同步修改生成器、正文和测试 |
| 摘要将1.90%与0.39%写成区间 | 成立 | 改为地理聚集与空间交错情形分别增加1.90%和0.39% |
| 分阶段搜索被包装为稳定算法贡献 | 成立 | 摘要、结论和算法定位改为“含跨场重组算子的ALNS”；保留组件事实，并明确分阶段搜索本身未形成稳定增益 |
| 中国应用外部效度、排放边界、固定功率充电边界不足 | 成立，属于适用边界而非当前模型错误 | 结论已明确：英国价格不能直接作为中国企业定量估计；当前只核算运营直接排放和购入电力间接排放；固定功率近似未描述高SOC功率衰减；面向国内应用需用区域分时因子和国内碳价复算 |
| 滚动重规划被误解为全局最优动态策略 | 需要主动设界 | 已明确它只优化冻结历史后的剩余任务，不声称得到覆盖全日未来信息的全局最优策略 |

## 经核查不成立或不能照单执行的意见

| 外部意见 | 裁决依据 |
|---|---|
| “全部图片缺失、只有占位符” | 当前 PDF 中图1至图7均已嵌入。图5和图6经实际渲染检查，不存在所述的整图缺失；此意见来自抽取器未读取图像或旧版材料 |
| “全文统一按60 kW充电” | 错误。正式参数为公共站60 kW、车场22 kW；当前确实采用站点固定功率，但不是所有位置统一60 kW |
| “持续时间和碳强度都用 gamma” | 错误。充电持续时间使用 `\Delta_q`，碳强度使用 `\gamma_t` |
| “TVCI和ALNS到第3.4节才定义” | 与当前 TeX 不符。两者已在引言贡献段首次实质出现时定义 |
| “28日日期不连续，可能挑日” | 错误。日期为11月2日至29日连续28日；图轴只稀疏显示刻度，不代表漏日 |
| “地理聚集的负协同结果被平均值掩盖” | 错误。正文已报告7/9改善、两网为负，并明确负值表示固定预算下未找到优于独立经营的协同解，不能直接归因为经济机制 |
| “TVCI-ALNS显著优于LNS” | 当前正文没有这一主张。正文明确与GA-VNS、LNS校正后均不显著，并保留平均名次、运行时间和波动作为描述性结果 |
| “必须废弃当前算法并改用纯LNS” | 证据不支持。LNS与主算法解质量无显著差异，但耗时更长；分阶段组件失效只支持降低该组件的创新定位，不足以推翻整个求解器和全部冻结证据 |
| “TVCI总减排小，所以必须从标题删除” | 逻辑不成立。小而稳定的边际作用及其不能替代路径减排，正是论文的对比张力和适用边界；是否保留标题应由研究问题与证据闭环决定，而不是按效应必须很大决定 |
| “必须加入全生命周期评价才可研究双碳” | 过度要求。运营边界的Scope 1与购入电力间接排放可以构成明确研究问题；必须诚实声明边界，但不应在不重做模型与实验的情况下强行接入电池制造、燃料上游和输配损耗 |
| “必须引入非线性充电，否则当前结果毫无意义” | 表述过度。非线性充电会影响外推边界，但不能据此证明本文固定功率区间内的相对充电择时比较无效。当前正确动作是限定结论并将非线性充电列为后续模型扩展，而不是污染冻结证据 |
| “动态订单取消率实际常为15%--20%，必须提高扰动” | 未提供可核查来源，不能采用。当前3网络、5事件流、约4%扰动只支持有限压力测试，正文已明确不作一般动态到达外推 |
| “空间交错必然带来更大协同收益，因此没有研究价值” | 过度简化。静态实验确实显示平均差异，但逐网并非一致；参与保障代价反而在空间交错情形更低，这是需要保留的反常识结果。可将空间交错视为控制因素，不把平均方向包装成普遍定理 |

## 当前审计结果

截至本记录生成时，论文数学审计为20项通过、0项失败、1项警告；两层模型形式化门禁为7/7通过；论文证据边界审计在允许E7待完成的模式下通过；定向生成器与边界测试通过。唯一数学警告是正式实验固定 `CE=0`，因此现有证据只能支持零配额基线，不能外推“配额由宽到紧”的规律。该项是研究边界警告，不是公式错误。

当前稿件仍不是投稿完成态。E7正式证据、E7生成表和全文最终一致性审查尚未收口；作者信息、基金、分类号、正式卷期和DOI等投稿元数据也应在投稿前按期刊要求填写，不能用占位值提交。
