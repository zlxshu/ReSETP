# 深圳 2025 年 2 月独立价区充电电价闭合

日期：2026-07-23  
判定：`PASS_SHENZHEN_2025_02_EV_CHARGING_SCENARIO_ROW_CLOSED`

## 1. 结论

原缺口不是深圳没有数值，而是旧 F3 把全国一般工商业“单一制/两部制”规则直接套到
深圳充电设施。广东省发展改革委 `粤发改价格〔2018〕313号` 对该场景有专项规则：
深圳各类已安装独立电表的电动汽车充电设施，按报装容量执行相应的大量用电或高需求
用电电价，并免收基本电费。深圳供电局 2026 年公开答复仍按同一规则说明办理口径。

因此，本文已经在 E3--E7 正式搜索前冻结的深圳数值行可以合法解释为：

`独立计量EV充电设施 / 大量用电 / 101--3000 kVA（主情景具体限定>100且<315 kVA） /
10 kV高供高计 / 每月每kVA用电量≤250 kWh / 仅收电能量价、基本电费豁免`。

2025 年 2 月尖峰、峰、平、谷分别为
`1.43716875 / 1.15526875 / 0.75776875 / 0.25716875 元/kWh`。
这与既有静态日历逐位一致，不修改任何封存数值。

## 2. 证据链

1. 广东省发展改革委 `粤发改价格〔2018〕313号`：闭合深圳独立计量充电设施的
   用电类别和基本电费豁免。
2. 广东省发展改革委 `粤发改价格〔2023〕148号` 及附件 3：闭合深圳独立价区及
   `101--3000 kVA / 10 kV高供高计 / ≤250 kWh/kVA·月` 输配电档。
3. 深圳供电局 2026-02-12 公开答复：交叉确认实际报装容量决定大量/高需求档，且
   免收容（需）量电费。
4. 保存的深圳供电局 2025 年 2 月代理购电工商业电价表扫描及 API 文本：闭合当月
   尖峰、峰、平、谷总电价。平段独立复算为
   `(51.13 + 18.04 + 3.84 + 2.766875)/100 = 0.75776875 元/kWh`。
5. 旧静态构造器在正式搜索前已选择同一数值行；本次只是把错误的“两部制电量项
   代理”标签改正为“独立计量充电设施大量用电电能量价、基本费豁免情景”。

## 3. 强制边界

本 PASS 只关闭论文表格和未来 E3--E7 的预注册构造情景，不关闭命名车场真实合同。
普洛斯深圳龙华魔方供应链大厦的实际报装容量、供电电压、计量点、月利用小时和账单
仍未知。论文只可写“情景采用/按专项规则设置”，不得写成“该车场实际执行”。

2025 年 2 月总电价数值仍由第三方数字档案保存的深圳供电局原表扫描提供；扫描标题、
表格和发布主体可见，字节与哈希已保存，但未找到原始供电局发布 URL。政策规则和
输配电价附件已经保存政府原始字节。该来源层边界不得省略。
