# T3-TARIFF-CARBON-MISALIGN：分时电价与时变碳强度的区域错位量化

## 口径与数据边界

本报告只读取 `data/ChinaInstances/china81_runtime_parameter_authority_v4_20260723/tariff_carbon_48slot_calendar.csv`。输入含 12096 行，即 9 城×28 日×48 个半小时槽；关键列无缺失，城市—日期—槽键无重复。输入 SHA-256 为 `e714b05b2e44635204681fe213dfd454e9f9009c647bad7318ce6b0ccad2004b`。碳强度为 Figshare 28953545 的 CEF Scenario S1-2025 **省级逐小时模拟投影**，逐小时值复制到两个半小时槽；不是实测、实时或边际碳强度。电价是官方价表支持下选取用户类别形成的构造情景，不是九个命名车场的实际账单。公共站总价在本输入中等于同城车场电能价加固定 0.40 元/kWh 服务费。

相关系数口径：先在每个统计范围内对 28 天（区域和全量还包括范围内城市）按 48 槽求均值，再在 48 个槽上计算 Pearson 与 Spearman；Spearman 使用并列值平均秩。极差比值定义为“（当日最高碳强度−当日最低碳强度）/当日均值”；这一口径避免部分投影日最低值为 0 时出现除零。连续 3 小时定义为日内 6 个相邻半小时槽，不跨 24:00；并列最优取最早窗口，同时报告并列窗口数。
