词语出处：

- `独立配送`：陈雨蝶、干宏程、程亮、温金鹏，《双碳背景下复杂冷链物流模型及求解算法》，图5，PDF物理页18／印刷页17；原题为“(a) 独立配送”。
- `联合配送`：陈雨蝶、干宏程、程亮，《“双碳”背景下联合配送冷链物流模型及其求解算法》，§3.2.1，PDF物理页7／印刷页1957；原文将“各配送中心共享产品、客户、车辆等资源，共同服务所有客户”称为“联合配送模式”。该词亦见陈雨蝶等（2025）图5，PDF物理页18／印刷页17，原题为“(c) 联合配送”。
- `转归解`：饶卫振、张云东、刘从虎、于灏、侯艳辉，《一种求解协作配送成本分摊问题核仁解的近似迭代算法》，§5.1，PDF物理页8／印刷页1524；原文定义为总分摊成本等于合作总成本，且每个成员分摊成本小于等于不合作成本的方案。

`(b)(c) 同属联合配送、以解条件区分`：陈雨蝶等（2023）§3.2.1（PDF物理页7／印刷页1957）把共享产品、客户和车辆、共同服务所有客户的业务定义为“联合配送模式”；饶卫振等（2019）§5.1（PDF物理页8／印刷页1524）在同一合作语境中用总成本守恒和成员不高于不合作成本的条件定义“转归解”。因此，(b) 与 (c) 的差别是解条件，不是两种配送模式。括号组合不是文献图题的逐字照录。
