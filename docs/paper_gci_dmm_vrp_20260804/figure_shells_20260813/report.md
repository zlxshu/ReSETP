### 3.2 一张还是两张

`DECISION（代理设计判断，不是用户新决定）`：**拆成两张。**

理由与依据如下：

1. `FACT`：陈雨蝶图 4 只承担多算法的时间收敛比较，正文没有用该图选正式实验预算，也没有标平台点或预算线。它只能作“算法对比收敛图”的直接母版，不能被扩大解释为“两用途合图”的文献先例。
2. `FACT`：项目 P47 冻结的次序是“收敛标定 → 定预算 → 正式实验”。预算标定图使用正式比较之前的长预算轨迹，必须越过进入平台的点并体现留余量；算法对比图使用已定正式墙钟内的多算法轨迹。两者的数据身份、生成次序和必需时间范围不同。
3. `FACT`：《图表壳规格》规定“一张图只讲一件事”，同时更正了“子图数量由内容决定”和“是图是表由目的决定”。两张图分别只回答性能比较与预算来源，符合这一组织规则。
4. `INFERENCE`：强行合图会出现两种不良结果之一：共用长时间轴会压缩正式比较的前期差异；使用双子图则实质仍是两个独立证据展品，只是共用一个图号，不能消除它们的证据区别。

### 3.3 两张收敛图壳的定型项

`FACT`：两图横轴均为“实际运行时间（秒）”，不使用迭代次数，也不抄母版的分钟单位。图壳用符号 `T`、`t_p`、`t_b` 表示占位时间，没有拍一个正式秒数。

`FACT`：算法对比图图例顺序固定为 `VCGP → MDFIHA → MDFIHA-ETGA → 本文算法`，与现行公开正式对比对象一致。线型顺序固定为实线、虚线、点划线、点线；同时使用项目既有色盲友好配色。曲线不画大圆点，不平滑，并以阶梯形保留“在职最好值只在改善时下降”的数据语义。图例固定在图内右上角。

`FACT`：预算标定图只放本文算法一条长轨迹，使用两条 0.468 pt 细竖线和细箭头分别标“进入平台期的点”与“所取预算”。平台点用一个 3 pt 空心方形定位；这是小尺寸标注，不是数据序列的大圆点。

`UNKNOWN / 占位`：正式算法名称；各轨迹的真实目标值与时间范围；真实平台点；真实所取预算。全部必须用本算法、本算例、本机器的收敛数据回填。
