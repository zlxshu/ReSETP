# 混合车队章候选图形态与占位稿

## 一、本轮边界

本轮只做文献图型核验、两个图形态候选和占位稿，不选择最终形态，不运行求解器，不改算例，不改论文正文。两张占位稿中的数值均为排版用假数，只用于检查轴、图例、线型、柱纹理和字号；图顶已显著标出“示意／占位”。

图幅实测统一采用同一口径：将 PDF 页面按 144 dpi 渲染，从图中最外侧可见内容到图题外框测量，不含相邻正文，换算后取到 0.1 cm。因此下列尺寸是版面实测值，不是作者源文件给出的尺寸；误差约为 ±0.1 cm。

- 本章自身问题由(a)回答：固定成本溢价变化时，实际派遣的油电车辆构成是否切换，以及该构成对应的总账怎样变化。日里程、电价和碳价可作为同版式的受控重复情景，不改变柱＋线图型。
