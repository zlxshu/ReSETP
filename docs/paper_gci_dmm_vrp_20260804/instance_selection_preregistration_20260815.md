**依据**（页码级，Claude 渲染原页目视核对）：饶卫振等 2022，印刷页 2731 §5.2.1 原文——

`FACT`（本项目实测，选此规则的理由）：在 `cn-jjj-50c-METRO-POOL` 上，

按奇偶交替为 5.82 km／0.386。两者都远离"按地理切开"（那会接近 1.0 以上），
分块数值略优**且有页码级先例**，故取分块。

## 三、主算例选择判据（**冻结**）

### 3.1 前置门槛（不满足即淘汰，不进排序）

1. 构造见证 `witness_status = PASS`；
2. 完整检查器违规数 `= 0`；
3. 混合车队临界带**下侧与上侧都有车**（`critical_band_below_vehicle_count > 0` 且
   `critical_band_above_vehicle_count > 0`，依 P48 用户已定判据）；
4. 服务客户与需求量**全量覆盖**。

### 3.2 排序键（唯一，不加权、不设阈值）

**一阶协同收益比例**，定义为：

```
协同收益% = ( Σ_c cost_{owner(c)}(c) − Σ_c min_d cost_d(c) ) / Σ_c cost_{owner(c)}(c) × 100
```

其中 `cost_d(c)` 为客户 c 由车场 d 直接服务（车场→客户→车场直达路线）的**完整评价器成本**，
`owner(c)` 为第二节规则确定的该客户所属企业的车场。

**取该值最大者。** 不设阈值、不设区间、不加权、不与其他量合成总分。

`PROCESS`（须用完整评价器，不得用直线代理）：本项目已多次因代理量误判翻车。
`cost_d(c)` 必须复用现有可争夺计算已经构造的那两条直达路线的完整成本
（`build_china81_metro_suite_20260812.py:1107-1155` 一线），**不得用直线距离**。

### 3.3 这个判据为什么合法（**对 P46 红线的正面回应**）

P46 已定：「哪个算例跑哪个实验在开跑前预注册写死，**不按效果挑题**」。

本判据**不触及**该红线，理由三条：

1. 它在**任何正式搜索之前**计算，用的是构造式直达路线成本，**不是实验结果**；
2. 它衡量的是**机制有没有作用空间**（客户归错企业后能省回多少），
   这是算例设计，用户在 P43／P22／P46 反复批准过「允许针对性调整构造，使机制具备共同发挥空间」；
3. 本文件在开跑前冻结、统一应用到全部目标格、**全部候选结果保留不删**。

`RED LINE`（会触及红线的做法，明令禁止）：先跑正式实验看效应，再回头换算例或换归属规则；
或对不同机制各挑一个最有利的算例。**一旦发生，本预注册作废并须向用户报告。**

### 3.4 判据方向与项目此前做法相反（须知）

`FACT`（Claude 在 418 对合格候选上实测，直线代理口径）：
一阶协同收益与可争夺比例的**相关系数为 −0.824**。
最高协同收益 46.6%（可争夺 0.04、车场单程 65.7 km），
最低 0.6%（可争夺 0.98、车场单程 1.75 km）。

`INFERENCE`：可争夺高＝客户从哪个场服务都差不多＝换回来也省不了；
可争夺低＝每个客户都有明显更近的场＝归错了就能省一大笔。
**多企业协作设定下要的是低可争夺**，与本项目此前"按可争夺最高排序"的做法方向相反。

`FACT`：`solver/reports/depot_pair_search_28cells_20260815/` 本轮选中的新主格
（可争夺 0.98）在全池 418 对中一阶协同收益**排倒数第一（0.6%）**。该选择据此作废。

`BOUNDARY`：上列 46.6%／0.6%／−0.824 均为**直线距离代理**口径，
用于确定判据方向，**不作为正式数字**；正式排序须按 3.2 用完整评价器重算，数字会变。
