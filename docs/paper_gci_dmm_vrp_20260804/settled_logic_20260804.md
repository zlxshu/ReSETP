## 四、必须在正文里如实交代的边界

这些不是缺陷，是必须写清楚的口径，否则审稿人会抓。

1. **碳强度是省级逐小时模拟投影，不是实测、不是实时、不是边际排放。** 成都 1344 个槽里有 734 个是精确 0.000000，是该投影数据集的产物。
2. **订单时间窗的"硬"是我们加的。** 起止分布来自真实企业订单（Zhang 2025, PLOS ONE, figshare 28113608, CC BY 4.0），但原论文用迟到罚金处理时间窗，并把硬时间窗列为未来研究方向（p.19）。
3. **需求量与服务时长是构造代理。** 需求只有 5 个取值（139/208/278/347/417 kg），来自"体积 ÷ 7.2 × 1000"；服务时长只有 5 个取值（6/9/12/15/18 分钟），来自"体积 × 0.1 h/m³"。二者均为已批准的 MC-001 代理换算，不是实测。
4. **E4 的 −9.75% 目前不能进正文。** 那 405 个解出自受求解器缺陷影响的路径，且 180/180 个车场单元全部贴 EV 上限。必须用干净解重跑。
5. **`g_qt`（充电会话与时段的重叠）含 max/min，不是线性表达式。** 仍是待决项（P14）。
   T1 查明 11 篇文献中无一篇同时给出连续起止 + 首尾分数重叠 + 与路线到达线性连接 + 乘分时碳的完整 MILP。

| 碳信号来源 | 充电站**本地光伏余电** | **区域电网**碳强度 |
| 车队 | 纯电动，单一车型 | 油电混合 |
| 车场 | 单车场 | 多车场 |
| 多趟 | 无 | 实体车日内多趟 |
| 规模 | 14–16 客户、3 辆车 | 100 客户量级 |
| 求解 | Gurobi 6 小时（到时限取当前最好解） | 启发式 |

其 56 算例结果可直接用作本文引言的靶子：普通燃油 VRP 平均 30.8 kg-CO₂、**普通电动 EVRP 反而 32.7 kg-CO₂**（为充电绕路，里程增加）、低碳 EVRP 25.7 kg-CO₂。即"电动化本身不等于减排"有实证。
另有条件性发现可作条件规则范式：春/夏/秋减排 22.7%/17.9%/19.6%，**冬季仅 7.2%**（光伏余电季节性）。

其余可迁移建模：Lin 等（2021）整时段占用；Shi 等（2025）连续区间对分段价格积分；Yao 等（2023）连续到达 + 离散时段启停；Zhen 等（2020）多车场多趟返场时刻；Cheng 等（2022）分时碳目标 + 站级功率约束（无路线）。
**没有任何一篇同时覆盖：混合车队 + 多车场 + 多趟 + 硬时间窗 + 车场与公共站两类充电点。** 这是"前人没有同时考虑"这条研究不足的实证依据。
