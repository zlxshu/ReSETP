**控制变量：** 固定同一实例、订单、路线、车型、总充电需求、充电位置、站点功率上限、价格与碳强度序列、算法预算和服务要求；只改变求解时采用的充电功率函数，以及是否用非线性参考函数回算同一方案。

**这张表证明什么：** 它用于量化线性或分段近似在充电时长、可行性和人民币账上的偏差，并如实识别当前 SOC 区间内是否根本没有非线性差异。

**这张表要支撑的正文结论句：** “在路线、车型、充电需求和站点功率上限相同的条件下，简化充电函数的账面结果经非线性参考函数回算后，充电时长、可行运行数和单目标总账的差异为【待回填】。”

**表注：** S 表示在相应简化充电函数下求得的账面结果；R 表示把同一方案按非线性参考函数完整回算。任何方案若在现行 SOC 区间内与参考函数等价，必须原样报告零差异。当前技术见证未进入曲线的非线性作用区间，尚无可填的正式 S/R 对照；所有数据格均为“待回填”，不虚构高 SOC 充电会话。

**必要性自评：表壳必要，正式正文保留有条件。** 非线性充电承担的是可行性保真而非必须产生节能效果；若正式 S/R 回算仍逐项相同，独立主表对论文效果几乎不变，建议从正文砍掉并在模型说明中交代等价范围。若回算发现可行性或时长偏差，则该表必要。
