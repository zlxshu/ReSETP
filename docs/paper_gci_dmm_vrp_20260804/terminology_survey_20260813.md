# 中文协同配送术语原文调查

日期：2026-08-13  
范围：只读本机 Zotero 中文全文；不改代码、算例、论文正文或图片。

## 一、先说结论

1. 第一组在中文原文中有直接用词：`独立配送模式`、`各配送中心独立运营`、`单独配送`。
2. 第二组有多套真实用词：`联合配送（模式）`、`共同配送`、`资源共享模式`、`协作配送模式`、`多中心协同配送`。其中，与“共享客户和车辆”对应得最直接的是陈雨蝶等（2023）的`联合配送模式`：作者原文明确写“各配送中心共享产品、客户、车辆等资源，共同服务所有客户”。
3. 在本轮指定中文全文及本机 Zotero 全文缓存中，未检索到把“合作后每个参与方不比单干差”原样命名为`个体理性`、`参与约束`或`全员不劣`的中文正文。最接近且定义严格的实际术语是饶卫振等（2019）的`转归解`；作者把它定义为：总分摊成本等于合作总成本，且每个成员分摊成本小于等于不合作成本。
4. 本文现在的 (b) 和 (c) 在文献术语体系里本来就属于同一种合作模式；差别不是“另一种配送模式”，而是同一联合／协作配送下采用了不同的解条件。中文文献可用“转归解”“核心解”等解类名称区分成本分摊条件，但本轮没有找到中文论文把路线图直接命名为“成本最优方案／全员不劣方案”的先例。

## 三、第一组：各车场各自经营、不合作

### 1. `独立配送模式`

- 出处：陈雨蝶、干宏程、程亮、温金鹏《双碳背景下复杂冷链物流模型及求解算法》，PDF 物理页 17，印刷页 16，§4.5。
- 原句：“小型冷链物流企业通常采用独立配送模式，因为它们可能只拥有一个配送中心，只服务自身的客户。”
- 原文用法：这是作者正式列出的三种“配送模式”之一；图5子图题在 PDF 物理页 18、印刷页 17 原样写作“(a) 独立配送”。

### 2. `各配送中心独立运营`

- 出处：王勇、李慧星、罗思妤、周景欣、许茂增《资源共享模式下多中心共同配送电动车辆路径优化问题》，PDF 物理页 4，印刷页 1122，图1说明。
- 原句摘录：“且各配送中心独立运营，导致某些配送服务区域内充电站使用频次过低，加剧了电动车配送路线迂回交错、违反客户服务时间窗等现象。”
- 原文用法：不是一个另立的模式名，而是作者对资源共享前状态的直接描述；它与本文“各车场各自经营”最贴近。

### 3. `单独配送`

- 出处：饶卫振、苗晓河、朱庆华、姜力文《考虑企业服务质量差异的协作配送问题及成本分摊方法研究》，PDF 物理页 3，印刷页 2723，§2.1。
- 原句：“城市内多家配送企业拥有相应的客户点和配送中心，企业单独配送时会产生大量交叉重叠的配送路线，导致成本居高不下。”
- 同文再次出现：PDF 物理页 4、印刷页 2724：“通过图1及表2发现，企业单独配送时路线较长，且存在交叉重叠。若多个企业协作配送，则可显著缩短配送距离，节约配送成本。”
- 原文用法：`单独配送`是正文中的对照状态，不是该文单列的模式标题。

## 四、第二组：合作共享客户与车辆

### 1. `联合配送模式`／`联合配送`

- 出处一：陈雨蝶、干宏程、程亮《“双碳”背景下联合配送冷链物流模型及其求解算法》，PDF 物理页 7，印刷页 1957，§3.2.1。
- 原句：“在联合配送模式下，各配送中心共享产品、客户、车辆等资源，共同服务所有客户，此时碳配额 Tm 为 200 kg。”
- 同页关于优化条件的原句：“采用 CGA-VNS 求解分区配送和联合配送两种模式下的最优路径和最低成本，结果如表4和表5所示。”
- 出处二：陈雨蝶等《双碳背景下复杂冷链物流模型及求解算法》，PDF 物理页 17，印刷页 16，§4.5。
- 原句：“……联合配送模式共享产品、客户、车辆等资源……”
- 图题：同文 PDF 物理页 18、印刷页 17，图5原样写作“(c) 联合配送”。
- 原文用法：这是本轮最直接、最完整对应“多个车场合作共享客户与车辆”的模式名。

### 2. `共同配送`／`多中心共同配送`

- 出处：王勇等《资源共享模式下多中心共同配送电动车辆路径优化问题》，PDF 物理页 1，印刷页 1119，摘要与关键词。
- 原句：“本研究所提出的模型和算法能够实现多中心共同配送线路中充电站的共享、电动配送车辆的共享调度以及合理的电动车辆路径优化……”
- 同页关键词原样为：“资源共享模式；多中心共同配送；电动车辆路径；充电站；CW-MOPSO混合算法”。
- 原文用法：`共同配送`是问题名称的一部分；作者同时用`资源共享模式`说明共享条件。

### 3. `资源共享模式`

- 出处：王勇等（2023），PDF 物理页 4，印刷页 1122，图1及其说明。
- 原句：“在保障电动配送车辆充电需求的前提下，有效整合充电站资源与电动车资源，开展配送中心间合作运营，并合理规划配送与充电路径，能够有效降低运营成本……”
- 同页图题：“资源共享模式下多中心共同配送电动车辆路径优化前后对比”。
- 同页对优化后状态的原句：“图1(b)表示多中心共同配送电动车辆路径优化后，多个配送中心进行合作使配送区域得到合理划分……实现充电站的共享利用与电动车的共享调度……”
- 原文用法：它是合作共享的条件／运营环境，与`多中心共同配送`合用，不是公平条件的名称。

### 4. `协作配送模式`／`协作配送`

- 出处：饶卫振等（2022），PDF 物理页 2，印刷页 2722，引言。
- 原句：“鉴于物流企业末端配送路线交叉重叠严重、成本居高不下的现状，协作配送模式应运而生。多个企业组建联盟，共享客户订单及配送资源进行协作，能够显著降低配送成本，提高配送效率。”
- 同文 PDF 物理页 3、印刷页 2723：“若多个企业依托第三方平台组建联盟协作配送，通过交换获得距离自身较近的客户订单，能够显著缩短配送距离，提高配送效率。”
- 原文用法：强调多个独立企业组建联盟、交换客户订单并共享配送资源；它与本文若按“不同企业参加合作”来叙述时最接近。

### 5. `多中心协同配送`

- 出处：王勇、苟梦圆、黄美林、蒋琼、许茂增《考虑动态需求的多中心电动配送车辆路径优化问题》，PDF 物理页 4，稿内印刷页 3，引言。
- 原句：“Sarbijan和Behnamian[17]研究了共享客户需求的多中心协同配送车辆路径问题……”；紧接着又写：“Ahari等[18]研究了共享运输车辆的多中心协同配送车辆路径问题……”
- 原文用法：这是王勇等在文献综述中概括所引研究的用词；一处对应共享客户需求，另一处对应共享运输车辆。它不是王勇等为自己全文统一采用的问题名称，不能据此把`协同配送`说成该文唯一术语。

## 五、第三组：保证每个参与方不比单干差

### 5.1 精确检索结果

在上述指定中文全文、补查的饶卫振等（2019）以及本机 Zotero 全文缓存中，未找到以下词在中文正文中原样出现：

- `个体理性`
- `参与约束`
- `全员不劣`

因此，本报告不把这三个词写成“中文协同配送文献的通行术语”。`全员不劣`确认是代理改写，不应继续冒充文献用语。`个体理性`和`参与约束`虽然可作为英文概念的常见译法候选，但本轮没有取得指定范围内的中文原句，故不据此采用。

### 5.2 最接近且有严格定义的实际术语：`转归解`

- 出处：饶卫振、张云东、刘从虎、于灏、侯艳辉《一种求解协作配送成本分摊问题核仁解的近似迭代算法》，PDF 物理页 8，印刷页 1524，§5.1。
- 原句：“显然，分摊方案至少应满足以下两个条件：1）总的分摊成本之和等于所有成员协作产生的总成本，即 x(N)=c(N)；2）每个成员分摊的成本应该小于等于不合作的成本，即 xi≤c({i})（1≤i≤n）。此类方案被称为转归解……”
- 紧接的原句：“转归解一定存在，且能够保证每个成员参与协作均能减少自身成本，从而可以保证任意单个成员均会参与协作。”
- 适用边界：`转归解`是合作博弈中的成本分摊方案名称。若本文 (c) 画的是“路线本身满足各车场利润下界、没有事后成本分摊”，直接把整条路线叫`转归解`会改变含义；此时宜采用原文条件句，而不是套用该解名。

### 5.3 同一条件的另一篇原文表述：`实质合作`

- 出处：饶卫振等（2022），PDF 物理页 8，印刷页 2728，§4.1。
- 原句：“根据Shapley值法的性质，由上式计算得到的分摊方案必然使得：1）n个企业成本分摊值加和等于大联盟总成本C(N)；2）每个企业的分摊成本 φi 必定小于该企业独立配送的成本 Ci，联盟形成实质合作。”
- 适用边界：`实质合作`是作者对上述结果的判断，不是与`联合配送模式`并列的模式名，也不是一个单独定义的约束名。

### 5.4 更宽、但不等同于“不比单干差”的实际表述：`公平合理`

- 出处：饶卫振等（2022），PDF 物理页 4，印刷页 2724，§2.1。
- 原句：“配送企业加入联盟的先决条件是，每个成员获得的成本节约量符合自身预期，即成本分摊方案需公平合理。”
- 适用边界：这句话还包含“符合自身预期”，比单纯的“不比单干差”更宽，不能把`公平合理`当成该数学条件的精确同义词。

### 5.5 不能混用的更强术语：`核心解`

- 出处：饶卫振等（2019），PDF 物理页 8，印刷页 1524，§5.1。
- 原句：“为了保证任意子联盟 S 也不会离开联盟 N，有学者进一步提出了核心解的概念。”
- 区别：`转归解`保证每个单个成员不因合作变差；`核心解`还要求任意子联盟都没有离开的动机。后者条件更强，不能拿来替换本文只要求“每个参与方不比单干差”的情形。

## 七、(b)(c) 是否本就同属一种模式

是。直接证据有两层。

第一，陈雨蝶等（2023）把`联合配送模式`定义为“各配送中心共享产品、客户、车辆等资源，共同服务所有客户”（PDF物理页7／印刷页1957）。这个定义只说明资源与服务关系，并没有因为总成本最低或成员保障条件不同而变成另一种配送模式。因此，本文 (b)(c) 只要都共享客户与车辆，就都属于联合配送。

第二，饶卫振等（2019）在同一个合作博弈中按约束强弱区分`转归解`和`核心解`：先用总成本守恒与单个成员不比不合作差定义转归解，再对“任意子联盟也不会离开”定义核心解（PDF物理页8／印刷页1524）。饶卫振等（2022）也始终把业务称为`协作配送`，随后才讨论Shapley分摊方案是否使每个企业成本低于独立配送成本、以及分摊是否公平（PDF物理页8／印刷页2728）。也就是说，中文文献的做法是保留同一个模式名，再用解类、约束或分摊条件区分不同方案。

本轮未在指定中文全文中找到一张与本文完全同构、把“联合配送的最低成本路线”和“同一联合配送下保障每个成员的路线”并排作两个中文子图的实例。能确认的是术语层级：`联合配送／协作配送`是模式，`转归解／核心解`或“每个成员成本不高于单干成本”是叠加在该模式上的解条件。
