% MV-HGS-SP main algorithm flow (v2, 2026-07-27).
% Bound to the unified protocol approved on 2026-07-27:
%   (a) three mechanism views, each run to its own NoImprovement(K) convergence
%       (a single budget is never split across the three views);
%   (b) an OUTER EPOCH LOOP: the accepted incumbent is written back as the
%       warm start of the next epoch and the route pool accumulates across epochs;
%   (c) time-limited MIP set partitioning on the pool with a min() safety net.
% Superseded v1 (single pass, "fixed 5000 iterations") is kept in git history only.
% Style: transparent line art, no shading, phase band on the left, loop return
% routed outside all nodes on the right.
