## E3以后回填规则

1. 只从封存CSV或独立复算产物生成表图，不手填结果。
2. 表格沿用当前全文行宽三线表、表头居中、同列数字右对齐和`\tabnote`格式。
3. 图形沿用中文轴、异线型、无网格和无外框图例；图例应放入不遮挡数据的轴内空白区。
   图4固定题名为“不同算法迭代图”，横轴为“时间(min)”、纵轴为“成本(元)”；不得为
   强化胜负而断轴、归一化、平滑或补造观测点。
4. 运行`python3 math_audit.py`与相关测试，再用XeLaTeX至少编译两遍。
5. 对最终PDF逐页栅格化检查遮挡、越界、断轴和表注。
