## 一、结论

**属于「(b) 可由一份国家级文件的标准链条完整推出」，不属于 (a)。**

- 该文件**没有直接印出** 2.6419 这个数。全文（70 页）检索 `2.6419` 与 `2.64` 命中 0 次。
- 但该文件同时印出了推出它所需的**全部四个输入**和**两条公式**，按其自身口径复算，
  逐位得到 `2.6419028944`（11 位有效数字全对，无凑数）。
- 因此这不是"本文设定"，也不是"照抄某文献的现成因子"，而是**按国家发展改革委指南的
  缺省参数与公式换算出的每升柴油燃烧 CO₂ 排放量**。

## 三、复算（2026-09-10 独立重算，与代码常数逐位一致）

```
ρ    = 0.84 t/m³ = 0.00084 t/L          （印刷页 15）
NCV  = 43.330 GJ/t                       （印刷页 60）
CC   = 20.20×10⁻³ tC/GJ                  （印刷页 60）
OF   = 98%                               （印刷页 60）

每升能量      0.00084 × 43.330            = 0.03639720      GJ/L
每升含碳      0.03639720 × 0.02020        = 0.00073522344   tC/L
氧化部分      0.00073522344 × 0.98        = 0.00072051897 12 tC/L
碳→二氧化碳   × 44/12                     = 0.0026419028944 tCO₂/L
吨→千克       × 1000                      = 2.6419028944    kgCO₂/L
```

合并写法：`EF = ρ · NCV · CC · OF · 44/12 = 2.6419028944 kgCO₂/L`。

## 五点五、与正文已引方法来源（巩亮 2026，`ref:95`）的对照

`paper_main.tex:430` 正是用 `\cite{ref:95}` 支撑"燃油车直接排放按油耗量和燃油排放因子计算"。
核对该文原文（Zotero item `HADEF6XR`，《控制与决策》2026, 41(5): 1338–1347）：

- 它的式 (10) 为 `F_j = 12/44 · Q_j U_j O_j`，其中 `Q_j` = 低位发热量、`U_j` = 单位热值含碳量、
  `O_j` = 碳氧化率，并明确 `F_c`（燃油车碳排放因子）**单位为 kgCO₂/L**。
  该式的上游是它的文献 [17]（李宁海等，我国交通运输业碳达峰时间预测）。
- **结论一：不冲突。** 该文**通篇没有印出任何燃油排放因子的数值**，只给公式结构。
  所以不存在"正文引了一个方法来源、表里却用另一个数"的矛盾。
- **结论二：结构一致，本文更完整。** 其 `Q·U·O·44/12` 与指南公式 (4)(5) 是同一条链，
  但它**缺了密度这一步**——`NCV×CC×OF×44/12` 的量纲是 tCO₂/t（每吨燃料），
  却直接标成 kgCO₂/L，是该文的一处量纲不闭合。本文的链条补上了 0.84 t/m³ 这一步，
  单位才真正落到 kgCO₂/L。
- **结论三：该文式 (10) 把 44/12 写成了 12/44**（碳与二氧化碳分子量之比写反），属印刷/笔误。
  引它作方法出处没问题，但**不要照抄它的式子形式**。
- 附带：该文同样是纯 CO₂ 口径，没有写 CO₂e。
