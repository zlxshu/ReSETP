### 第 15 处：改了表格单元就必须同改正文

`mechanical_insertion_count` 在 `dynamic_events.csv` 里是**累计**值：
顺序插入 1→1→3→4→**5**，滚动重优化 0→0→2→2→**2**，与 `raw_runs.csv` 的终值一致。
按表内定义（"把新到订单插入路径的次数"），滚动重优化就是 2。

但原正文写的是"两种在线策略都把5笔新增订单全部插入路径"——单元格改成 2 之后，
这句和表格会当面打架（正文说两臂都插了 5 笔，表里一臂写 2）。故正文同步改为：

> 2）两种在线策略均完整承接了5笔新增订单，但放置方式不同：顺序插入策略的5笔全部由逐客户插入，只在既有路径上添加新停靠点；
> 滚动重优化策略只有第3批次的2笔由逐客户插入放置，其余3笔由批次重排直接安置。

即把"都插入 5 笔"改成"都承接 5 笔"，插入次数交给表格说。
若作者更想保留单元格 5，则应改的是**行名**（如"新增订单放置笔数"），二者只能取其一。

## 三、查过、结论是"论文没错"但值得记一笔的地方

### 1. 标准算例的 .xx5 半档值（7 处）

`public28_formal_20260830` 的 `cost` 字段是**整数**（千分之一单位），
所以 PR11A/PR12A/PR14A/PR16B/PR17B/PR19A/PR20B 的本文 Best 恰好是精确的两位半档
（如 PR17B = 4771155/1000 = 4771.155）。论文按 ROUND_HALF_UP 进位为 4771.16，**正确**。
> 施工提醒：审计脚本第一版用 `float(cost)/1000` 曾把这 7 处全部误判为 MISMATCH——
> 二进制下 4771.155 实为 4771.15499…，向下舍成 4771.15。已改为 `Decimal(cost)/Decimal(1000)`。
> 凡"精确十进制"的量，审计必须走 Decimal，不能先落到 float。

因此 PR17B 的本文 Best 确实等于 BKS 4771.16，正文"求得与已知最优解成本相同的方案"成立。

### 2. 标准算例 Gap 的口径

论文的 8 个百分比（0.35/1.78/1.61/1.12 与 0.73/2.52/2.01/1.45）**全部**符合
"（该列 Average 单元格 − BKS Average 单元格）/ BKS Average"这一口径，8 个逐位吻合。
另一种口径"逐题算比再取均值"给出的是 0.32 等，与论文不符。口径已在脚本里写死并留了对照打印。
本文两列的 Average 单元格本身也已核过等于 28 次全精度均值的正确舍入（8656.73 / 8688.79）。

### 3. 4.1.2 里"合计 ≠ 各行相加"是对的，不要改

`final_solution_trip_rows.tex` 的合计行是全精度总和后舍入，与逐行二位相加可能差 0.01。
同类：4.1.2 的 79.20\%（全精度 44.20+34.99 之和的正确舍入）与两个印出占比相加的 79.19 差 0.01。
这两处**保持原样**，因为合计行必须与该 run 的官方 breakdown 对齐（生成脚本内有断言）。

### 4. 4.4.2 的 0.585 / 0.143 / 4.09

* **0.585 元/kWh** 已精确定源：北京峰段价 1.14862175 − 谷段价 0.56328575 = **0.585336** → 0.585。
* **0.143 kgCO$_2$e/kWh 与 4.09 元/kgCO$_2$e：未能定源**，只能确认两者互相自洽（0.585336 / 0.143 = 4.0933 → 4.09）。
  能逐位复原的定义是"首趟前窗口内谷段各时隙碳强度均值 0.61785 − 前日 18:00 时隙碳强度 0.4748 = **0.14305** → 0.143，
  盈亏平衡碳价 = 0.585336 / 0.14305 = **4.0917** → 4.09"。
  **该定义是本次复原的，仓库里没找到当初的推导记录**；其他几个自然定义都对不上
  （谷段均值−峰段均值 = 0.148 → 3.96；谷段最低−峰段最低 = 0.154 → 3.80）。
  但这个复原口径**一边取均值、一边取单个时隙**，并不对称；这张表里两项相减的组合很多，
  其中一个恰好落在 0.143 上，证据强度不如"三位吻合"看着那么高。
  **结论按"未验证"记**：0.585 已定源，0.143 与 4.09 只是彼此自洽，推导过程没找到，请作者确认。
  已在脚本里按复原口径固定，注释写明"口径为复原，非脚本原始记录"。
